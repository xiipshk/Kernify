## 1. Арифметические операторы

```cpp
int a = 17, b = 5;

a + b   // 22  (сложение)
a - b   // 12  (вычитание)
a * b   // 85  (умножение)
a / b   // 3   (целочисленное деление!)
a % b   // 2   (остаток от деления)

// Унарные
+a      // 17
-a      // -17
++a     // префиксный инкремент (a=18, возвращает 18)
a++     // постфиксный инкремент (возвращает 17, потом a=18)
--a     // префиксный декремент
a--     // постфиксный декремент
```

### Важно: целочисленное деление
```cpp
int x = 5 / 2;        // 2 (не 2.5!)
double y = 5.0 / 2;   // 2.5
double z = 5 / 2.0;   // 2.5
```

### Остаток от деления
```cpp
17 % 5   // 2
-17 % 5  // -2 (знак делимого)
17 % -5  // 2  (знак делимого)
```

## 2. Операторы присваивания

```cpp
int x = 10;
x += 5;   // x = x + 5  -> 15
x -= 3;   // x = x - 3  -> 12
x *= 2;   // x = x * 2  -> 24
x /= 4;   // x = x / 4  -> 6
x %= 4;   // x = x % 4  -> 2

// Битовые
x &= 3;   // x = x & 3
x |= 1;   // x = x | 1
x ^= 2;   // x = x ^ 2
x <<= 1;  // x = x << 1
x >>= 1;  // x = x >> 1
```

---

## 3. Операторы сравнения

```cpp
int a = 5, b = 10;

a == b   // false (равно)
a != b   // true  (не равно)
a < b    // true  (меньше)
a > b    // false (больше)
a <= b   // true  (меньше или равно)
a >= b   // false (больше или равно)

// Цепочки сравнений (C++20: <=>)
auto cmp = a <=> b;  // three-way comparison (spaceship operator)
// Возвращает: std::strong_ordering::less / equal / greater
```

### Сравнение с плавающей точкой
```cpp
// НЕ делайте так:
if (x == 1.5) { ... }  // ОПАСНО: ошибки округления

// Делайте так:
#include <cmath>
if (std::abs(x - 1.5) < 1e-9) { ... }  // epsilon comparison
```

## 4. Логические операторы

```cpp
bool p = true, q = false;

!p      // false (NOT)
p && q  // false (AND, short-circuit)
p || q  // true  (OR, short-circuit)
```

### Short-circuit evaluation
```cpp
bool result = (ptr != nullptr) && (ptr->value > 0);
// Если ptr == nullptr, вторая часть НЕ вычисляется (нет UB)

int x = 0;
bool b = (x != 0) && (10 / x > 5);  // Безопасно: 10/x не вычисляется
```

## 5. Битовые операторы

```cpp
unsigned char a = 0b1010;  // 10 (1010)
unsigned char b = 0b0110;  // 6  (0110)

a & b   // 0b0010 = 2  (AND)
a | b   // 0b1110 = 14 (OR)
a ^ b   // 0b1100 = 12 (XOR)
~a      // 0b0101 = 5  (NOT, инверсия битов)

a << 1  // 0b10100 = 20 (сдвиг влево = *2)
a >> 1  // 0b0101 = 5   (сдвиг вправо = /2)
```

### Практические примеры
```cpp
// Флаги
enum Flags : unsigned { Read = 1, Write = 2, Execute = 4 };
unsigned perm = Read | Write;  // 3
bool can_read = perm & Read;   // true
perm |= Execute;               // добавить флаг
perm &= ~Write;                // убрать флаг

// Быстрое умножение/деление на степени 2
x << 3  // x * 8
x >> 2  // x / 4

// Проверка чётности
bool even = (x & 1) == 0;
```

## 6. Операторы работы с памятью и объектами

```cpp
int x = 42;
int* p = &x;       // адрес (address-of)
int val = *p;      // разыменование (dereference)

int arr[5] = {1,2,3,4,5};
int* p2 = arr;     // ухудшение до указателя на первый элемент
int v = p2[2];     // 3 (pointer arithmetic: *(p2 + 2))

// sizeof
sizeof(int)        // 4 (байт)
sizeof x           // 4 (без скобок для выражений)
sizeof arr         // 20 (весь массив, не указатель!)
```

### `alignof` и `alignas` (C++11)
```cpp
alignof(int)       // 4 (требование выравнивания)
alignof(double)    // 8

struct alignas(16) AlignedStruct {  // выравнивание 16 байт
    int x;
};
```

## 7. Приоритет и ассоциативность (высший -> низший)

| Приоритет | Операторы | Ассоциативность |
|-----------|-----------|-----------------|
| 1 | `::` (scope) | Слева направо |
| 2 | `()`, `[]`, `.`, `->`, `++`, `--`, `type()`, `type{}` | Слева направо |
| 3 | `++`, `--`, `+`, `-`, `!`, `~`, `*`, `&`, `sizeof`, `alignof`, `new`, `delete`, `co_await` | Справа налево |
| 4 | `.*`, `->*` | Слева направо |
| 5 | `*`, `/`, `%` | Слева направо |
| 6 | `+`, `-` | Слева направо |
| 7 | `<<`, `>>` | Слева направо |
| 8 | `<=>`, `<`, `<=`, `>`, `>=` | Слева направо |
| 9 | `==`, `!=` | Слева направо |
| 10 | `&` | Слева направо |
| 11 | `^` | Слева направо |
| 12 | `\|` | Слева направо |
| 13 | `&&` | Слева направо |
| 14 | `\|\|` | Слева направо |
| 15 | `?:` (тернарный) | Справа налево |
| 16 | `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `&=`, `\|=`, `^=`, `<<=`, `>>=` | Справа налево |
| 17 | `throw` | Справа налево |
| 18 | `,` (запятая) | Слева направо |

### Примеры
```cpp
a = b = c = 0;     // a = (b = (c = 0))
a + b * c          // a + (b * c)
a && b || c        // (a && b) || c
*p++               // *(p++) — постфиксный ++ выше, чем *
```

## 8. Тернарный оператор

```cpp
int a = 10, b = 20;
int max = (a > b) ? a : b;  // 20

// Может использоваться как lvalue (C++17)
(a > b ? a : b) = 30;  // присваивает большей переменной

// В constexpr
constexpr int abs(int x) { return x >= 0 ? x : -x; }
```

---

## 9. Запятая (comma operator)

```cpp
int a = (1, 2, 3);  // a = 3 (значение последнего выражения)

for (int i = 0, j = 10; i < j; ++i, --j) {
    // множественные переменные в for
}

// В макросах
#define LOG_AND_RETURN(x) (std::cout << x, x)
```

## Типичные ошибки

| Ошибка | Правильно |
|--------|-----------|
| `if (x = 5)` (присваивание) | `if (x == 5)` или `if (auto val = x; val == 5)` |
| `5 / 2 == 2.5` | `5 / 2 == 2` (целочисленное), `5.0 / 2 == 2.5` |
| `x << 1` вместо `x * 2` для signed | `x * 2` (UB при переполнении signed) |
| `~x` для signed | Используйте unsigned типы для битовых операций |
| Забыли скобки: `a & b == c` | `(a & b) == c` (приоритет `==` выше `&`) |
