# Урок 2: Переменные и типы данных

## Объявление переменных: let, const, var

В современном JavaScript (ES2015+) есть два основных способа объявить переменную:

```javascript
// let — переменная, которую можно переприсваивать
let age = 25;
age = 26; // OK
console.log(age); // 26

// const — константа, переприсваивание запрещено
const PI = 3.14159;
// PI = 3; // TypeError: Assignment to constant variable

// const с объектами/массивами — ссылка не меняется, но содержимое можно
const user = { name: 'Анна' };
user.name = 'Мария'; // OK — меняем свойство, не саму ссылку
user.age = 20; // OK
// user = {}; // TypeError — нельзя заменить объект целиком
```

### var — устаревший способ (для понимания старого кода)

```javascript
var oldStyle = 'ES5';

// Проблемы var:
function example() {
  if (true) {
    var x = 10; // function-scoped, не block-scoped
  }
  console.log(x); // 10 — переменная "утекает" из блока
}

// let/const — block-scoped:
function exampleModern() {
  if (true) {
    let y = 10;
    const z = 20;
  }
  // console.log(y); // ReferenceError
  // console.log(z); // ReferenceError
}
```

**Правило:** По умолчанию используйте `const`. Если нужно переприсваивать — `let`. `var` не используйте в новом коде.

## Примитивные типы данных

В JavaScript **8 примитивных типов** (ES2023):

| Тип | Описание | Пример |
|-----|----------|--------|
| `number` | Числа (целые, дробные, Infinity, NaN) | `42`, `3.14`, `-10`, `Infinity` |
| `bigint` | Целые числа произвольной точности | `9007199254740991n`, `123n` |
| `string` | Строки (текст) | `'привет'`, `"мир"`, `` `шаблон ${x}` `` |
| `boolean` | Логические значения | `true`, `false` |
| `undefined` | Значение не присвоено | `let x;` → `undefined` |
| `null` | Пустое значение (нет объекта) | `let x = null;` |
| `symbol` | Уникальные идентификаторы | `Symbol('id')` |
| `object` | **Не примитив** — сложные структуры | `{}`, `[]`, `new Date()` |

```javascript
// Проверка типа
typeof 42;           // 'number'
typeof 123n;         // 'bigint'
typeof 'hello';      // 'string'
typeof true;         // 'boolean'
typeof undefined;    // 'undefined'
typeof null;         // 'object' — известный баг JS с 1995 года!
typeof Symbol();     // 'symbol'
typeof {};           // 'object'
typeof [];           // 'object'
typeof function(){}; // 'function'
```

### Особенности number

```javascript
// Специальные значения
Infinity;           // Бесконечность (1 / 0)
-Infinity;          // Минус бесконечность
NaN;                // Not a Number (0 / 0, 'строка' * 2)

// Проверки
Number.isNaN(NaN);           // true (не используйте глобальный isNaN!)
Number.isFinite(42);         // true
Number.isFinite(Infinity);   // false
Number.isInteger(3.14);      // false
Number.isInteger(42);        // true

// Безопасные целые (до 2^53 - 1)
Number.MAX_SAFE_INTEGER;  // 9007199254740991
Number.MIN_SAFE_INTEGER;  // -9007199254740991

// Для больших чисел — BigInt
const big = 9007199254740991n + 1n; // 9007199254740992n
// big + 42; // TypeError — нельзя смешивать number и bigint
```

## Строки (string)

```javascript
// Три способа записи
const single = 'Одинарные кавычки';
const double = "Двойные кавычки";
const backtick = `Шаблонные строки (template literals)`;

// Шаблонные строки — поддержка интерполяции и многострочности
const name = 'Алекс';
const age = 25;
const greeting = `Привет, ${name}! Тебе ${age} лет.`;
console.log(greeting); // Привет, Алекс! Тебе 25 лет.

// Многострочные строки
const html = `
  <div>
    <h1>Заголовок</h1>
    <p>Текст</p>
  </div>
`;

// Экранирование
const path = 'C:\\Users\\name';     // обратный слеш
const quote = 'Он сказал: "Привет"'; // кавычки внутри
const template = `Стоимость: \${100}`; // экранирование ${ в шаблоне
```

**Полезные методы строк (ES2023+):**

```javascript
const str = '  JavaScript  ';

str.trim();           // 'JavaScript' — убирает пробелы по краям
str.trimStart();      // 'JavaScript  '
str.trimEnd();        // '  JavaScript'
str.toUpperCase();    // '  JAVASCRIPT  '
str.toLowerCase();    // '  javascript  '
str.repeat(3);        // '  JavaScript    JavaScript    JavaScript  '

// Поиск
'hello world'.includes('world');  // true
'hello world'.startsWith('he');   // true
'hello world'.endsWith('ld');     // true
'hello'.indexOf('l');             // 2 (первое вхождение)
'hello'.lastIndexOf('l');         // 3 (последнее вхождение)

// Извлечение (не меняют оригинал!)
'hello'.slice(1, 4);      // 'ell' (от 1 до 4, не включая 4)
'hello'.substring(1, 4);  // 'ell' (похоже, но отрицательные не работает)
'hello'.substr(1, 3);     // 'ell' (устарел, от 1 длина 3)
'hello'.at(1);            // 'e' (ES2022, поддерживает отрицательные: .at(-1) = 'o')
'hello'.charAt(1);        // 'e' (старый способ)

// Замена
'foo bar'.replace('foo', 'baz');        // 'baz bar' (только первое)
'foo foo'.replaceAll('foo', 'baz');     // 'baz baz' (ES2021, все вхождения)
'foo bar'.replace(/foo/, 'baz');        // с regex

// Разделение и объединение
'a,b,c'.split(',');        // ['a', 'b', 'c']
['a', 'b', 'c'].join('-'); // 'a-b-c'

// ES2023: изменяющие копии (не мутируют оригинал!)
const arr = [3, 1, 2];
arr.toSorted();      // [1, 2, 3] — копия, отсортированная
arr.toReversed();    // [2, 1, 3] — копия, перевёрнутая
arr.with(0, 99);     // [99, 1, 2] — копия с заменой индекса 0
```

## Boolean и логическое приведение

```javascript
// Явные boolean
true;
false;

// Falsy значения (приводятся к false)
false;
0;           // и -0, 0n
'';          // пустая строка
null;
undefined;
NaN;
document.all; // экзотический случай (legacy)

// Все остальное — truthy
true;
1;
'0';         // строка с нулём — true!
'false';     // строка "false" — true!
[];
{};          // пустой объект/массив — true!
function() {};

// Явное приведение к boolean
Boolean('hello');  // true
Boolean(0);        // false
!!'hello';         // true (двойное отрицание — идиома)
!!0;               // false
```

## Null и Undefined

```javascript
let declaredButNotAssigned; // undefined
let explicitlyNull = null;  // null

// Разница:
// undefined — переменная объявлена, но значение не задано
// null — переменной явно присвоено "ничего" (пустое значение объекта)

// Проверки
declaredButNotAssigned === undefined; // true
explicitlyNull === null;              // true

// Nullish coalescing (ES2020) — только для null/undefined
const userName = null;
const displayName = userName ?? 'Гость'; // 'Гость'

// Не путать с || (OR) — он срабатывает на любом falsy!
const count = 0;
count || 10;     // 10 (потому что 0 — falsy)
count ?? 10;     // 0 (потому что 0 не null/undefined)
```

## Приведение типов (Type Coercion)

### Неявное (автоматическое)

```javascript
// Строковое сложение
'5' + 1;        // '51' (строка)
'5' - 1;        // 4 (число! минус работает только с числами)
'5' * '2';      // 10 (число)
true + 1;       // 2 (true → 1)
false + 1;      // 1 (false → 0)
null + 1;       // 1 (null → 0)
undefined + 1;  // NaN (undefined → NaN)
[] + [];        // '' (пустая строка)
[] + {};        // '[object Object]'
{} + [];        // 0 (блок {} + унарный +) — хитрый случай!
```

### Явное (ручное)

```javascript
// К числу
Number('42');      // 42
Number('3.14');    // 3.14
Number('hello');   // NaN
Number(true);      // 1
Number(false);     // 0
Number(null);      // 0
Number(undefined); // NaN
Number('');        // 0

// parseInt / parseFloat (парсят до первого нецифрового)
parseInt('42px');      // 42
parseFloat('3.14px');  // 3.14
parseInt('hello');     // NaN

// Унарный плюс (коротко)
+'42';      // 42
+true;      // 1
+null;      // 0
+undefined; // NaN

// К строке
String(42);        // '42'
String(true);      // 'true'
String(null);      // 'null'
String(undefined); // 'undefined'
(42).toString();   // '42'
42 + '';           // '42' (трюк с конкатенацией)

// К boolean
Boolean(42);       // true
Boolean(0);        // false
Boolean('');       // false
Boolean('0');      // true!
!!42;              // true
!!0;               // false
```

## Symbol — уникальные идентификаторы (ES2015)

```javascript
const sym1 = Symbol('id');
const sym2 = Symbol('id');
sym1 === sym2; // false — каждый Symbol уникален

// Глобальный реестр символов
const globalSym1 = Symbol.for('app.user.id');
const globalSym2 = Symbol.for('app.user.id');
globalSym1 === globalSym2; // true — один и тот же из реестра

Symbol.keyFor(globalSym1); // 'app.user.id'

// Использование: уникальные ключи объекта
const ID = Symbol('id');
const user = {
  [ID]: 123, // computed property name
  name: 'Alex'
};
user[ID]; // 123
// user.ID — undefined (обычное свойство 'ID' не равно Symbol)

// Symbolы не перечисляются в for...in, Object.keys, JSON.stringify
Object.keys(user);        // ['name']
JSON.stringify(user);     // '{"name":"Alex"}'
```

## Object — ссылочный тип

```javascript
// Объекты создаются по ссылке
const a = { x: 1 };
const b = a;     // b ссылается на ТОТ ЖЕ объект
b.x = 2;
console.log(a.x); // 2 — изменился и a!

// Копирование (поверхностное)
const c = { ...a };        // spread (ES2018)
const d = Object.assign({}, a); // старый способ
c.x = 99;
console.log(a.x); // 2 — a не изменился

// Глубокое копирование (ES2023+)
const deep = structuredClone(a); // работает с Date, Map, Set, RegExp и др.
// Или: JSON.parse(JSON.stringify(a)) — но теряет функции, Date, undefined, циклические ссылки
```
