## Что такое функция?

Функция — это именованный блок кода, который можно вызывать многократно. Функции позволяют:
- Избегать дублирования кода (DRY — Don't Repeat Yourself)
- Разбивать сложные задачи на простые части
- Делать код читаемым и поддерживаемым

```javascript
// Объявление функции (Function Declaration)
function greet(name) {
  return `Привет, ${name}!`;
}

// Вызов функции
greet('Алекс');  // 'Привет, Алекс!'
greet('Мария');  // 'Привет, Мария!'
```

---

## Способы объявления функций

### 1. Function Declaration (объявление функции)

```javascript
function add(a, b) {
  return a + b;
}

// Можно вызывать ДО объявления (hoisting)
console.log(add(2, 3)); // 5 — работает!

function add(a, b) {
  return a + b;
}
```

**Хостинг:** Function Declaration поднимается вверху области видимости целиком (имя + тело).

---

### 2. Function Expression (функциональное выражение)

```javascript
// Присваивание функции в переменную
const multiply = function(a, b) {
  return a * b;
};

// Нельзя вызывать ДО объявления
// console.log(multiply(2, 3)); // ReferenceError!

const multiply = function(a, b) {
  return a * b;
};
console.log(multiply(2, 3)); // 6 — работает
```

**Именованное функциональное выражение** (полезно для отладки):
```javascript
const factorial = function fact(n) {
  return n <= 1 ? 1 : n * fact(n - 1);
};
```

---

### 3. Arrow Functions (стрелочные функции, ES2015)

```javascript
// Полная форма
const add = (a, b) => {
  return a + b;
};

// Неявный возврат (implicit return) — без {} и return
const addShort = (a, b) => a + b;

// Один параметр — скобки не обязательны
const square = x => x * x;

// Нет параметров — нужны пустые скобки
const sayHi = () => 'Привет!';

// Несколько строк — нужны {} и return
const sum = (a, b) => {
  const result = a + b;
  return result;
};

// Возврат объекта — оберните в ()
const createUser = (name, age) => ({ name, age });
createUser('Alex', 25); // { name: 'Alex', age: 25 }
```

**Важные отличия стрелочных функций:**
- Нет своего `this` (берёт из внешней области)
- Нет `arguments`
- Нельзя использовать как конструктор (`new`)
- Нет `prototype`

## Параметры и аргументы

### Обязательные и необязательные параметры

```javascript
function greet(name, greeting = 'Привет') {
  return `${greeting}, ${name}!`;
}

greet('Alex');           // 'Привет, Alex!'
greet('Alex', 'Здравствуй'); // 'Здравствуй, Alex!'
```

### Rest-параметры (остаточные параметры)

```javascript
function sum(...numbers) {
  return numbers.reduce((acc, n) => acc + n, 0);
}

sum(1, 2, 3);      // 6
sum(10, 20, 30, 40); // 100

// Комбинация с обычными параметрами (rest должен быть последним)
function show(name, ...tags) {
  console.log(name, tags);
}
show('JS', 'web', 'frontend'); // 'JS' ['web', 'frontend']
```

### Spread-оператор при вызове

```javascript
const nums = [1, 2, 3];
sum(...nums); // 6 — равносильно sum(1, 2, 3)
```

## Возврат значений (return)

```javascript
function divide(a, b) {
  if (b === 0) {
    return 'Ошибка: деление на ноль'; // ранний возврат
  }
  return a / b;
}

divide(10, 2); // 5
divide(10, 0); // 'Ошибка: деление на ноль'
```

**Неявный возврат `undefined`:**
```javascript
function log(message) {
  console.log(message);
  // return undefined — неявно
}
const result = log('test'); // undefined
```

## Область видимости (Scope)

### Глобальная область
```javascript
const globalVar = 'я везде';

function test() {
  console.log(globalVar); // доступна
}
```

### Функциональная область (Function Scope)
```javascript
function outer() {
  const innerVar = 'только здесь';

  function inner() {
    console.log(innerVar); // доступна (замыкание!)
  }

  inner();
}
// console.log(innerVar); // ReferenceError
```

### Блочная область (Block Scope) — let, const
```javascript
if (true) {
  let blockVar = 'только в блоке';
  const blockConst = 'тоже только здесь';
  var functionVar = 'видна во всей функции';
}
// console.log(blockVar);     // ReferenceError
// console.log(blockConst);   // ReferenceError
console.log(functionVar);    // 'видна во всей функции'
```

### Лексическое окружение и замыкания (Closures)

```javascript
function createCounter() {
  let count = 0; // приватная переменная

  return function() {
    count++;
    return count;
  };
}

const counter1 = createCounter();
counter1(); // 1
counter1(); // 2

const counter2 = createCounter();
counter2(); // 1 (свой независимый count)
```

**Замыкание** — функция запоминает окружение, в котором была создана.

## Callback-функции (функции обратного вызова)

Функция, переданная другой функции как аргумент:

```javascript
function processUser(name, callback) {
  const user = { name, id: Date.now() };
  callback(user); // вызываем переданную функцию
}

processUser('Alex', (user) => {
  console.log('Пользователь создан:', user);
});

// Массивные методы с коллбеками
[1, 2, 3].forEach((num, i) => console.log(i, num));
```

## Рекурсия

Функция, вызывающая сама себя:

```javascript
// Факториал
function factorial(n) {
  if (n <= 1) return 1; // базовый случай
  return n * factorial(n - 1); // рекурсивный шаг
}

factorial(5); // 120

// Обход дерева (файловая система, DOM, JSON)
function printTree(node, indent = '') {
  console.log(indent + node.name);
  if (node.children) {
    for (const child of node.children) {
      printTree(child, indent + '  ');
    }
  }
}
```

**Осторожно:** глубокая рекурсия → `RangeError: Maximum call stack size exceeded`. Для больших данных используйте итерацию.

## Методы объекта и this

```javascript
const user = {
  name: 'Alex',

  // Обычная функция — this = объект
  sayHi() {
    return `Привет, я ${this.name}`;
  },

  // Стрелочная — this из внешней области (здесь — window/global)
  sayHiArrow: () => `Привет, я ${this.name}`,
};

user.sayHi();        // 'Привет, я Alex'
user.sayHiArrow();   // 'Привет, я undefined' (или имя глобального объекта)
```

**Потеря контекста:**
```javascript
const sayHi = user.sayHi;
sayHi(); // 'Привет, я undefined' — this потерян!

// Решение: bind / call / apply
const bound = user.sayHi.bind(user);
bound(); // 'Привет, я Alex'

user.sayHi.call({ name: 'Guest' }); // 'Привет, я Guest'
```

## IIFE (Immediately Invoked Function Expression)

Сразу вызываемая функция — для изоляции области видимости:

```javascript
// Старый способ (var)
(function() {
  var temp = 'не загрязняет глобал';
})();

// Современный (блок + let/const)
{
  const temp = 'тоже не загрязняет';
}

// IIFE с параметрами
const result = (function(a, b) {
  return a + b;
})(2, 3); // 5
```

## Типичные ошибки

| Ошибка | Неправильно | Правильно | Пояснение |
|--------|-------------|-----------|-----------|
| Потеря `this` | `const fn = obj.method; fn()` | `const fn = obj.method.bind(obj)` | `this` теряется при передаче функции |
| Стрелочная как метод | `obj = { m: () => this }` | `obj = { m() { return this } }` | У стрелочных нет своего `this` |
| Забытый `return` | `const fn = (x) => { x * 2 }` | `const fn = (x) => x * 2` или `{ return x * 2 }` | `{}` требует явного `return` |
| Мутация аргументов | `function f(arr) { arr.push(1) }` | `function f(arr) { return [...arr, 1] }` | Лучше не мутировать входные данные |
| Рекурсия без базы | `function f(n) { return f(n-1) }` | `function f(n) { if(n<=0) return 0; return f(n-1) }` | Всегда нужен базовый случай |
