## 1. ES Modules (ESM) — нативные модули

### Базовый синтаксис
```javascript
// math.js — именованные экспорты
export function add(a, b) { return a + b; }
export function sub(a, b) { return a - b; }
export const PI = 3.14159;

// default экспорт (один на файл)
export default function multiply(a, b) { return a * b; }

// Экспорт списком
function div(a, b) { return a / b; }
function mod(a, b) { return a % b; }
export { div, mod };

// Реэкспорт (переэкспорт)
export { add, sub } from "./math.js";
export { default as multiply } from "./multiply.js";
export * from "./constants.js"; // все именованные
```

### Импорт
```javascript
// Именованные
import { add, sub, PI } from "./math.js";
import { add as addNumbers } from "./math.js"; // алиас

// Default
import multiply from "./multiply.js"; // любое имя
import { default as mul } from "./multiply.js";

// Комбинированный
import multiply, { add, PI } from "./math.js";

// Namespace import (все именованные в объекте)
import * as Math from "./math.js";
Math.add(1, 2);

// Динамический импорт (Promise-based, работает везде)
const module = await import("./math.js");
module.add(1, 2);

// Условный/ленивый импорт
if (condition) {
  const { heavy } = await import("./heavy.js");
}
```

### ESM в браузере
```html
<script type="module" src="./main.js"></script>
<!-- Или inline -->
<script type="module">
  import { add } from "./math.js";
  console.log(add(1, 2));
</script>

<!-- nomodule — фоллбек для старых браузеров -->
<script nomodule src="./legacy-bundle.js"></script>
```

### Особенности ESM
```javascript
// 1. Всегда strict mode
// 2. Топ-уровневый await (ES2022)
const data = await fetch("/api/data").then(r => r.json());

// 3. import.meta — метаданные модуля
console.log(import.meta.url);     // полный URL модуля
console.log(import.meta.resolve); // функция resolve (предложение)
import.meta.env;                  // Vite/инструменты инжектят env

// 4. Циклические зависимости — работают (live bindings)
```

## 2. CommonJS (CJS) — Node.js legacy

### Синтаксис
```javascript
// math.cjs
function add(a, b) { return a + b; }
module.exports = { add }; // или exports.add = add;

// main.cjs
const { add } = require("./math.cjs");
const math = require("./math.cjs"); // { add }

// Динамический require
const mod = require(`./lang/${lang}.cjs`);
```

### ESM ↔ CJS Interop
```javascript
// ESM импортирует CJS
import pkg from "lodash"; // default = module.exports
import { debounce } from "lodash"; // именованные из свойств default

// CJS импортирует ESM (только динамически!)
const esm = await import("./esm-module.js"); // Promise
// require("./esm-module.js") — ОШИБКА!

// package.json: "type": "module" — весь проект ESM
// Файлы .mjs = ESM, .cjs = CJS (явное расширение)
```

### package.json: exports / imports (современный)
```json
{
  "name": "my-lib",
  "type": "module",
  "exports": {
    ".": {
      "import": "./dist/index.js",
      "require": "./dist/index.cjs",
      "types": "./dist/index.d.ts"
    },
    "./utils": "./dist/utils.js"
  },
  "imports": {
    "#internal/*": "./src/internal/*"
  }
}
```

## 3. npm — управление пакетами

### package.json ключевые поля
```json
{
  "name": "my-app",
  "version": "1.0.0",
  "type": "module",
  "main": "./dist/index.cjs",
  "module": "./dist/index.js",
  "exports": { ".": "./dist/index.js" },
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview",
    "test": "vitest",
    "lint": "eslint .",
    "format": "prettier --write ."
  },
  "dependencies": {
    "lodash": "^4.17.21",
    "zod": "^3.22.0"
  },
  "devDependencies": {
    "vite": "^5.0.0",
    "vitest": "^1.0.0",
    "eslint": "^8.56.0",
    "prettier": "^3.2.0",
    "typescript": "^5.3.0"
  },
  "engines": { "node": ">=18" },
  "packageManager": "pnpm@9.0.0"
}
```

### Версионирование (SemVer)
```
^1.2.3  — совместимые (>=1.2.3 <2.0.0)
~1.2.3  — только патчи (>=1.2.3 <1.3.0)
1.2.3   — точно версия
*       — любая
```

### Workspaces (монорепо)
```json
{
  "name": "my-monorepo",
  "private": true,
  "workspaces": [
    "packages/*",
    "apps/*"
  ],
  "scripts": {
    "build": "turbo run build",
    "test": "turbo run test"
  }
}
```

## 4. Структура проекта (best practices)

### Рекомендуемая структура (Vite/React/Vue/Svelte)
```
my-app/
├── public/              # Статические ассеты (копируются как есть)
│   └── favicon.ico
├── src/
│   ├── assets/          # Импортируемые ассеты (CSS, изображения)
│   ├── components/      # UI компоненты
│   ├── features/        # Feature-based модули (domain logic)
│   │   └── auth/
│   │       ├── api.js
│   │       ├── components/
│   │       ├── hooks/
│   │       └── index.js
│   ├── lib/             # Утилиты, хелперы, конфиги
│   ├── hooks/           # Общие хуки
│   ├── styles/          # Глобальные стили, переменные
│   ├── App.jsx
│   ├── main.jsx         # Entry point
│   └── vite-env.d.ts    # Типы для import.meta.env
├── tests/               # Интеграционные/E2E тесты
├── .eslintrc.cjs
├── .prettierrc
├── tsconfig.json
├── vite.config.ts
├── package.json
└── README.md
```

### Библиотека (npm package)
```
my-lib/
├── src/
│   ├── index.ts         # Public API entry
│   ├── utils/
│   └── types.ts
├── dist/                # Билд (gitignored, публикуется)
├── tests/
├── package.json         # "exports", "types"
├── tsconfig.json
├── rollup.config.js / vite.config.ts
└── README.md
```

## 5. Бандлеры: Vite, esbuild, Rollup, Webpack

### Vite (современный стандарт для приложений)
```typescript
// vite.config.ts
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import path from "path";

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: { "@": path.resolve(__dirname, "./src") }
  },
  build: {
    target: "es2022",
    minify: "esbuild", // или "terser"
    sourcemap: true,
    rollupOptions: {
      output: {
        manualChunks: { vendor: ["react", "react-dom"] }
      }
    }
  },
  server: { port: 3000, proxy: { "/api": "http://localhost:4000" } }
});
```

### Rollup (для библиотек)
```javascript
// rollup.config.js
import resolve from "@rollup/plugin-node-resolve";
import commonjs from "@rollup/plugin-commonjs";
import typescript from "@rollup/plugin-typescript";
import dts from "rollup-plugin-dts";
import { readFileSync } from "fs";

const pkg = JSON.parse(readFileSync("package.json", "utf-8"));

export default [
  // ES + CJS builds
  {
    input: "src/index.ts",
    output: [
      { file: pkg.module, format: "es", sourcemap: true },
      { file: pkg.main, format: "cjs", sourcemap: true }
    ],
    plugins: [resolve(), commonjs(), typescript()],
    external: [...Object.keys(pkg.dependencies || {}), ...Object.keys(pkg.peerDependencies || {})]
  },
  // .d.ts
  {
    input: "dist/index.d.ts",
    output: [{ file: "dist/index.d.ts", format: "es" }],
    plugins: [dts()]
  }
];
```

### esbuild (максимальная скорость)
```bash
# CLI
esbuild src/index.ts --bundle --outfile=dist/index.js --format=esm --platform=node --target=node18 --external:lodash

# JS API
await require("esbuild").build({
  entryPoints: ["src/index.ts"],
  bundle: true,
  outfile: "dist/index.js",
  format: "esm",
  platform: "node",
  target: "node18",
  external: ["lodash"]
});
```

### Webpack (legacy / complex configs)
```javascript
// webpack.config.js — только если нужен Module Federation, сложные оптимизации
module.exports = {
  entry: "./src/index.ts",
  module: { rules: [{ test: /\.ts$/, use: "ts-loader" }] },
  resolve: { extensions: [".ts", ".js"] },
  optimization: { usedExports: true }
};
```

## Практические задания

1. **Создайте библиотеку**: `npm init`, настройте `package.json` с `exports`, напишите утилиты, соберите Rollup'ом в ESM+CJS+types, опубликуйте в npm (или локально `npm pack`).

2. **Монorepo**: Настройте pnpm workspaces с `packages/ui`, `packages/utils`, `apps/web`. Настройте Turbo для кэширования билдов.

3. **Vite плагин**: Напишите простой Vite плагин, который заменяет `__BUILD_TIME__` на текущую дату при билде.

4. **Динамические импорты**: Реализуйте code-splitting роутинга — ленивая загрузка страниц через `import("./pages/About.jsx")`.

5. **ESM в Node.js**: Напишите CLI утилиту на ESM с `#!/usr/bin/env node`, использующую `commander`, `chalk`, `ora`.

## Типичные ошибки

| Ошибка | Правильно |
|--------|-----------|
| `import "lodash"` в CJS файле | `const _ = require("lodash")` или переименуйте в `.mjs` / `"type": "module"` |
| `require("esm-module")` | Только `await import("esm-module")` |
| Циклические импорты ломают код | ESM поддерживает live bindings — рефакторьте архитектуру |
| `package.json` без `"exports"` — утечка внутренних файлов | Всегда объявляйте `exports` для публичного API |
| Бандлер включает `node_modules` в бандл библиотеки | `external: [...Object.keys(pkg.dependencies)]` |
