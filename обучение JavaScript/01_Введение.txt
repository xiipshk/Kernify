# Урок 1: Введение в JavaScript

## Что такое JavaScript?

JavaScript — это язык программирования, который изначально создавался для оживления веб-страниц в браузере. Сегодня он работает везде: в браузерах, на серверах (Node.js), в мобильных приложениях и даже в микроконтроллерах.

**Ключевые особенности:**
- Интерпретируемый язык (не требует компиляции)
- Динамическая типизация
- Поддерживает несколько парадигм: императивную, объектно-ориентированную, функциональную
- Автоматическое управление памятью (сборка мусора)

## Консоль браузера — ваша первая среда разработки

Самый быстрый способ начать — открыть консоль разработчика:

| Браузер | Горячие клавиши |
|---------|----------------|
| Chrome / Edge / Opera | `F12` или `Ctrl+Shift+J` (Win/Linux), `Cmd+Option+J` (Mac) |
| Firefox | `F12` или `Ctrl+Shift+K` (Win/Linux), `Cmd+Option+K` (Mac) |
| Safari | `Cmd+Option+C` (нужно включить меню Develop) |

Во вкладке **Console** вы можете писать код и сразу видеть результат.

```javascript
console.log('Привет, JavaScript!');
// Вывод: Привет, JavaScript!
```

> **Совет:** `console.log()` — главная функция для вывода отладочной информации. Используйте её постоянно.

## Подключение JavaScript к HTML

Есть три способа подключить скрипт:

### 1. Встроенный скрипт (inline)
```html
<button onclick="alert('Клик!')">Нажми меня</button>
```
❌ **Не рекомендуется** — смешивает логику и разметку.

### 2. Внутренний скрипт (internal)
```html
<script>
  console.log('Код внутри HTML');
</script>
```
Подходит для быстрых тестов, но не для продакшена.

### 3. Внешний файл (external) — **Рекомендуемый способ**
```html
<!-- В <head> с defer (выполнится после парсинга HTML) -->
<script src="app.js" defer></script>

<!-- Или в конце <body> (старая школа) -->
<script src="app.js"></script>
```

**Почему `defer`?**
- Скрипт загружается параллельно с HTML
- Выполняется после построения DOM
- Сохраняет порядок выполнения нескольких скриптов

## Первая программа

Создайте файл `app.js`:

```javascript
// app.js — моя первая программа

// 1. Вывод в консоль
console.log('🚀 JavaScript запущен!');

// 2. Работа с DOM (Document Object Model)
document.addEventListener('DOMContentLoaded', () => {
  const heading = document.createElement('h1');
  heading.textContent = 'Привет из JavaScript!';
  heading.style.color = '#2c3e50';
  document.body.appendChild(heading);
});

// 3. Простое взаимодействие
function sayHello(name) {
  return `Привет, ${name}! 👋`;
}

console.log(sayHello('Мир'));
```

Создайте `index.html`:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Урок 1: Первая программа</title>
  <script src="app.js" defer></script>
</head>
<body>
  <p>Откройте консоль (F12), чтобы увидеть вывод.</p>
</body>
</html>
```

Откройте `index.html` в браузере → F12 → вкладка Console.

## Комментарии

```javascript
// Однострочный комментарий

/*
  Многострочный комментарий
  Может занимать несколько строк
  Полезно для документирования функций
*/

/**
 * JSDoc-комментарий — для генерации документации
 * @param {string} name - Имя пользователя
 * @returns {string} Приветствие
 */
function greet(name) {
  return `Hello, ${name}!`;
}
```

## Строгий режим ("use strict")

Современный JavaScript работает в строгом режиме по умолчанию в модулях (ESM), но в обычных скриптах его нужно включать:

```javascript
'use strict';

// Теперь это вызовет ошибку:
// x = 10; // ReferenceError: x is not defined

// Правильно:
let x = 10;
```

**Что даёт строгий режим:**
- Запрещает неявные глобальные переменные
- Запрещает дублирование параметров функций
- Делает `this` равным `undefined` в функциях (не window)
- Запрещает октальные литералы в старом виде (`010`)

## Современный стандарт: ES2023+

JavaScript развивается ежегодно (ES2015, ES2016... ES2023+). Основные современные возможности:

| Год | Ключевые фичи |
|-----|---------------|
| ES2015 (ES6) | `let`, `const`, стрелочные функции, классы, промисы, модули |
| ES2017 | `async/await` |
| ES2020 | Nullish coalescing (`??`), optional chaining (`?.`) |
| ES2021 | `replaceAll`, `Promise.any` |
| ES2022 | Приватные поля классов (`#field`), `at()` |
| **ES2023** | `findLast`, `findLastIndex`, `toSorted`, `toReversed`, `toSpliced`, `with()` |
| **ES2024** | `Object.groupBy`, `Map.groupBy`, `Promise.withResolvers` |

В уроках мы будем использовать современный синтаксис (ES2023+).
