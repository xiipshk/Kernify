## 1. Node.js Runtime Architecture

### Компоненты
```
┌─────────────────────────────────────────────────────────────┐
│                      Node.js Process                         │
│  ┌──────────────┐    ┌──────────────────────────────────┐   │
│  │   V8 Engine  │    │           libuv                  │   │
│  │  (JS Heap)   │    │  ┌──────────┐ ┌──────────────┐   │   │
│  │  Call Stack  │    │  │ Timer    │ │ I/O (poll)   │   │   │
│  └──────────────┘    │  │ Queue    │ │ (network, fs)│   │   │
│         │            │  └──────────┘ └──────────────┘   │   │
│         ▼            │  ┌──────────┐ ┌──────────────┐   │   │
│  ┌──────────────┐    │  │ Check    │ │ Close        │   │   │
│  │ Microtask    │    │  │ Queue    │ │ Callbacks    │   │   │
│  │ Queue        │    │  └──────────┘ └──────────────┘   │   │
│  └──────────────┘    └──────────────────────────────────┘   │
│         │                    │                               │
│         └────────────────────┼───────────────────────────────┘
│                              ▼
│                     ┌──────────────┐
│                     │  Event Loop  │
│                     └──────────────┘
└─────────────────────────────────────────────────────────────┘
```

## 2. Modules — ESM и CommonJS

### ESM (рекомендуется)
```javascript

// Default экспорт

// Реэкспорт
```

## 3. Filesystem — fs/promises, Streams, Watchers

### fs/promises (async/await)
```javascript
import * as fs from "fs/promises";
import * as path from "path";

// Чтение/запись
const content = await fs.readFile("file.txt", "utf-8");
await fs.writeFile("file.txt", "Hello", "utf-8");
await fs.appendFile("log.txt", "\nNew line");

// JSON
const pkg = await fs.readFile("package.json", "utf-8").then(JSON.parse);
await fs.writeFile("config.json", JSON.stringify(config, null, 2));

// Директории
await fs.mkdir("dir/subdir", { recursive: true });
const entries = await fs.readdir("dir", { withFileTypes: true });
for (const entry of entries) {
  console.log(entry.name, entry.isDirectory(), entry.isFile());
}

// Статус
const stats = await fs.stat("file.txt");
stats.isFile();        // true
stats.isDirectory();   // false
stats.size;            // байты
stats.mtime;           // Date модификации

// Существование
await fs.access("file.txt", fs.constants.R_OK | fs.constants.W_OK);
// или
try { await fs.stat("file.txt"); exists = true; } catch { exists = false; }

// Удаление/перемещение
await fs.rm("file.txt");
await fs.rm("dir", { recursive: true, force: true });
await fs.rename("old.txt", "new.txt");
await fs.copyFile("src.txt", "dest.txt");

// Симлинки
await fs.symlink("target", "link");
await fs.readlink("link"); // "target"
await fs.unlink("link");

// Временные файлы
import { tmpdir } from "os";
import { mkdtemp, writeFile } from "fs/promises";
const tempDir = await mkdtemp(path.join(tmpdir(), "myapp-"));
await writeFile(path.join(tempDir, "data.json"), "{}");
```

### Streams — для больших файлов
```javascript
import { createReadStream, createWriteStream } from "fs";
import { pipeline } from "stream/promises";
import { createGzip } from "zlib";
import { createCipheriv } from "crypto";

// Копирование больших файлов (backpressure handled)
await pipeline(
  createReadStream("input.txt"),
  createWriteStream("output.txt")
);

// Сжатие на лету
await pipeline(
  createReadStream("huge.log"),
  createGzip(),
  createWriteStream("huge.log.gz")
);

// Шифрование
const key = crypto.randomBytes(32);
const iv = crypto.randomBytes(16);
await pipeline(
  createReadStream("secret.txt"),
  createCipheriv("aes-256-gcm", key, iv),
  createWriteStream("secret.enc")
);

// Readable stream как async iterator
for await (const chunk of createReadStream("file.txt", { highWaterMark: 64 * 1024 })) {
  // chunk — Buffer
  processChunk(chunk);
}

// Object mode streams
import { Readable } from "stream";
const readable = Readable.from([1, 2, 3, 4, 5], { objectMode: true });
for await (const item of readable) {
  console.log(item);
}
```

### File Watchers
```javascript
import { watch, watchFile } from "fs";

// watch — событийный (лучше для директорий)
const watcher = watch("src", { recursive: true }, (eventType, filename) => {
  console.log(eventType, filename); // "rename", "change"
});
watcher.close(); // остановка

// watchFile — polling (fallback)
watchFile("config.json", { interval: 1000 }, (curr, prev) => {
  if (curr.mtime !== prev.mtime) reloadConfig();
});
unwatchFile("config.json");

// chokidar — production выбор (батчерит события)
import chokidar from "chokidar";
const watcher = chokidar.watch("src/**/*.js", {
  ignored: /node_modules/,
  persistent: true,
  ignoreInitial: true
});
watcher.on("change", path => console.log("Changed:", path));
watcher.on("add", path => console.log("Added:", path));
watcher.on("unlink", path => console.log("Removed:", path));
await watcher.close();
```

## 4. HTTP Server — Native, Express, Fastify

### Native http модуль
```javascript
import { createServer } from "http";
import { parse } from "url";
import { readFile } from "fs/promises";
import { join, extname } from "path";

const server = createServer(async (req, res) => {
  // Парсинг URL
  const { pathname, query } = parse(req.url, true);

  // CORS
  res.setHeader("Access-Control-Allow-Origin", "*");
  res.setHeader("Access-Control-Allow-Methods", "GET,POST,OPTIONS");
  res.setHeader("Access-Control-Allow-Headers", "Content-Type");

  if (req.method === "OPTIONS") {
    res.writeHead(204);
    return res.end();
  }

  // Routing
  if (pathname === "/api/users" && req.method === "GET") {
    const users = await getUsers();
    res.setHeader("Content-Type", "application/json");
    return res.end(JSON.stringify(users));
  }

  if (pathname === "/api/users" && req.method === "POST") {
    let body = "";
    for await (const chunk of req) body += chunk;
    const user = JSON.parse(body);
    const created = await createUser(user);
    res.writeHead(201, { "Content-Type": "application/json" });
    return res.end(JSON.stringify(created));
  }

  // Static files
  if (pathname.startsWith("/static/")) {
    try {
      const filePath = join(process.cwd(), "public", pathname.slice(8));
      const content = await readFile(filePath);
      const mime = getMimeType(extname(filePath));
      res.setHeader("Content-Type", mime);
      return res.end(content);
    } catch {
      res.writeHead(404);
      return res.end("Not Found");
    }
  }

  res.writeHead(404);
  res.end("Not Found");
});

server.listen(3000, () => console.log("Server on :3000"));

// Graceful shutdown
const shutdown = () => {
  server.close(() => {
    console.log("Closed");
    process.exit(0);
  });
  setTimeout(() => process.exit(1), 10000); // force
};
process.on("SIGTERM", shutdown);
process.on("SIGINT", shutdown);
```

### Express (популярный фреймворк)

```javascript
import express from "express";
import cors from "cors";
import helmet from "helmet";
import morgan from "morgan";
import rateLimit from "express-rate-limit";

const app = express();

// Middleware
app.use(helmet());           // security headers
app.use(cors());             // CORS
app.use(express.json());     // JSON body parser
app.use(express.urlencoded({ extended: true }));
app.use(morgan("combined")); // logging
app.use(rateLimit({ windowMs: 15 * 60 * 1000, max: 100 })); // rate limit

// Routes
app.get("/api/health", (req, res) => {
  res.json({ status: "ok", timestamp: new Date().toISOString() });
});

app.get("/api/users", async (req, res, next) => {
  try {
    const users = await getUsers(req.query);
    res.json(users);
  } catch (err) {
    next(err); // передача в error handler
  }
});

app.post("/api/users", async (req, res, next) => {
  try {
    const user = await createUser(req.body);
    res.status(201).json(user);
  } catch (err) {
    next(err);
  }
});

// Параметры маршрута
app.get("/api/users/:id", async (req, res, next) => {
  try {
    const user = await getUserById(req.params.id);
    if (!user) return res.status(404).json({ error: "Not found" });
    res.json(user);
  } catch (err) {
    next(err);
  }
});

// Error handler (4 аргумента!)
app.use((err, req, res, next) => {
  console.error(err);
  const status = err.statusCode || 500;
  res.status(status).json({
    error: err.message,
    ...(process.env.NODE_ENV === "development" && { stack: err.stack })
  });
});

// 404 handler
app.use((req, res) => {
  res.status(404).json({ error: "Not found" });
});

const server = app.listen(3000, () => console.log("Express on :3000"));
```

## 6. Processes — Child Process, Worker Threads, Clustering

### child_process
```javascript
import { spawn, execFile, fork } from "child_process";
import { promisify } from "util";

// spawn — потоковый, для длинных процессов
const child = spawn("ffmpeg", ["-i", "input.mp4", "output.mp4"]);
child.stdout.on("data", data => console.log(data.toString()));
child.stderr.on("data", data => console.error(data.toString()));
child.on("close", code => console.log(`Exited: ${code}`));

// execFile — буферизированный, для коротких
const { stdout, stderr } = await promisify(execFile)("git", ["status", "--porcelain"]);

// fork — отдельный Node.js процесс (IPC)
const worker = fork("./worker.js", ["arg1"], {
  env: { ...process.env, WORKER_ID: "1" },
  stdio: ["pipe", "pipe", "pipe", "ipc"] // 4-й канал для IPC
});
worker.send({ type: "task", data: [1, 2, 3] });
worker.on("message", (msg) => console.log("Result:", msg));

// В worker.js
process.on("message", (msg) => {
  if (msg.type === "task") {
    const result = msg.data.reduce((a, b) => a + b, 0);
    process.send({ type: "result", value: result });
  }
});
```

### Worker Threads (CPU-intensive задачи)
```bash
npm install node:worker_threads (built-in Node 12+)
```

```javascript
// main.js
import { Worker, isMainThread, parentPort, workerData } from "worker_threads";
import { resolve } from "path";

if (isMainThread) {
  const worker = new Worker(resolve("./worker.js"), {
    workerData: { iterations: 1000000 }
  });

  worker.on("message", (result) => {
    console.log("Result:", result);
  });
  worker.on("error", (err) => console.error(err));
  worker.on("exit", (code) => {
    if (code !== 0) console.error(`Worker stopped with code ${code}`);
  });
} else {
  // worker.js код
  const { iterations } = workerData;
  let sum = 0;
  for (let i = 0; i < iterations; i++) sum += Math.sqrt(i);
  parentPort.postMessage(sum);
}
```

### Clustering (multi-core)
```javascript
// cluster.js
import cluster from "cluster";
import { cpus } from "os";
import { createServer } from "http";

if (cluster.isPrimary) {
  const numCPUs = cpus().length;
  console.log(`Primary ${process.pid} forking ${numCPUs} workers`);

  for (let i = 0; i < numCPUs; i++) {
    cluster.fork();
  }

  cluster.on("exit", (worker, code, signal) => {
    console.log(`Worker ${worker.process.pid} died (${signal || code}). Restarting...`);
    cluster.fork();
  });
} else {
  // Worker процесс — ваш сервер
  const server = createServer((req, res) => {
    res.writeHead(200);
    res.end(`Hello from worker ${process.pid}`);
  });
  server.listen(3000);
}
```

## Практические задания

1. **CLI Tool**: Напишите CLI на ESM с `commander`: команды `init`, `build`, `deploy`, `--watch` флаг. Используйте `chalk` для цветов, `ora` для спиннеров, `inquirer` для промптов.

2. **File Watcher Service**: Сервис, который следит за директорией `uploads/`, при появлении нового файла — обрабатывает (resize картинки через `sharp`, конвертирует видео через `ffmpeg`), кладёт результат в `processed/`, пишет метаданные в SQLite.

3. **REST API с Express/Fastify**: CRUD для сущности `Task` (title, description, status, dueDate). Валидация через `zod`, пагинация, фильтрация, сортировка. Swagger/OpenAPI документация.

4. **Worker Pool**: Класс `WorkerPool` с методами `exec(fn, args)` — выполняет функцию в воркере, возвращает Promise. Лимит воркеров, очередь задач, graceful shutdown.

5. **Config Loader**: Модуль `loadConfig()` — читает `.env`, `.env.local`, `.env.${NODE_ENV}`, валидирует через `zod`, поддерживает секреты из файлов (`_FILE` суффикс: `JWT_SECRET_FILE=/run/secrets/jwt`), кэширует результат.

6. **Graceful Shutdown**: Класс `Lifecycle` — регистрирует `onShutdown(fn)`, обрабатывает `SIGTERM`/`SIGINT`, ждёт завершения всех async задач с таймаутом, логирует зависшие.

## Типичные ошибки

| Ошибка | Правильно |
|--------|-----------|
| `require("esm-module")` в CJS | Только `await import("esm-module")` |
| `__dirname` в ESM | `import { dirname } from "path"; import { fileURLToPath } from "url"; const __dirname = dirname(fileURLToPath(import.meta.url))` |
| `fs.readFile` без `await` / не промис | Используйте `fs/promises` или `promisify` |
| Большие файлы в память (`readFile`) | Используйте `createReadStream` + `pipeline` |
| `process.on("uncaughtException")` в проде | Не перехватывайте — падайте и рестартуйте (PM2, systemd) |
| `child_process.exec` с пользовательским вводом | `execFile` / `spawn` с массивом аргументов (no shell injection) |
| Воркеры для I/O задач | Worker Threads — для CPU-bound, для I/O — async/await |
| Кластеризация без sticky sessions для WebSocket | Используйте Redis adapter или отдельный WS сервер |
| Хардкод конфига в коде | Только через `process.env` + валидация (zod) |
| `.env` в git | `.env` в `.gitignore`, `.env.example` в репо |
