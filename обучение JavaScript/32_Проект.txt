## Требования

### Функционал (MVP)
1. **Документы**: Rich-text редактор (TipTap/ProseMirror/Slate) с коллаборативным редактированием
2. **Real-time**: Несколько пользователей одновременно редактируют, видят курсоры друг друга
3. **История**: Time-travel (undo/redo на уровне документа), версионирование
4. **Комментарии**: Потоки комментариев, упоминания (@user), разрешение
5. **Права доступа**: Owner/Editor/Commenter/Viewer, приглашения по ссылке
6. **Офлайн**: Полная работа офлайн, синхронизация при онлайне (CRDT)
7. **Экспорт**: PDF, Markdown, HTML, DOCX

### Архитектурные требования
- **Monorepo** (Nx / Turborepo): apps/api, apps/web, packages/shared, packages/editor, packages/sync
- **Backend**: Node.js (Fastify/NestJS) + TypeScript, PostgreSQL + Redis
- **Real-time**: WebSocket (ws / Socket.io) + Horizontal scaling (Redis Pub/Sub)
- **Sync Engine**: Yjs (CRDT) или Automerge / custom OT
- **Database**: Event Store (EventStoreDB) или PostgreSQL + event sourcing
- **Auth**: JWT + Refresh tokens, OAuth2 (Google/GitHub), 2FA (TOTP)
- **API**: tRPC (end-to-end types) + REST для вебхуков
- **Frontend**: React 18 + Vite, TanStack Query, Zustand/Jotai, TailwindCSS
- **Testing**: Vitest (unit), Playwright (e2e), Contract tests (Pact)
- **Observability**: OpenTelemetry, Prometheus, Grafana, Sentry
- **CI/CD**: GitHub Actions → Docker → Kubernetes (kind локально, GKE/EKS в проде)

### 1. Sync Engine (packages/sync) — Yjs + WebRTC/WebSocket

```typescript
// packages/sync/src/yjs-provider.ts
import * as Y from 'yjs';
import { WebsocketProvider } from 'y-websocket';
import { IndexeddbPersistence } from 'y-indexeddb';

export class CollaborativeDoc {
  private doc: Y.Doc;
  private provider: WebsocketProvider;
  private persistence: IndexeddbPersistence;
  private awareness: any;

  constructor(
    private docId: string,
    private user: { id: string; name: string; color: string },
    private wsUrl: string
  ) {
    this.doc = new Y.Doc({ guid: docId });
    this.setupPersistence();
    this.setupProvider();
    this.setupAwareness();
  }

  private setupPersistence() {
    this.persistence = new IndexeddbPersistence(this.docId, this.doc);
    this.persistence.on('synced', () => {
      console.log('Local DB synced');
    });
  }

  private setupProvider() {
    this.provider = new WebsocketProvider(this.wsUrl, this.docId, this.doc, {
      connect: true,
      awareness: this.awareness
    });

    this.provider.on('status', (event: { status: string }) => {
      console.log('Connection status:', event.status);
    });

    this.provider.on('sync', (isSynced: boolean) => {
      if (isSynced) this.flushPendingOperations();
    });
  }

  private setupAwareness() {
    this.awareness = this.provider.awareness;
    this.awareness.setLocalStateField('user', {
      id: this.user.id,
      name: this.user.name,
      color: this.user.color,
      cursor: null,
      selection: null
    });

    this.awareness.on('change', () => {
      // Обновление UI курсоров других пользователей
      const states = Array.from(this.awareness.getStates().values());
      this.onAwarenessChange?.(states.filter(s => s.user?.id !== this.user.id));
    });
  }

  // Rich-text binding (TipTap/ProseMirror)
  bindToEditor(editor: any) {
    const yText = this.doc.getText('content');
    // y-prosemirror или y-tiptap binding
  }

  // Офлайн очередь операций
  private pendingOps: Uint8Array[] = [];

  applyLocalUpdate(update: Uint8Array) {
    if (this.provider.wsconnected) {
      this.provider.send(update);
    } else {
      this.pendingOps.push(update);
    }
  }

  private flushPendingOperations() {
    this.pendingOps.forEach(op => this.provider.send(op));
    this.pendingOps = [];
  }

  // Снимок для экспорта/истории
  getSnapshot(): Uint8Array {
    return Y.encodeStateAsUpdate(this.doc);
  }

  destroy() {
    this.provider.destroy();
    this.persistence.destroy();
    this.doc.destroy();
  }

  onAwarenessChange?: (users: any[]) => void;
}
```

### 2. Document Service (apps/api/src/modules/documents)

```typescript
// apps/api/src/modules/documents/document.aggregate.ts
import { AggregateRoot, EventHandler } from '@nestjs/cqrs';

export class Document extends AggregateRoot {
  private constructor(
    public readonly id: DocumentId,
    private _title: string,
    private _ownerId: UserId,
    private _collaborators: Collaborator[],
    private _yjsState: Uint8Array,
    private _version: number,
    private _status: DocumentStatus
  ) {
    super();
  }

  static create(cmd: CreateDocumentCommand): Document {
    const doc = new Document(
      DocumentId.generate(),
      cmd.title,
      cmd.ownerId,
      [{ userId: cmd.ownerId, role: 'owner' }],
      new Uint8Array(),
      0,
      'active'
    );
    doc.apply(new DocumentCreated(doc.id, cmd.title, cmd.ownerId));
    return doc;
  }

  updateTitle(title: string, userId: UserId) {
    this.assertCanEdit(userId);
    if (this._title !== title) {
      this._title = title;
      this.apply(new DocumentTitleChanged(this.id, title, userId));
    }
  }

  addCollaborator(userId: UserId, role: CollaboratorRole, actorId: UserId) {
    this.assertOwner(actorId);
    if (!this._collaborators.some(c => c.userId.equals(userId))) {
      this._collaborators.push({ userId, role });
      this.apply(new CollaboratorAdded(this.id, userId, role));
    }
  }

  updateYjsState(state: Uint8Array, version: number) {
    if (version !== this._version) {
      throw new ConcurrencyError(`Expected version ${this._version}, got ${version}`);
    }
    this._yjsState = state;
    this._version++;
    this.apply(new DocumentSynced(this.id, state, this._version));
  }

  // Event Handlers для проекций
  @EventHandler(DocumentCreated)
  onCreated(event: DocumentCreated) { /* read model update */ }

  @EventHandler(DocumentSynced)
  onSynced(event: DocumentSynced) { /* read model update */ }
}
```

### 3. Event Sourcing Infrastructure

```typescript
// packages/shared/src/event-store/event-store.ts
import { EventStoreDBClient, jsonEvent, START } from '@eventstore/db-client';

export class EventStore {
  constructor(private client: EventStoreDBClient) {}

  async appendToStream(
    streamId: string,
    events: DomainEvent[],
    expectedRevision: number | typeof START = START
  ) {
    const eventData = events.map(e => jsonEvent({
      type: e.constructor.name,
      data: e.serialize(),
      metadata: { causationId: e.causationId, correlationId: e.correlationId }
    }));
    await this.client.appendToStream(streamId, eventData, { expectedRevision });
  }

  async readStream(streamId: string) {
    const events = [];
    for await (const event of this.client.readStream(streamId, { fromRevision: START })) {
      events.push(this.deserialize(event.event));
    }
    return events;
  }

  async subscribeToAll(handler: (event: DomainEvent) => Promise<void>) {
    const subscription = this.client.subscribeToAll({
      fromPosition: { commitPosition: 0n, preparePosition: 0n },
      resolveLinkTos: true
    });
    for await (const event of subscription) {
      await handler(this.deserialize(event.event));
    }
  }
}
```

### 4. tRPC Router с типами

```typescript
// apps/api/src/trpc/router.ts
import { initTRPC, TRPCError } from '@trpc/server';
import { z } from 'zod';
import { DocumentService } from '../modules/documents/document.service';
import { SyncService } from '../modules/sync/sync.service';

const t = initTRPC.context<{ userId: string }>().create();

export const appRouter = t.router({
  documents: t.router({
    list: t.procedure
      .input(z.object({ cursor: z.string().optional(), limit: z.number().default(20) }))
      .query(async ({ ctx, input }) => {
        return documentService.listForUser(ctx.userId, input);
      }),

    create: t.procedure
      .input(z.object({ title: z.string().min(1).max(200) }))
      .mutation(async ({ ctx, input }) => {
        return documentService.create(ctx.userId, input.title);
      }),

    getById: t.procedure
      .input(z.object({ id: z.string().uuid() }))
      .query(async ({ ctx, input }) => {
        const doc = await documentService.getById(input.id);
        if (!doc.canAccess(ctx.userId)) throw new TRPCError({ code: 'FORBIDDEN' });
        return doc;
      }),

    updateTitle: t.procedure
      .input(z.object({ id: z.string().uuid(), title: z.string().min(1).max(200) }))
      .mutation(async ({ ctx, input }) => {
        await documentService.updateTitle(input.id, input.title, ctx.userId);
      }),

    invite: t.procedure
      .input(z.object({
        id: z.string().uuid(),
        email: z.string().email(),
        role: z.enum(['editor', 'commenter', 'viewer'])
      }))
      .mutation(async ({ ctx, input }) => {
        await documentService.invite(input.id, input.email, input.role, ctx.userId);
      })
  }),

  sync: t.router({
    getSnapshot: t.procedure
      .input(z.object({ docId: z.string().uuid() }))
      .query(async ({ input }) => {
        return syncService.getSnapshot(input.docId);
      }),

    // WebSocket connection info
    getConnectionInfo: t.procedure
      .input(z.object({ docId: z.string().uuid() }))
      .query(async ({ ctx, input }) => {
        return syncService.getConnectionInfo(input.docId, ctx.userId);
      })
  })
});

export type AppRouter = typeof appRouter;
```

### 5. Frontend Architecture (apps/web)

```typescript
// apps/web/src/features/documents/DocumentEditor.tsx
import { useEditor, EditorContent } from '@tiptap/react';
import Collaboration from '@tiptap/extension-collaboration';
import CollaborationCursors from '@tiptap/extension-collaboration-cursors';
import { useDocument } from '@/hooks/useDocument';
import { useSync } from '@/hooks/useSync';

export function DocumentEditor({ docId }: { docId: string }) {
  const { document, user } = useDocument(docId);
  const { provider, awareness } = useSync(docId, user);

  const editor = useEditor({
    extensions: [
      StarterKit,
      Collaboration.configure({ document: provider.doc }),
      CollaborationCursors.configure({ provider: provider.awareness })
    ],
    content: document.content,
    onUpdate: ({ editor }) => {
      // Автосохранение с дебаунсом
      debouncedSave(editor.getJSON());
    },
    editorProps: {
      attributes: { class: 'prose prose-lg max-w-none focus:outline-none' }
    }
  });

  // Рендер курсоров других пользователей
  const cursors = useAwarenessCursors(awareness);

  return (
    <div className="flex h-screen">
      <aside className="w-64 border-r p-4">
        <CollaboratorsList users={cursors} currentUser={user} />
        <CommentsPanel docId={docId} />
      </aside>
      <main className="flex-1 p-8 overflow-auto">
        <EditorContent editor={editor} />
        {cursors.map(cursor => (
          <RemoteCursor key={cursor.user.id} cursor={cursor} />
        ))}
      </main>
    </div>
  );
}
```

```typescript
  instrumentations: [
    new HttpInstrumentation(),
    new ExpressInstrumentation(),
    new PinoInstrumentation()
  ]
});

// Custom spans для бизнес-операций
import { trace, SpanStatusCode } from '@opentelemetry/api';

export async function traceOperation<T>(
  name: string,
  fn: (span: any) => Promise<T>,
  attributes?: Record<string, any>
): Promise<T> {
  return trace.getTracer('collab-platform').startActiveSpan(name, async span => {
    try {
      span.setAttributes(attributes || {});
      const result = await fn(span);
      span.setStatus({ code: SpanStatusCode.OK });
      return result;
    } catch (error) {
      span.setStatus({ code: SpanStatusCode.ERROR, message: error.message });
      span.recordException(error);
      throw error;
    } finally {
      span.end();
    }
  });
}
```

## Типичные ошибки

| Ошибка | Решение |
|--------|---------|
| WebSocket не переподключается | Exponential backoff + jitter, heartbeat ping/pong |
| CRDT память растёт бесконечно | Garbage collection (Yjs: `doc.gc()`), снапшоты |
| Race condition при сохранении | Optimistic locking (version), retry с backoff |
| Нет горизонтального масштабирования WS | Redis Pub/Sub + sticky sessions или connection routing |
| События теряются при рестарте | EventStoreDB persistent subscriptions, outbox pattern |
| Тесты флакают на WebSocket | Mock WS провайдер в unit, отдельный WS сервер в e2e |
