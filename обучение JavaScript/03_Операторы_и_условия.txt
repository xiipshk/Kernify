# Урок 3: Операторы и условия

## Арифметические операторы

```javascript
// Базовые
10 + 5;   // 15 (сложение)
10 - 5;   // 5 (вычитание)
10 * 5;   // 50 (умножение)
10 / 5;   // 2 (деление)
10 % 3;   // 1 (остаток от деления)
2 ** 3;   // 8 (возведение в степень, ES2016)

// Инкремент/декремент
let x = 5;
x++;      // 5 (постфикс: вернул старое, потом увеличил)
++x;      // 7 (префикс: увеличил, вернул новое)
x--;      // 7
--x;      // 5

// Сокращённое присваивание
let a = 10;
a += 5;   // a = a + 5 → 15
a -= 3;   // 12
a *= 2;   // 24
a /= 4;   // 6
a %= 4;   // 2
a **= 2;  // 4
```

### Особенности чисел
```javascript
0.1 + 0.2;           // 0.30000000000000004 (проблема IEEE 754)
// Решение: умножайте на 100, считайте, делите назад
Math.round((0.1 + 0.2) * 100) / 100; // 0.3

// Или используйте библиотеку (decimal.js) для финансов
```

## Операторы сравнения

```javascript
// Строгое равенство (РЕКОМЕНДУЕТСЯ)
5 === 5;       // true
5 === '5';     // false (разные типы)
null === undefined; // false

// Нестрогое равенство (ИСПОЛЬЗОВАТЬ ОСТОРОЖНО)
5 == '5';      // true (приведение типов!)
null == undefined;  // true (специальное правило)
0 == false;    // true
'' == false;   // true

// Нестрогое неравенство
5 != '5';      // false
null != undefined; // false

// Сравнение
10 > 5;    // true
10 >= 10;  // true
'b' > 'a'; // true (лексикографическое, по кодам символов)
'10' > '2'; // false! (строка '1' < '2')
```

**Правило:** Всегда используйте `===` и `!==`. `==` и `!=` ведут к неожиданным багам.

### Сравнение объектов
```javascript
{} === {};           // false (разные ссылки)
const a = {}; a === a; // true (та же ссылка)
[] === [];           // false

// Для сравнения содержимого — JSON.stringify или глубокое сравнение
JSON.stringify({a:1}) === JSON.stringify({a:1}); // true (но порядок ключей важен)
```

## Логические операторы

```javascript
// && (И) — возвращает первое falsy или последнее truthy
true && 'hello';    // 'hello'
'hello' && true;    // true
false && 'hello';   // false
0 && 'world';       // 0
'' && 'world';      // ''
null && 'world';    // null

// || (ИЛИ) — возвращает первое truthy или последнее falsy
false || 'hello';   // 'hello'
'hello' || 'world'; // 'hello' (первое truthy)
0 || 42;            // 42
'' || 'default';    // 'default'

// ! (НЕ) — всегда возвращает boolean
!true;      // false
!0;         // true
!!'hello';  // true (приведение к boolean)
```

### Короткое замыкание (Short-circuit evaluation)
```javascript
// && — если слева falsy, правое НЕ вычисляется
false && console.log('не выполнится'); // false
true && console.log('выполнится');     // выполняется

// || — если слева truthy, правое НЕ вычисляется
true || console.log('не выполнится');  // true
false || console.log('выполнится');    // выполняется

// Практический пример: значения по умолчанию
const name = userName ?? 'Гость';      // ES2020: только null/undefined
const nameOld = userName || 'Гость';   // старое: любое falsy
```

### Nullish coalescing (??) и Optional chaining (?.)

```javascript
// ?? — только для null/undefined (ES2020)
const a = null ?? 'default';      // 'default'
const b = 0 ?? 'default';         // 0 (не перезаписывает 0!)
const c = '' ?? 'default';        // '' (не перезаписывает пустую строку!)

// ?. — безопасный доступ к свойствам (ES2020)
const user = { profile: { name: 'Alex' } };
user.profile?.name;        // 'Alex'
user.address?.city;        // undefined (не ошибка!)
user?.profile?.name;       // 'Alex'
user?.missing?.deep?.value; // undefined

// ?. с вызовом функций
const obj = { method: () => 'hello' };
obj.method?.();            // 'hello'
obj.missing?.();           // undefined (не ошибка!)

// ??= и ||= и &&= (ES2021) — присваивание с проверкой
let x = null;
x ??= 10;  // x = 10
x ??= 20;  // x остаётся 10

let y = 'hello';
y ||= 'world'; // y остаётся 'hello'

let z = false;
z &&= true; // z остаётся false
```

## Условные конструкции

### if / else if / else
```javascript
const score = 85;

if (score >= 90) {
  console.log('Отлично! 🎉');
} else if (score >= 70) {
  console.log('Хорошо! 👍');
} else if (score >= 50) {
  console.log('Удовлетворительно');
} else {
  console.log('Нужно подтянуть 📚');
}

// Блоки {} обязательны для читаемости (в отличие от Python)
// Но для однострочников можно без скобок (не рекомендуется)
if (age >= 18) console.log('Совершеннолетний');
```

### Тернарный оператор (?:)
```javascript
const age = 20;
const status = age >= 18 ? 'взрослый' : 'подросток';
// Эквивалент:
let status;
if (age >= 18) {
  status = 'взрослый';
} else {
  status = 'подросток';
}

// Вложенные тернарные (читать сложно, избегайте)
const result = score > 90 ? 'A' : score > 80 ? 'B' : score > 70 ? 'C' : 'F';
```

### switch / case
```javascript
const day = 3;

switch (day) {
  case 1:
    console.log('Понедельник');
    break;
  case 2:
    console.log('Вторник');
    break;
  case 3:
  case 4:
  case 5:
    console.log('Рабочий день');
    break;
  case 6:
  case 7:
    console.log('Выходной');
    break;
  default:
    console.log('Неверный день');
}

// switch использует строгое сравнение (===)
switch ('5') {
  case 5:  console.log('number'); break;
  case '5': console.log('string'); break; // сработает этот
}

// ES2025 (предложение): switch как выражение (pattern matching)
// Пока используйте объект/Map для сопоставления
const messages = {
  success: 'Успех!',
  error: 'Ошибка!',
  loading: 'Загрузка...',
};
const msg = messages[status] ?? 'Неизвестный статус';
```

## Цикл while и do...while

```javascript
// while — проверка ДО выполнения
let i = 0;
while (i < 5) {
  console.log(i); // 0, 1, 2, 3, 4
  i++;
}

// do...while — проверка ПОСЛЕ (выполнится хотя бы раз)
let j = 0;
do {
  console.log(j); // 0
  j++;
} while (j < 0); // условие false, но тело выполнилось 1 раз

// Бесконечный цикл + break
while (true) {
  const input = prompt('Введите "exit" для выхода');
  if (input === 'exit') break;
  console.log('Вы ввели:', input);
}
```

## Оператор запятая (,)

```javascript
// Вычисляет все выражения, возвращает последний
let x = (1, 2, 3); // x = 3

// В циклах — множественная инициализация/обновление
for (let i = 0, j = 10; i <= j; i++, j--) {
  console.log(i, j);
}
```

## Побитовые операторы (для справки)

```javascript
// Работают с 32-битными целыми
5 & 3;   // 1 (AND)
5 | 3;   // 7 (OR)
5 ^ 3;   // 6 (XOR)
~5;      // -6 (NOT)
5 << 1;  // 10 (сдвиг влево)
5 >> 1;  // 2 (сдвиг вправо со знаком)
5 >>> 1; // 2 (сдвиг вправо без знака)

// Практические трюки
~~5.9;      // 5 (быстрый Math.floor для положительных)
5.9 | 0;    // 5 (тоже)
!!(5 & 1);  // true (проверка нечётности)
```
