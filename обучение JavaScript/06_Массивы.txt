## Что такое массив?

Массив — это упорядоченная коллекция значений. Каждому значению соответствует числовой индекс (начиная с 0).

```javascript
// Создание массива
const fruits = ['яблоко', 'банан', 'апельсин'];
const numbers = [1, 2, 3, 4, 5];
const mixed = [1, 'текст', true, null, { a: 1 }, [1, 2]];

// Доступ по индексу
fruits[0];    // 'яблоко'
fruits[1];    // 'банан'
fruits[99];   // undefined (индекса нет)

// Длина массива
fruits.length; // 3
```

## Создание массивов

```javascript
// Литерал (рекомендуется)
const arr = [1, 2, 3];

// Конструктор
const arr2 = new Array(1, 2, 3);
const arr3 = new Array(5);      // [empty × 5] — 5 пустых слотов!
const arr4 = Array.of(1, 2, 3); // [1, 2, 3] — безопаснее new Array()

// Из итерируемого объекта
const fromString = Array.from('hello');  // ['h', 'e', 'l', 'l', 'o']
const fromSet = Array.from(new Set([1, 2, 2, 3])); // [1, 2, 3]

// Заполнение значением
const filled = Array(3).fill(0);        // [0, 0, 0]
const filled2 = Array.from({ length: 3 }, (_, i) => i * 2); // [0, 2, 4]
```

## Чтение и запись элементов

```javascript
const arr = ['a', 'b', 'c', 'd'];

// Прямой доступ
arr[0] = 'z';        // ['z', 'b', 'c', 'd']
arr[10] = 'x';       // ['z', 'b', 'c', 'd', empty × 6, 'x'] — разреженные массивы!

// after, before (ES2023) — без мутации
arr.toSpliced(1, 1, 'x', 'y'); // ['z', 'x', 'y', 'c', 'd'] — копия
arr.toReversed();              // ['d', 'c', 'b', 'a'] — копия
arr.toSorted();                // ['a', 'b', 'c', 'd'] — копия
arr.with(1, 'z');              // ['a', 'z', 'c', 'd'] — копия с заменой
```

## Основные мутирующие методы

### Добавление / удаление с концов

```javascript
const arr = [1, 2, 3];

arr.push(4, 5);     // 5 — новая длина, arr = [1, 2, 3, 4, 5]
arr.pop();          // 5, arr = [1, 2, 3, 4]

arr.unshift(0);     // 5, arr = [0, 1, 2, 3, 4]
arr.shift();        // 0, arr = [1, 2, 3, 4]
```

### Splice — универсальный метод изменений

```javascript
const arr = [1, 2, 3, 4, 5];

// Удаление: splice(старт, количество)
arr.splice(1, 2);           // [2, 3] — удалённые, arr = [1, 4, 5]

// Замена: splice(старт, количество, ...новые)
arr.splice(1, 1, 'a', 'b'); // [4], arr = [1, 'a', 'b', 5]

// Вставка: splice(старт, 0, ...новые)
arr.splice(2, 0, 'x');      // [], arr = [1, 'a', 'x', 'b', 5]
```

## Не мутирующие методы (иммутабельные)

```javascript
const arr = [1, 2, 3, 4, 5];

// Конкатенация
arr.concat([6, 7]);           // [1, 2, 3, 4, 5, 6, 7]
[...arr, 6, 7];               // то же самое (spread)

// Срез
arr.slice(1, 3);              // [2, 3] — от индекса 1 до 3 (не включая)
arr.slice(-2);                // [4, 5] — последние 2
arr.slice();                  // [1, 2, 3, 4, 5] — копия

// Объединение в строку
arr.join(', ');               // '1, 2, 3, 4, 5'
arr.join('');                 // '12345'
```

## Поиск и проверка

```javascript
const arr = [5, 12, 8, 130, 44];

// Поиск индекса
arr.indexOf(8);       // 2
arr.indexOf(99);      // -1 (нет)
arr.lastIndexOf(8);   // 2 (если дубликаты)

// Поиск элемента (ES2015+)
arr.find(x => x > 10);        // 12 — первый подходящий
arr.findIndex(x => x > 10);   // 1 — индекс первого подходящего
arr.findLast(x => x > 10);    // 130 — последний подходящий (ES2023)
arr.findLastIndex(x => x > 10); // 3

// Проверка наличия
arr.includes(8);      // true
arr.includes(99);     // false
[NaN].includes(NaN);  // true (в отличие от indexOf!)

// Проверка условия
arr.some(x => x > 10);   // true — хотя бы один
arr.every(x => x > 0);   // true — все
```

## Трансформация: map, filter, reduce

### map — преобразование каждого элемента

```javascript
const numbers = [1, 2, 3, 4];

const doubled = numbers.map(x => x * 2);     // [2, 4, 6, 8]
const strings = numbers.map(String);         // ['1', '2', '3', '4']
const objects = numbers.map(n => ({ value: n }));
// [{value:1}, {value:2}, {value:3}, {value:4}]

// map получает (element, index, array)
['a', 'b', 'c'].map((ch, i) => `${i}:${ch}`); // ['0:a', '1:b', '2:c']
```

### filter — отбор элементов

```javascript
const numbers = [1, 2, 3, 4, 5, 6];

const evens = numbers.filter(n => n % 2 === 0); // [2, 4, 6]
const big = numbers.filter(n => n > 3);         // [4, 5, 6]

// Комбинация map + filter
const result = numbers
  .filter(n => n % 2 === 0)
  .map(n => n * 10); // [20, 40, 60]
```

### reduce — свёртка к одному значению

```javascript
const numbers = [1, 2, 3, 4];

// Сумма
const sum = numbers.reduce((acc, n) => acc + n, 0); // 10

// Произведение
const product = numbers.reduce((acc, n) => acc * n, 1); // 24

// Поиск максимума
const max = numbers.reduce((a, b) => Math.max(a, b)); // 4 (без initialValue — первый элемент)

// Группировка объектов
const users = [
  { name: 'Alex', role: 'admin' },
  { name: 'Bob', role: 'user' },
  { name: 'Carol', role: 'admin' }
];

const byRole = users.reduce((acc, user) => {
  (acc[user.role] ??= []).push(user);
  return acc;
}, {});

// { admin: [...], user: [...] }

// Плоское отображение (flatMap = map + flat)
const phrases = ['hello world', 'foo bar'];
phrases.flatMap(s => s.split(' ')); // ['hello', 'world', 'foo', 'bar']
```

## Плоские массивы: flat, flatMap

```javascript
const nested = [1, [2, [3, [4]]]];

nested.flat();        // [1, 2, [3, [4]]] — глубина 1
nested.flat(2);       // [1, 2, 3, [4]] — глубина 2
nested.flat(Infinity); // [1, 2, 3, 4] — полностью

// flatMap — map + flat(1)
[1, 2, 3].flatMap(x => [x, x * 10]); // [1, 10, 2, 20, 3, 30]
```

## Сортировка

```javascript
const numbers = [3, 1, 4, 1, 5, 9];

// Встроенная сортировка (мутирует! Преобразует в строки!)
numbers.sort();           // [1, 1, 3, 4, 5, 9] — лексикографически для чисел работает случайно
[10, 2, 30].sort();       // [10, 2, 30] — НЕПРАВИЛЬНО!

// Правильная числовая сортировка
numbers.sort((a, b) => a - b);     // [1, 1, 3, 4, 5, 9] — по возрастанию
numbers.sort((a, b) => b - a);     // [9, 5, 4, 3, 1, 1] — по убыванию

// toSorted (ES2023) — без мутации
const sorted = numbers.toSorted((a, b) => a - b);

// Сортировка объектов
const users = [{ age: 25 }, { age: 20 }, { age: 30 }];
users.toSorted((a, b) => a.age - b.age);
```

## Итерация

```javascript
const arr = ['a', 'b', 'c'];

// for...of — значения
for (const item of arr) {
  console.log(item);
}

// forEach — коллбек (нельзя прервать break/continue)
arr.forEach((item, index) => {
  console.log(index, item);
});

// for...in — индексы (не рекомендуется для массивов!)
for (const i in arr) {
  console.log(i, arr[i]);
}

// entries, keys, values — итераторы
for (const [i, v] of arr.entries()) {}
for (const i of arr.keys()) {}
for (const v of arr.values()) {}

// Array.fromAsync (ES2023) — для async итераторов
// const result = await Array.fromAsync(asyncIterable);
```

## Typed Arrays (типизированные массивы)

Для работы с бинарными данными:

```javascript
// Буфер
const buffer = new ArrayBuffer(16); // 16 байт

// Представления (Views)
const int32 = new Int32Array(buffer);    // 4 байта на число
const float64 = new Float64Array(buffer); // 8 байт
const uint8 = new Uint8Array(buffer);     // 1 байт (0-255)

int32[0] = 42;
float64[0] = 3.14;
uint8[0] = 255;

// Создание из обычного массива
const arr = new Uint8Array([1, 2, 3, 255]);

// Методы как у обычных массивов (map, filter, reduce, forEach...)
arr.map(x => x * 2);
```

## Типичные ошибки

| Ошибка | Неправильно | Правильно | Пояснение |
|--------|-------------|-----------|-----------|
| `new Array(n)` | `new Array(3)` → `[empty × 3]` | `Array(3).fill(0)` или `[...Array(3)]` | Создаёт разреженный массив |
| Сортировка чисел | `[10, 2].sort()` | `[10, 2].sort((a,b)=>a-b)` | Сортирует как строки |
| Мутация в коллбеке | `arr.forEach(x => arr.push(x))` | `arr.flatMap(x => [x, x])` | Бесконечный цикл / ошибки |
| `for...in` для массивов | `for (const i in arr)` | `for (const v of arr)` | `for...in` перечисляет свойства, не гарантирует порядок |
| `reduce` без initialValue | `[].reduce(f)` | `[].reduce(f, 0)` | Ошибка на пустом массиве |
