# Урок 4: Циклы

## Цикл for — классический

```javascript
// for (инициализация; условие; обновление)
for (let i = 0; i < 5; i++) {
  console.log(i); // 0, 1, 2, 3, 4
}

// Части можно опускать (но ; обязательны)
let i = 0;
for (; i < 5; ) {
  console.log(i++);
}

// Множественные переменные
for (let i = 0, j = 10; i < j; i++, j--) {
  console.log(i, j); // 0 10, 1 9, 2 8, 3 7, 4 6
}
```

---

## Цикл for...of — итерация по значениям (ES2015)

**Основной способ перебора массивов, строк, Map, Set, NodeList:**

```javascript
const fruits = ['яблоко', 'банан', 'апельсин'];

for (const fruit of fruits) {
  console.log(fruit); // значения: 'яблоко', 'банан', 'апельсин'
}

// С индексом (через entries)
for (const [index, fruit] of fruits.entries()) {
  console.log(`${index}: ${fruit}`);
}

// По строкам — по символам (учитывает Unicode!)
for (const char of '🎉🎊') {
  console.log(char); // '🎉', '🎊' (не суррогаты!)
}

// Map
const map = new Map([['a', 1], ['b', 2]]);
for (const [key, value] of map) {
  console.log(key, value);
}

// Set
const set = new Set([1, 2, 2, 3]);
for (const value of set) {
  console.log(value); // 1, 2, 3 (уникальные)
}
```

## Цикл for...in — итерация по ключам (устарел для массивов)

```javascript
const obj = { a: 1, b: 2, c: 3 };

for (const key in obj) {
  console.log(key, obj[key]); // 'a' 1, 'b' 2, 'c' 3
}

// ⚠️ for...in перебирает унаследованные свойства!
const parent = { x: 10 };
const child = Object.create(parent);
child.y = 20;
for (const key in child) {
  console.log(key); // 'y', 'x' — и своё, и унаследованное!
}

// Проверка.hasOwnProperty()
for (const key in child) {
  if (child.hasOwnProperty(key)) {
    console.log(key); // только 'y'
  }
}

// ❌ НЕ ИСПОЛЬЗУЙТЕ for...in для массивов!
// - Порядок не гарантирован
// - Перебирает индексы как строки
// - Подхватывает добавленные в прототип свойства
```

## forEach — метод массива (не цикл, но часто заменяет)

```javascript
const fruits = ['яблоко', 'банан', 'апельсин'];

fruits.forEach((fruit, index, array) => {
  console.log(index, fruit);
  // array — ссылка на исходный массив
});

// ⚠️ forEach НЕ поддерживает break/continue/return
// Для прерывания — используйте for...of или классический for
```

## break и continue

```javascript
// break — выход из цикла
for (let i = 0; i < 10; i++) {
  if (i === 5) break;
  console.log(i); // 0, 1, 2, 3, 4
}

// continue — пропуск итерации
for (let i = 0; i < 5; i++) {
  if (i === 2) continue;
  console.log(i); // 0, 1, 3, 4
}

// Метки (labels) — для вложенных циклов
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (i === 1 && j === 1) break outer;
    console.log(i, j);
  }
}
// Вывод: 0 0, 0 1, 0 2, 1 0
```

## Итерация объектов (современные способы)

```javascript
const user = { name: 'Alex', age: 25, city: 'Moscow' };

// Object.keys — только свои перечисляемые свойства
for (const key of Object.keys(user)) {
  console.log(key, user[key]);
}

// Object.values — только значения
for (const value of Object.values(user)) {
  console.log(value);
}

// Object.entries — пары [ключ, значение] (ИДЕАЛЬНО для for...of)
for (const [key, value] of Object.entries(user)) {
  console.log(`${key}: ${value}`);
}

// Object.getOwnPropertySymbols — для Symbol-ключей
const sym = Symbol('id');
const obj = { [sym]: 123, name: 'Test' };
Object.getOwnPropertySymbols(obj); // [Symbol(id)]
```

## Итерация Map и Set

```javascript
const map = new Map([
  ['name', 'Alex'],
  ['age', 25]
]);

// Map сохраняет порядок вставки!
for (const [key, value] of map) {
  console.log(key, value);
}
// Или:
for (const key of map.keys()) { /* ... */ }
for (const value of map.values()) { /* ... */ }
for (const entry of map.entries()) { /* ... */ }

const set = new Set([1, 2, 3, 2]);
for (const value of set) {
  console.log(value); // 1, 2, 3
}
```

## Генераторы и итераторы (продвинуто)

```javascript
// Генератор — функция, которую можно приостановить
function* range(start, end) {
  for (let i = start; i <= end; i++) {
    yield i; // отдаёт значение и ждёт следующий .next()
  }
}

const gen = range(1, 3);
gen.next(); // { value: 1, done: false }
gen.next(); // { value: 2, done: false }
gen.next(); // { value: 3, done: false }
gen.next(); // { value: undefined, done: true }

// Генератор — итерируемый объект!
for (const num of range(1, 3)) {
  console.log(num); // 1, 2, 3
}

// Бесконечный генератор
function* idGenerator() {
  let id = 0;
  while (true) yield id++;
}
const ids = idGenerator();
ids.next().value; // 0
ids.next().value; // 1
```

## Асинхронная итерация (for await...of) — ES2018

```javascript
async function* fetchPages() {
  for (let page = 1; page <= 3; page++) {
    const response = await fetch(`/api/items?page=${page}`);
    yield await response.json();
  }
}

// Использование
for await (const page of fetchPages()) {
  console.log(page); // ждёт каждый yield
}
```

## Практические паттерны

### Обратный цикл
```javascript
// Классический
for (let i = arr.length - 1; i >= 0; i--) { }

// ES2023: toReversed()
for (const item of arr.toReversed()) { }
```

### Цикл с шагом
```javascript
// Каждый второй
for (let i = 0; i < arr.length; i += 2) { }

// ES2023: filter + for...of
for (const item of arr.filter((_, i) => i % 2 === 0)) { }
```

### Удаление элементов во время итерации
```javascript
// ❌ Нельзя в forEach / for...of (пропускает элементы)
// ✅ Обратный цикл
for (let i = arr.length - 1; i >= 0; i--) {
  if (shouldRemove(arr[i])) arr.splice(i, 1);
}

// ✅ filter (создаёт новый массив)
const filtered = arr.filter(item => !shouldRemove(item));
```

## Производительность (кратко)

| Способ | Скорость | Когда использовать |
|--------|----------|-------------------|
| `for (let i=0; i<len; i++)` | Максимальная | Критичные участки, большие массивы |
| `for...of` | Высокая | Обычный код, читаемость |
| `forEach` | Средняя | Простые коллбеки, когда не нужен break |
| `for...in` | Низкая | Только для объектов (с hasOwnProperty) |

> **Совет:** В 95% случаев используйте `for...of`. Классический `for` — только для производительности или специфических задач.
