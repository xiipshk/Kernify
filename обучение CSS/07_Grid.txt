# Урок 7: CSS Grid — Двумерный layout: треки, линии, области, minmax, auto-fit/fill, subgrid, masonry

## Цели урока
- Освоить двумерную систему раскладки: ряды и колонки одновременно
- Понять Grid Lines, Grid Tracks, Grid Cells, Grid Areas
- Изучить fr, minmax(), repeat(), auto-fit/auto-fill, fit-content()
- Научиться именованным линиям и областям (grid-template-areas)
- Освоить subgrid, masonry, container queries в grid

---

## 1. Концепция Grid — двумерный layout

```
GRID CONTAINER (display: grid)
│
├─ COLUMN TRACKS (колонки) — inline axis
│   ├─ Grid Lines: 1, 2, 3, 4... (или именованные)
│   ├─ Grid Tracks: пространство между линиями
│   └─ gutters: column-gap
│
├─ ROW TRACKS (ряды) — block axis
│   ├─ Grid Lines: 1, 2, 3, 4...
│   ├─ Grid Tracks
│   └─ gutters: row-gap
│
├─ GRID CELL — пересечение 1 колонки и 1 ряда (минимальная единица)
├─ GRID AREA — прямоугольник из нескольких ячеек
└─ GRID ITEM — прямой ребёнок контейнера
```

### Базовое включение
```css
.grid {
  display: grid;
  /* или inline-grid для inline контекста */
}
```

## 2. Определение треков — grid-template-columns/rows

### Явные треки
```css
.grid {
  display: grid;

  /* Колонки */
  grid-template-columns: 200px 1fr 2fr;      /* 3 колонки: фикс, 1 часть, 2 части */
  grid-template-columns: repeat(3, 1fr);     /* 3 равные колонки */
  grid-template-columns: repeat(4, 100px 1fr); /* Паттерн: 100px, 1fr × 4 */

  /* Ряды */
  grid-template-rows: auto 1fr auto;         /* header, main, footer */
  grid-template-rows: repeat(3, minmax(100px, auto));
}
```

### fr (fraction) — гибкие доли
```css
.grid {
  grid-template-columns: 1fr 2fr 1fr;  /* 25% / 50% / 25% */
  /* fr делит ТОЛЬКО свободное пространство после фиксированных треков */

  grid-template-columns: 200px 1fr;    /* 200px фикс, остальное = 1fr */
}
```

### minmax() — диапазон размеров
```css
.grid {
  /* Минимум 200px, максимум 1fr (остаток) */
  grid-template-columns: repeat(3, minmax(200px, 1fr));

  /* Минимум по контенту, максимум 300px */
  grid-template-columns: minmax(min-content, 300px);

  /* Минимум max-content, максимум 50% */
  grid-template-columns: minmax(max-content, 50%);

  /* auto = minmax(min-content, max-content) */
  grid-template-columns: minmax(auto, 1fr);
}
```

### repeat() с auto-fit / auto-fill — responsive без media queries
```css
.grid {
  /* auto-fill — создаёт столько треков, сколько помещается (пустые остаются) */
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));

  /* auto-fit — схлопывает пустые треки, растягивает заполненные */
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));

  /* Разница видна когда элементов меньше, чем может поместиться */
}

/* Практический паттерн — адаптивная сетка карточек */
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
  gap: 1.5rem;
}
```

### fit-content() — clamp для треков
```css
.grid {
  /* Минимум по контенту, максимум 300px */
  grid-template-columns: fit-content(300px) 1fr;

  /* Эквивалент: minmax(auto, max-content) ограниченный 300px */
}
```

## 3. Размещение элементов — линии и спаны

### По номерам линий
```css
.item {
  /* column-start / column-end / row-start / row-end */
  grid-column: 1 / 3;        /* От линии 1 до 3 (2 колонки) */
  grid-row: 1 / span 2;      /* От линии 1, занимает 2 ряда */

  /* Сокращения */
  grid-column: 2;            /* От линии 2 до 3 (1 колонка) */
  grid-column: span 3;       /* 3 колонки от авто-начала */
  grid-area: 1 / 2 / 3 / 4;  /* row-start / col-start / row-end / col-end */
}
```

### Именованные линии
```css
.grid {
  display: grid;
  grid-template-columns:
    [sidebar-start] 250px [sidebar-end content-start] 1fr [content-end];
  grid-template-rows:
    [header-start] auto [header-end main-start] 1fr [main-end footer-start] auto [footer-end];
}

.sidebar {
  grid-column: sidebar-start / sidebar-end;
  grid-row: header-start / footer-end;
}

.content {
  grid-column: content-start / content-end;
  grid-row: main-start / main-end;
}
```

### Именованные области (grid-template-areas) — визуальный подход
```css
.grid {
  display: grid;
  grid-template-columns: 250px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  gap: 1rem;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

/* Responsive — просто меняем areas */
@media (max-width: 768px) {
  .grid {
    grid-template-columns: 1fr;
    grid-template-areas:
      "header"
      "main"
      "sidebar"
      "footer";
  }
}
```

## 4. Выравнивание — justify/align/place

### Контейнер (треки внутри контейнера)
```css
.grid {
  display: grid;
  /* Если треков меньше контейнера */
  justify-content: start | center | end | stretch | space-around | space-between | space-evenly;
  align-content: start | center | end | stretch | space-around | space-between | space-evenly;

  /* Сокращение */
  place-content: center stretch;
}
```

### Элементы (контент внутри ячейки)
```css
.grid {
  /* Default для всех детей */
  justify-items: start | center | end | stretch;  /* inline axis */
  align-items: start | center | end | stretch | baseline;  /* block axis */
  place-items: center stretch;
}

.item {
  /* Переопределение для конкретного */
  justify-self: start | center | end | stretch;
  align-self: start | center | end | stretch | baseline;
  place-self: center;
}
```

## 5. Автоматическое размещение (Auto-placement)

### Алгоритм dense — заполнение дыр
```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-flow: row dense;  /* или column dense */

  /* dense пытается заполнить пустые ячейки следующими элементами */
  /* Меняет визуальный порядок! */
}

.item-wide {
  grid-column: span 2;
}

/* Без dense: дыры остаются */
/* С dense: следующие элементы заполняют дыры */
```

### Неявные треки (implicit tracks)
```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  /* Ряды не заданы — создаются автоматически */

  grid-auto-rows: minmax(100px, auto);  /* Размер неявных рядов */
  grid-auto-columns: 1fr;                /* Размер неявных колонок */

  grid-auto-flow: row;      /* Заполнение по рядам (default) */
  grid-auto-flow: column;   /* Заполнение по колонкам */
  grid-auto-flow: dense;    /* Плотная упаковка */
}
```

## 6. Subgrid — наследование треков родителя

```css
/* Родитель */
.parent-grid {
  display: grid;
  grid-template-columns: [start] 1fr [mid] 2fr [end];
  grid-template-rows: [top] auto [mid] 1fr [bottom];
}

/* Ребёнок наследует треки */
.child-grid {
  display: grid;
  grid-template-columns: subgrid;  /* Наследует колонки родителя */
  grid-template-rows: subgrid;     /* Наследует ряды родителя */
  /* Теперь можно позиционировать по линиям родителя! */
}

.grandchild {
  grid-column: start / mid;  /* Использует линии .parent-grid */
  grid-row: top / mid;
}

/* Частичный subgrid */
.partial {
  grid-template-columns: subgrid;
  grid-template-rows: auto 1fr auto;  /* Свои ряды */
}
```

## 7. Masonry (Pinterest-style) — экспериментальный

```css
/* Включается флагом в браузере: layout.css.grid-template-masonry-value.enabled */
.masonry {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  grid-template-rows: masonry;  /* Включает masonry layout */
  gap: 1rem;
}

/* Masonry-auto-flow — контроль порядка */
.masonry {
  masonry-auto-flow: next;      /* Следующая доступная ячейка (default) */
  masonry-auto-flow: definite-first;  /* Сначала элементы с заданной высотой */
}

/* Прогрессивное улучшение */
@supports (grid-template-rows: masonry) {
  .masonry {
    grid-template-rows: masonry;
  }
}

/* Fallback для старых браузеров — column-count */
.masonry {
  column-count: 4;
  column-gap: 1rem;
}
@supports (grid-template-rows: masonry) {
  .masonry {
    column-count: initial;
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
    grid-template-rows: masonry;
  }
}
```

## 8. Grid + Container Queries — адаптивные компоненты

```css
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 1rem;
  container-type: inline-size;
}

.card {
  /* Стили карточки */
}

@container (max-width: 400px) {
  .card {
    grid-template-areas:
      "image"
      "title"
      "content"
      "footer";
    grid-template-columns: 1fr;
  }
}

@container (min-width: 400px) {
  .card {
    grid-template-areas:
      "image title"
      "image content"
      "footer footer";
    grid-template-columns: 150px 1fr;
  }
}
```

## 9. Продвинутые техники

### Перекрывающиеся элементы (без z-index)
```css
.overlay-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(2, 200px);
}

.item-1 { grid-area: 1 / 1 / 3 / 3; }  /* Большой на заднем плане */
.item-2 { grid-area: 1 / 2 / 2 / 4; }  /* Перекрывает справа сверху */
.item-3 { grid-area: 2 / 1 / 3 / 2; }  /* Перекрывает слева снизу */
/* Порядок в DOM определяет z-index (последний = верхний) */
```

### Aspect Ratio в Grid
```css
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  grid-auto-rows: 1fr;  /* Квадратные ячейки */
}

.item {
  aspect-ratio: 16 / 9;
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

### Анимация Grid Tracks (ограниченно)
```css
/* Анимируются: grid-gap, grid-template-rows/columns (только дискретные значения) */
/* НЕ анимируются: fr, auto, minmax, repeat с auto-fit/fill */

.grid {
  transition: grid-template-columns 0.3s, gap 0.3s;
}

.grid.expanded {
  grid-template-columns: 300px 1fr;
}
```

## 11. Grid vs Flexbox — итоговое сравнение

| Сценарий | Grid | Flexbox |
|----------|------|---------|

| Карточки с wrap | ✅ (auto-fit) | ✅ |
| Двумерная сетка | ✅ | ❌ |
| Перекрытие элементов | ✅ | ❌ |
| Именованные области | ✅ | ❌ |
| Subgrid | ✅ | ❌ |
| Masonry | ✅ (эксп.) | ❌ |

## 12. Таблица частых ошибок

| Ошибка | Проблема | Решение |
|--------|----------|---------|
| `1fr 1fr 1fr` вместо `repeat(3, 1fr)` | Повторение, сложно менять | `repeat()` |
| Нет `minmax()` в repeat | Карточки сжимаются до 0 на мобильных | `repeat(auto-fit, minmax(250px, 1fr))` |
| `auto-fill` вместо `auto-fit` | Пустые колонки в конце ряда | `auto-fit` для растягивания |
| `grid-area` с несуществующими именами | Тихий фейл, элемент в авто-место | Проверяй имена в template-areas |
| Subgrid без `display: grid` на ребёнке | Не работает | Ребёнок тоже должен быть grid |
| Masonry без флага/fallback | Не работает в продакшене | `@supports` + column-count fallback |
| `gap` в процентах | Считается от ширины контейнера, может быть большим | Пиксели или `clamp()` |

## 14. Ключевые выводы

1. **Grid = двумерный layout**. Одновременно контроль рядов И колонок.
2. **`repeat(auto-fit, minmax(min, max))`** — responsive сетка без media queries.
3. **Именованные линии и области** — читаемый, поддерживаемый код.
4. **Subgrid** — решает проблему вложенных гридов, наследует треки родителя.
5. **Masonry** — нативный Pinterest layout (экспериментально, нужен fallback).
6. **Container Queries + Grid** — компоненты, адаптирующиеся к своему контейнеру.
7. **Firefox DevTools** — лучший друг для отладки Grid (показывает линии, номера, области).
