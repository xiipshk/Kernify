## 1. Что такое CSS

**CSS (Cascading Style Sheets)** — язык таблиц стилей, описывающий внешний вид HTML-документов.

```html
<!-- HTML отвечает за СТРУКТУРУ -->
<article class="card">
  <h2>Заголовок</h2>
  <p>Текст содержимого</p>
  <button>Кнопка</button>
</article>
```

```css
/* CSS отвечает за ВНЕШНИЙ ВИД */
.card {
  border: 1px solid #e5e7eb;
  border-radius: 8px;
  padding: 1.5rem;
  box-shadow: 0 4px 6px -1px rgb(0 0 0 / 0.1);
}

.card h2 {
  font-size: 1.25rem;
  font-weight: 600;
  color: #111827;
}

.card button {
  background: #2563eb;
  color: white;
  padding: 0.5rem 1rem;
  border-radius: 4px;
  border: none;
  cursor: pointer;
}
```

### Разделение ответственностей
| HTML | CSS | JavaScript |
|------|-----|------------|
| Структура, семантика | Визуальное оформление | Поведение, интерактивность |
| Контент | Layout, цвета, типографика | События, состояние, API |

## 2. Анатомия CSS-правила

```css
селектор {
  свойство: значение;
  другое-свойство: другое-значение;
}
```

### Пример разбора:
```css
.button--primary {
  background-color: #2563eb;
  color: #ffffff;
  padding: 0.75rem 1.5rem;
  border-radius: 0.375rem;
  font-weight: 500;
  transition: background-color 0.2s ease;
}
```
- **Селектор**: `.button--primary` — к каким элементам применять
- **Блок объявлений**: всё внутри `{}`
- **Объявление**: `background-color: #2563eb;`
- **Свойство**: `background-color`
- **Значение**: `#2563eb`

## 3. Способы подключения CSS

### 3.1 Внешний файл (Рекомендуемый)
```html
<head>
  <link rel="stylesheet" href="styles/main.css">
</head>
```

**Преимущества:**
- Кэшируется браузером
- Переиспользуется на всех страницах
- Разделение кода
- Поддерживает `@import` и `@layer`

### 3.2 Внутренние стили (`<style>`)
```html
<head>
  <style>
    .hero { background: linear-gradient(135deg, #667eea, #764ba2); }
  </style>
</head>
```
**Когда использовать:** критические стили above-the-fold, email-верстка, временные правки.

### 3.3 Инлайн стили (`style=""`)
```html
<div style="color: red; font-size: 14px;">Текст</div>
```
**Когда использовать:** динамические значения из JS, уникальные разовые стили.
**Недостатки:** максимальная специфичность, не переиспользуются, загрязняют HTML.

### 3.4 @import (не рекомендуется для продакшена)
```css
/* В CSS файле */
@import url('reset.css');
@import url('components.css');
```
**Проблемы:** блокирует параллельную загрузку, дополнительные HTTP-запросы.
**Альтернатива:** сборщики (Vite, Webpack) или нативные `@layer` с `<link rel="preload">`.

## 4. Базовые селекторы

```css
/* Типовой (элемент) */
p { line-height: 1.6; }

/* Класс (наиболее используемый) */
.card { padding: 1rem; }

/* ID (высокая специфичность — избегай для стилей) */
#header { position: sticky; top: 0; }

/* Атрибут */
input[type="email"] { background: #fef3c7; }

/* Универсальный */
* { box-sizing: border-box; }

/* Комбинаторы */
.parent > .child { }           /* Прямой потомок */
.ancestor .descendant { }      /* Любой потомок */
h2 + p { margin-top: 0; }      /* Смежный брат */
h2 ~ p { color: #6b7280; }     /* Все следующие братья */
```

## 5. Каскад и наследование — основы

### Каскад (порядок приоритета, от низкого к высокому):
1. **User Agent Styles** — стили браузера по умолчанию
2. **User Styles** — пользовательские стили браузера
3. **Author Styles** — твои стили (самый важный)
4. **Author `!important`**
5. **User `!important`**
6. **User Agent `!important`**

### Наследование
Свойства **наследуются** по умолчанию:
```css
body {
  font-family: system-ui;
  color: #1f2937;
  line-height: 1.5;
}
/* Все потомки наследуют font-family, color, line-height */
```

Свойства **НЕ наследуются**:
- `margin`, `padding`, `border`
- `width`, `height`
- `position`, `display`, `flex`, `grid`
- `background`, `box-shadow`

```css
/* Принудительное наследование */
.child {
  color: inherit;           /* Явно наследовать */
  border: inherit;          /* Работает для наследуемых */
  margin: initial;          /* Сбросить до начального */
  padding: unset;           /* inherit если наследуется, иначе initial */
  background: revert;       /* Сбросить к user-agent стилям */
  font-size: revert-layer;  /* Сбросить к предыдущему слою */
}
```

## 6. Единицы измерения

### Абсолютные (физические)
```css
width: 100px;   /* Пиксели — базовая единица */
width: 2in;     /* Дюймы (96px) */
width: 2.54cm;  /* Сантиметры */
width: 25.4mm;  /* Миллиметры */
width: 72pt;    /* Пойнты (1/72 in) */
width: 6pc;     /* Пики (12pt) */
```

### Относительные к шрифту
```css
font-size: 1em;      /* Размер шрифта родителя */
font-size: 1rem;     /* Размер шрифта :root (обычно 16px) */
font-size: 1.2ex;    /* Высота буквы 'x' */
font-size: 2ch;      /* Ширина символа '0' */
font-size: 100%;     /* Процент от родителя */
```

### Относительные к viewport
```css
width: 100vw;   /* 1% ширины viewport */
height: 50vh;   /* 1% высоты viewport */
size: 10vmin;   /* 1% от меньшей стороны */
size: 10vmax;   /* 1% от большей стороны */
```

### Логические (новые, для RTL/LTR)
```css
margin-inline-start: 1rem;   /* margin-left в LTR, margin-right в RTL */
margin-inline-end: 1rem;
padding-block-start: 1rem;   /* padding-top */
padding-block-end: 1rem;     /* padding-bottom */
width: 100%;                 /* inline-size */
height: 100%;                /* block-size */
```

## 7. DevTools — основы отладки

### Инспектор (Elements)
- **Ctrl+Shift+C** — выбрать элемент
- Видишь: computed styles, box model, event listeners
- **Фильтр стилей** — поиск по свойству
- **Переключение псевдоклассов** `:hover`, `:focus`, `:active`

### Консоль (Console)
```javascript
// Получить вычисленные стили
getComputedStyle(document.querySelector('.card'))

// Проверить поддержку
CSS.supports('display', 'grid')  // true/false

// Найти элемент по селектору
document.querySelector('.card')
document.querySelectorAll('.card')
```

### Полезные вкладки
- **Computed** — итоговые значения после каскада
- **Layout** — Grid/Flex визуализация
- **Animations** — инспектор анимаций
- **Rendering** — эмуляция prefers-color-scheme, reduced-motion

## 8. Практическое задание

### Задача 1: Базовая HTML-страница с CSS
Создай `index.html` и `styles.css`:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Мой первый CSS</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <header class="header">
    <h1>Заголовок сайта</h1>
    <nav class="nav">
      <a href="#" class="nav__link">Главная</a>
      <a href="#" class="nav__link">О нас</a>
      <a href="#" class="nav__link">Контакты</a>
    </nav>
  </header>

  <main class="main">
    <article class="card">
      <h2 class="card__title">Название статьи</h2>
      <p class="card__text">Текст статьи с <strong>выделением</strong>.</p>
      <button class="button button--primary">Читать далее</button>
    </article>
  </main>

  <footer class="footer">
    <p>&copy; 2024 Мой сайт</p>
  </footer>
</body>
</html>
```

```css
/* styles.css */
/* 1. Сброс */
*, *::before, *::after { box-sizing: border-box; }
* { margin: 0; padding: 0; }

/* 2. Базовые стили */
:root {
  --color-primary: #2563eb;
  --color-text: #1f2937;
  --color-muted: #6b7280;
  --spacing: 1rem;
  --radius: 8px;
}

body {
  font-family: system-ui, -apple-system, sans-serif;
  color: var(--color-text);
  line-height: 1.6;
  background: #f9fafb;
}

/* 3. Компоненты */
.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: var(--spacing) 2rem;
  background: white;
  box-shadow: 0 1px 3px rgb(0 0 0 / 0.1);
}

.nav { display: flex; gap: 1.5rem; }
.nav__link { color: var(--color-text); text-decoration: none; }
.nav__link:hover { color: var(--color-primary); }

.main { padding: 2rem; max-width: 800px; margin: 0 auto; }

.card {
  background: white;
  border-radius: var(--radius);
  padding: 1.5rem;
  box-shadow: 0 1px 3px rgb(0 0 0 / 0.1);
}

.card__title { margin-bottom: 0.5rem; font-size: 1.5rem; }
.card__text { color: var(--color-muted); margin-bottom: 1rem; }

.button {
  padding: 0.5rem 1rem;
  border-radius: 4px;
  border: none;
  cursor: pointer;
  font-weight: 500;
  transition: background 0.2s;
}

.button--primary {
  background: var(--color-primary);
  color: white;
}
.button--primary:hover { background: #1d4ed8; }

.footer {
  padding: 2rem;
  text-align: center;
  color: var(--color-muted);
  border-top: 1px solid #e5e7eb;
}
```

### Задача 2: Исследование каскада
В DevTools:
1. Найди элемент `.card__title`
2. Посмотри вкладку **Computed** — откуда приходит `font-size`?
3. Добавь `!important` к одному свойству — что изменилось?
4. Отключи CSS файл — что осталось от User Agent стилей?

## 9. Таблица частых ошибок новичков

| Ошибка | Проблема | Решение |
|--------|----------|---------|
| Стили в `style=""` везде | Неподдерживаемо, высокая специфичность | Внешние CSS файлы + классы |
| Использование ID для стилей (`#id`) | Слишком высокая специфичность | Классы БЭМ: `.block__element` |
| Нет `box-sizing: border-box` | Padding/break ломают ширину | `*, *::before, *::after { box-sizing: border-box }` |
| Пиксели везде (`16px`) | Не масштабируется при зумме | `rem` для шрифтов, логические свойства |
| Нет `viewport` meta | Мобильные ломаются | `<meta name="viewport" content="width=device-width, initial-scale=1">` |
| Селекторы типа `div div div p` | Хрупкие, зависят от структуры | Классы с понятными именами |
| Не знают про наследование | Пишут `color` на каждом элементе | Задай на `body`, наследуй |

## 11. Ключевые выводы

1. **CSS — это декларативный язык**: ты описываешь *что* должно быть, браузер решает *как*.
2. **Разделяй структуру (HTML) и оформление (CSS)** — это основа поддерживаемости.
3. **Используй классы, не ID и не теги** — низкая специфичность = легкость переопределения.
4. **`box-sizing: border-box` глобально** — экономит кучу нервов.
5. **`rem` для типографики, логические свойства для layout** — доступность и i18n.
6. **DevTools — твой лучший друг** — учись читать Computed, Layout, Cascade.
7. **Каскад — не баг, а фича** — понимай приоритеты, не борьби с ними `!important`.
