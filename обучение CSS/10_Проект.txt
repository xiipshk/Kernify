# Урок 10: Проект начального уровня — Landing Page с полным адаптивом

## Цели проекта
- Закрепить все навыки уроков 1-9 в одном полном проекте
- Построить современную Landing Page: Hero, Features, Testimonials, Pricing, Footer
- Применить: CSS Variables, Fluid Typography, Flexbox, Grid, Container Queries
- Сделать полностью доступный, производительный, кроссбраузерный код
- Написать чистый, поддерживаемый CSS по методологии БЭМ

---

## 1. Техническое задание

### Структура страницы
```
┌─────────────────────────────────────┐
│ HEADER (sticky)                     │
│  Logo | Nav Links | CTA Button      │
├─────────────────────────────────────┤
│ HERO                                │
│  h1 + p + Primary CTA + Secondary  │
│  Background: gradient + pattern     │
├─────────────────────────────────────┤
│ FEATURES (Grid 3→2→1)               │
│  6 карточек: icon + h3 + p          │
├─────────────────────────────────────┤
│ TESTIMONIALS (Slider/Grid)          │
│  3 карточки: avatar + quote + author│
├─────────────────────────────────────┤
│ PRICING (Grid 3→1)                  │
│  3 тарифа: name + price + features  │
├─────────────────────────────────────┤
│ CTA SECTION                         │
│  h2 + p + Button                    │
├─────────────────────────────────────┤
│ FOOTER                              │
│  Logo + Links columns + Copyright   │
└─────────────────────────────────────┘
```

### Требования
| Критерий | Требование |
|----------|------------|
| Адаптивность | 320px – 1920px+, mobile-first |
| Типографика | Fluid clamp(), 6 шагов |
| Цвета | OKLCH палитра, dark mode |
| Layout | Flexbox (header, cards), Grid (sections) |
| Контейнеры | Container Queries для карточек |
| Изображения | srcset/sizes, WebP/AVIF, lazy loading |
| Доступность | WCAG AA, focus-visible, prefers-reduced-motion |
| Производительность | LCP < 2.5s, CLS < 0.1, нет layout shifts |
| БЭМ | Блоки: header, hero, features, testimonials, pricing, footer |

## 4. Чек-лист качества (Definition of Done)

### HTML
- [ ] Семантические теги (header, main, section, article, footer, nav)
- [ ] ARIA labels где нужно (aria-label, aria-labelledby, aria-expanded)
- [ ] Alt тексты для всех изображений (пустые для декоративных)
- [ ] loading="lazy" для below-the-fold, eager для LCP
- [ ] width/height на всех img для предотвращения CLS

### CSS
- [ ] Cascade Layers в правильном порядке
- [ ] OKLCH цвета с color-mix() для вариаций
- [ ] Fluid typography clamp() на всех размерах
- [ ] Fluid spacing clamp() на всех отступах
- [ ] Container Queries для карточек
- [ ] Grid auto-fit/minmax для responsive сеток
- [ ] Flexbox для 1D layout (header, card innards)
- [ ] Logical properties (margin-inline, padding-block)
- [ ] Focus-visible стили на всех интерактивных
- [ ] prefers-reduced-motion поддержка
- [ ] prefers-color-scheme dark mode
- [ ] forced-colors поддержка (transparent borders → currentColor)

### Производительность
- [ ] Критический CSS инлайн или предзагружен
- [ ] Шрифты: font-display: swap, subset, preload
- [ ] Изображения: WebP/AVIF, правильные размеры, srcset
- [ ] Нет layout shifts (CLS = 0)
- [ ] LCP элемент (hero h1) без задержек

### Кодстайл
- [ ] БЭМ нейминг: block__element--modifier
- [ ] CSS переменные для всех повторяющихся значений
- [ ] Комментарии к секциям
- [ ] Нет !important (кроме utilities с комментарием)
- [ ] Нет ID селекторов для стилей

## 6. Ключевые выводы проекта

1. **Архитектура важнее кода** — Cascade Layers, токены, утилиты дают масштабируемость.
2. **Fluid-first подход** — clamp(), auto-fit, cqw убирают 80% медиа-запросов.
3. **Container Queries** — компоненты становятся真正 reusable.
4. **Доступность не опциональна** — focus-visible, reduced-motion, contrast — база.
5. **Производительность = UX** — правильные изображения, шрифты, нет CLS.
6. **БЭМ + Layers** = легко читать, легко менять, легко отдавать команде.
