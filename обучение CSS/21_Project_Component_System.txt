# Урок 21: Проект — адаптивная система компонентов с анимацией и проверкой доступности

## Цели проекта
- Построить полную систему компонентов: кнопка, карточка, модалка, навигация, фильтр
- Сделать всё адаптивным (mobile-first, 320px – 1920px+)
- Добавить анимации (appear, hover, модалка) с уважением `prefers-reduced-motion`
- Обеспечить доступность: WCAG AA контраст, `:focus-visible`, keyboard navigation, skip-link, ARIA
- Применить архитектуру из уроков 20: БЭМ, токены, @layer, design tokens
- Написать чек-лист качества и провести само-аудит

---

## 1. Техническое задание

### Компоненты системы
| Компонент | Состояния | Требования |
|-----------|-----------|------------|
| Кнопка (`.c-btn`) | default, hover, focus-visible, active, disabled, loading | Адаптивный размер, контраст, фокус |
| Карточка (`.c-card`) | default, hover, featured | Изображение, заголовок, текст, цена, кнопка |
| Модалка (`.c-modal`) | closed, open, closing | Focus trap, ESC закрывает, backdrop |
| Навигация (`.c-nav`) | default, scrolled, mobile | Skip-link, клавиатура, логика折�ения |
| Фильтр (`.c-filter`) | default, active, selected | Чекбоксы, радио, селект, доступность |

### Глобальные требования
| Критерий | Значение |
|----------|----------|
| Адаптивность | 320px – 1920px+, mobile-first |
| Типографика | Fluid `clamp()`, 6 шагов, rem |
| Цвета | OKLCH, dark mode, контраст ≥ 4.5:1 (AA) |
| Layout | Flexbox (1D), Grid (2D) |
| Контейнеры | Container Queries для карточек |
| Изображения | object-fit: cover, aspect-ratio, lazy loading |
| Доступность | WCAG AA, :focus-visible, prefers-reduced-motion, ARIA |
| Анимации | Уважение reduced motion, will-change, GPU-ускорение |
| Архитектура | БЭМ, токены, @layer, низкая специфичность |

## 11. JavaScript — модалка, навигация, фокус

```javascript
// app.js — минимальная интерактивность для доступности

// --- Модалка ---
const modalOverlay = document.querySelector('.c-modal__overlay');
const modalOpenBtns = document.querySelectorAll('[data-open-modal]');
const modalCloseBtn = document.querySelector('.c-modal__close');

function openModal() {
  modalOverlay.classList.add('is-open');
  document.body.classList.add('modal-open');
  // Переместить фокус внутрь модалки
  const firstFocusable = modalOverlay.querySelector(
    'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])'
  );
  if (firstFocusable) firstFocusable.focus();
}

function closeModal() {
  modalOverlay.classList.remove('is-open');
  document.body.classList.remove('modal-open');
  // Вернуть фокус на кнопку открытия
  const trigger = document.querySelector('[data-open-modal].aria-expanded="true"');
  if (trigger) trigger.focus();
}

modalOpenBtns.forEach(btn => {
  btn.addEventListener('click', openModal);
  btn.setAttribute('aria-expanded', 'false');
  btn.addEventListener('click', () => btn.setAttribute('aria-expanded', 'true'));
});

modalCloseBtn.addEventListener('click', closeModal);

modalOverlay.addEventListener('click', (e) => {
  if (e.target === modalOverlay) closeModal();
});

document.addEventListener('keydown', (e) => {
  if (e.key === 'Escape' && modalOverlay.classList.contains('is-open')) {
    closeModal();
  }
});

// --- Мобильная навигация ---
const menuToggle = document.querySelector('.c-nav__menu-toggle');
const navList = document.querySelector('.c-nav__list');

menuToggle.addEventListener('click', () => {
  const isOpen = navList.classList.toggle('is-open');
  menuToggle.setAttribute('aria-expanded', isOpen);
});

// Закрыть мобильное меню при клике на ссылку
document.querySelectorAll('.c-nav__link').forEach(link => {
  link.addEventListener('click', () => {
    navList.classList.remove('is-open');
    menuToggle.setAttribute('aria-expanded', 'false');
  });
});

// --- Фильтр ---
const filterBtn = document.querySelector('.c-filter__button');
filterBtn.addEventListener('click', () => {
  // Пример: применить фильтр, anunciar screen reader
  const resultCount = document.querySelector('.c-filter__result');
  if (resultCount) {
    resultCount.setAttribute('aria-live', 'polite');
    resultCount.textContent = 'Результаты обновлены';
  }
});
```

## 14. Само-аудит (что проверить в браузере)

1. **Контраст**: открой DevTools → Инспектор → выбери текст → проверь отношение контраста в палитре цветов (≥ 4.5:1)
2. **Фокус**: пройдись Tab по всей странице — каждый интерактивный элемент должен иметь чёткую обводку (`:focus-visible`)
3. **Мышь**: кликни на кнопку — обводки быть не должно (`:focus:not(:focus-visible)`)
4. **Масштаб**: Ctrl/Cmd + `+` до 200% — текст увеличивается, нет обрезки и горизонтальной прокрутки
5. **Модалка**: открой через Tab + Enter, попробуй сфокусироваться за пределами модалки (не должно получиться), нажми ESC — модалка закрывается, фокус возвращается на кнопку
6. **Reduced motion**: включи в настройках ОС «Уменьшить движение» — анимации модалки отключаются
7. **Темы**: переключи ОС в тёмную тему — цвета адаптируются (dark mode)
8. **Мобильный**: открой DevTools Device Toolbar (iPhone SE, 375px) — меню скрыто, карточки в одну колонку

## 16. Ключевые выводы

1. **Архитектура важнее кода** — БЭМ, токены, @layer дают масштабируемость и предсказуемость
2. **Доступность не опциональна** — фокус, контраст, клавиатура, ARIA — база любого компонента
3. **Mobile-first + контейнерные запросы** — компоненты адаптируются к контейнеру, не только к экрану
4. **Анимации с уважением пользователя** — `prefers-reduced-motion` обязательно
5. **Тёмная тема через токены** — одна переменная, весь интерфейс перекрашивается
6. **Само-аудит перед сдачей** — проверяй контраст, фокус, масштаб, модалку, тёмную тему в реальном браузере
