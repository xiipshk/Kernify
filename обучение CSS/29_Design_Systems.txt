# Урок 29: Дизайн-системы — токены, темы, custom properties, конвенции компонентов, мультибрендовые системы

## Цели урока
- Понять структуру дизайн-системы: примитивы, семантические токены, компонентные токены
- Научиться создавать и использовать CSS-переменные как дизайн-токены
- Построить систему тем (light/dark, брендовые темы) через custom properties
- Определить конвенции компонентов (наименование, структура, варианты)
- Создать мультибрендовую систему с переключением тем

## 1. Что такое дизайн-система

Дизайн-система — это набор повторно используемых компонентов, правил и ограничений, которые обеспечивают консистентность интерфейса между продуктами и командами.

### Уровни дизайн-системы
```
Дизайн-система
├── Токены (примитивы)       — цвета, отступы, шрифты, радиусы, тени
├── Семантические токены     — --color-primary, --space-section
├── Компонентные токены      --btn-padding, --card-radius
├── Компоненты                — кнопка, карточка, модалка, инпут
├── Шаблоны                    — страница, форма, дашборд
└── Страницы                    — главная, профиль, настройки
```

### Дизайн-токены — единственный источник истины
Токены — это именованные значения, которые используются вместо хардкода:
```css
/* Плохо — хардкод */
.btn {
  background: #2563eb;
  padding: 8px 16px;
  border-radius: 4px;
}

/* Хорошо — токены */
.btn {
  background: var(--color-primary);
  padding: var(--space-sm) var(--space-md);
  border-radius: var(--radius-md);
}
```

## 2. Структура токенов: Primitive → Semantic → Component

### Примитивы (Primitive tokens)
Базовые значения без привязки к назначению.

```css
:root {
  /* Цвета — OKLCH */
  --primitive-color-slate-50: oklch(0.98 0.001 285);
  --primitive-color-slate-100: oklch(0.96 0.003 285);
  --primitive-color-slate-900: oklch(0.21 0.006 285);
  --primitive-color-blue-500: oklch(0.62 0.22 264);
  --primitive-color-blue-600: oklch(0.55 0.22 264);
  --primitive-color-green-500: oklch(0.75 0.18 150);
  --primitive-color-red-500: oklch(0.65 0.22 20);

  /* Отступы */
  --primitive-space-xs: 0.25rem;
  --primitive-space-sm: 0.5rem;
  --primitive-space-md: 1rem;
  --primitive-space-lg: 1.5rem;
  --primitive-space-xl: 2rem;
  --primitive-space-2xl: 3rem;

  /* Размеры шрифтов */
  --primitive-fs-xs: 0.75rem;
  --primitive-fs-sm: 0.875rem;
  --primitive-fs-base: 1rem;
  --primitive-fs-lg: 1.125rem;
  --primitive-fs-xl: 1.25rem;
  --primitive-fs-2xl: 1.5rem;
  --primitive-fs-3xl: 2rem;

  /* Радиусы */
  --primitive-radius-sm: 0.25rem;
  --primitive-radius-md: 0.5rem;
  --primitive-radius-lg: 1rem;
  --primitive-radius-full: 9999px;

  /* Тени */
  --primitive-shadow-sm: 0 1px 2px rgb(0 0 0 / 0.05);
  --primitive-shadow-md: 0 4px 6px -1px rgb(0 0 0 / 0.1);
  --primitive-shadow-lg: 0 10px 15px -3px rgb(0 0 0 / 0.1);
}
```

### Семантические токены (Semantic tokens)
Назначение в интерфейсе, не привязанное к конкретному компоненту.

```css
:root {
  /* Цвета */
  --color-bg: var(--primitive-color-slate-50);
  --color-bg-inverted: var(--primitive-color-slate-950);
  --color-text: var(--primitive-color-slate-900);
  --color-text-inverted: var(--primitive-color-slate-50);
  --color-muted: oklch(0.55 0.01 285);
  --color-border: oklch(0.88 0.006 285);

  /* Семантические цвета */
  --color-primary: var(--primitive-color-blue-600);
  --color-primary-hover: var(--primitive-color-blue-500);
  --color-primary-active: var(--primitive-color-blue-700);
  --color-success: var(--primitive-color-green-500);
  --color-error: var(--primitive-color-red-500);
  --color-warning: oklch(0.80 0.15 60);

  /* Отступы */
  --space-xs: var(--primitive-space-xs);
  --space-sm: var(--primitive-space-sm);
  --space-md: var(--primitive-space-md);
  --space-lg: var(--primitive-space-lg);
  --space-xl: var(--primitive-space-xl);
  --space-2xl: var(--primitive-space-2xl);

  /* Размеры шрифтов */
  --fs-xs: var(--primitive-fs-xs);
  --fs-sm: var(--primitive-fs-sm);
  --fs-base: var(--primitive-fs-base);
  --fs-lg: var(--primitive-fs-lg);
  --fs-xl: var(--primitive-fs-xl);
  --fs-2xl: var(--primitive-fs-2xl);
  --fs-3xl: var(--primitive-fs-3xl);

  /* Радиусы */
  --radius-sm: var(--primitive-radius-sm);
  --radius-md: var(--primitive-radius-md);
  --radius-lg: var(--primitive-radius-lg);
  --radius-full: var(--primitive-radius-full);

  /* Тени */
  --shadow-sm: var(--primitive-shadow-sm);
  --shadow-md: var(--primitive-shadow-md);
  --shadow-lg: var(--primitive-shadow-lg);

  /* Линейная высота */
  --line-height-tight: 1.1;
  --line-height-base: 1.6;
}
```

### Компонентные токены (Component tokens)
Значения, специфичные для компонента.

```css
:root {
  /* Кнопка */
  --btn-padding-sm: var(--space-xs) var(--space-sm);
  --btn-padding-md: var(--space-sm) var(--space-md);
  --btn-padding-lg: var(--space-md) var(--space-lg);
  --btn-font-size-sm: var(--fs-xs);
  --btn-font-size-md: var(--fs-sm);
  --btn-font-size-lg: var(--fs-base);
  --btn-height-sm: 36px;
  --btn-height-md: 44px;
  --btn-height-lg: 52px;
  --btn-radius: var(--radius-md);

  /* Карточка */
  --card-padding: var(--space-lg);
  --card-radius: var(--radius-lg);
  --card-border: 1px solid var(--color-border);
  --card-shadow: var(--shadow-md);

  /* Модалка */
  --modal-max-width: 560px;
  --modal-padding: var(--space-xl);
  --modal-radius: var(--radius-lg);

  /* Навигация */
  --nav-height: 64px;
  --nav-item-padding: var(--space-xs) 0;
}
```

## 3. Темы через CSS-переменные

### Светлая тема (по умолчанию)
```css
:root {
  --color-bg: var(--primitive-color-slate-50);
  --color-text: var(--primitive-color-slate-900);
  --color-border: oklch(0.88 0.006 285);
  --color-muted: oklch(0.55 0.01 285);
}
```

### Темная тема (через медиа-запрос)
```css
@media (prefers-color-scheme: dark) {
  :root {
    --color-bg: var(--primitive-color-slate-950);
    --color-text: var(--primitive-color-slate-50);
    --color-border: oklch(0.28 0.006 285);
    --color-muted: oklch(0.55 0.01 285);
  }
}
```

### Темная тема (через класс — ручное переключение)
```html
<body data-theme="dark">
```

```css
[data-theme="dark"] {
  --color-bg: var(--primitive-color-slate-950);
  --color-text: var(--primitive-color-slate-50);
  --color-border: oklch(0.28 0.006 285);
  --color-muted: oklch(0.55 0.01 285);
}

[data-theme="light"] {
  --color-bg: var(--primitive-color-slate-50);
  --color-text: var(--primitive-color-slate-900);
  --color-border: oklch(0.88 0.006 285);
  --color-muted: oklch(0.55 0.01 285);
}
```

### JS-переключатель темы
```javascript
const themeToggle = document.querySelector('#theme-toggle');
const html = document.documentElement;

// Загрузка сохраненной темы
const savedTheme = localStorage.getItem('theme') || 'light';
html.setAttribute('data-theme', savedTheme);
themeToggle.checked = savedTheme === 'dark';

// Переключение
themeToggle.addEventListener('change', () => {
  const newTheme = themeToggle.checked ? 'dark' : 'light';
  html.setAttribute('data-theme', newTheme);
  localStorage.setItem('theme', newTheme);
});
```

## 4. Мультибрендовые системы

### Концепция
Одна кодовая база, несколько брендов через переопределение токенов.

```html
<!-- Бренд A -->
<body data-brand="brand-a">

<!-- Бренд B -->
<body data-brand="brand-b">
```

```css
:root {
  /* Базовые токены (общие) */
  --color-bg: var(--primitive-color-slate-50);
  --color-text: var(--primitive-color-slate-900);
  --space-md: var(--primitive-space-md);
}

/* Бренд A — синяя гамма */
[data-brand="brand-a"] {
  --color-primary: var(--primitive-color-blue-600);
  --color-primary-hover: var(--primitive-color-blue-500);
  --color-success: var(--primitive-color-green-500);
  --color-error: var(--primitive-color-red-500);
  --font-family: 'Inter', system-ui, sans-serif;
}

/* Бренд B — зелёная гамма */
[data-brand="brand-b"] {
  --color-primary: oklch(0.65 0.18 150);
  --color-primary-hover: oklch(0.58 0.18 150);
  --color-success: oklch(0.70 0.15 140);
  --color-error: oklch(0.60 0.20 25);
  --font-family: 'Roboto', system-ui, sans-serif;
}

/* Бренд C — фиолетовая гамма */
[data-brand="brand-c"] {
  --color-primary: oklch(0.60 0.20 280);
  --color-primary-hover: oklch(0.52 0.20 280);
  --color-success: oklch(0.72 0.16 160);
  --color-error: oklch(0.62 0.21 15);
  --font-family: 'Poppins', system-ui, sans-serif;
}

/* Компоненты используют семантические токены — автоматически перекрашиваются */
.btn--primary {
  background: var(--color-primary);
  color: white;
  font-family: var(--font-family);
}
```

### Пример мультибренда — кнопка
```html
<!-- Бренд A — синяя кнопка -->
<button data-brand="brand-a" class="btn btn--primary">Кнопка A</button>

<!-- Бренд B — зелёная кнопка -->
<button data-brand="brand-b" class="btn btn--primary">Кнопка B</button>
```

```css
.btn--primary {
  background: var(--color-primary);
  color: white;
  border: none;
  border-radius: var(--radius-md);
  padding: var(--space-sm) var(--space-md);
  font-family: var(--font-family);
  font-size: var(--fs-sm);
  font-weight: 600;
  cursor: pointer;
  transition: background 0.2s;
}

.btn--primary:hover {
  background: var(--color-primary-hover);
}
```

## 5. Конвенции компонентов

### Именование классов (БЭМ + префиксы)
```
c-    — компонент (component)
u-    — утилита (utility)
l-    — layout (layout)
is-   — состояние (state)
has-  — состояние (state)
t-    — тема (theme)
js-   — только для JS, не стилизуется
```

### Примеры
```html
<!-- Компонент -->
<button class="c-btn c-btn--primary is-loading">Отправить</button>

<!-- Утилита -->
<div class="u-text-center u-mt-lg">Текст по центру</div>

<!-- Layout -->
<div class="l-container l-grid-3">...</div>

<!-- Состояние -->
<input class="c-input is-invalid is-focused">

<!-- Тема -->
<div class="t-brand-a t-theme-dark">...</div>

<!-- JS хук -->
<button class="js-modal-open">Открыть модалку</button>
```

### Структура компонента
```
c-btn/
├── c-btn.css           (стили компонента)
├── c-btn.html          (пример HTML)
├── c-btn.demo.html     (живой пример)
├── c-btn.test.html     (тесты доступности)
└── README.md           (документация использования)
```

### Варианты компонента (API)
```css
/* c-btn — базовые стили */
.c-btn {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  gap: var(--space-xs);
  padding: var(--space-sm) var(--space-md);
  font-size: var(--fs-sm);
  font-weight: 600;
  border-radius: var(--radius-md);
  border: none;
  cursor: pointer;
  min-height: 44px;
  transition: background 0.2s, border-color 0.2s, transform 0.1s;
}

/* Варианты (variants) */
.c-btn--primary { background: var(--color-primary); color: white; }
.c-btn--secondary { background: transparent; color: var(--color-primary); border: 1px solid var(--color-primary); }
.c-btn--ghost { background: transparent; color: var(--color-text); }
.c-btn--danger { background: var(--color-error); color: white; }

/* Размеры (sizes) */
.c-btn--sm { padding: var(--space-xs) var(--space-sm); font-size: var(--fs-xs); min-height: 36px; }
.c-btn--md { padding: var(--space-sm) var(--space-md); font-size: var(--fs-sm); min-height: 44px; }
.c-btn--lg { padding: var(--space-md) var(--space-lg); font-size: var(--fs-base); min-height: 52px; }

/* Состояния (states) */
.c-btn:disabled { opacity: 0.5; cursor: not-allowed; }
.c-btn.is-loading { opacity: 0.7; cursor: not-allowed; pointer-events: none; }
.c-btn:focus-visible { outline: 3px solid var(--color-primary); outline-offset: 2px; }
```

### Правила конвенций
1. Компоненты именуются с префиксом `c-`
2. Модификаторы через `--`, элементы через `__`
3. Состояния через `is-` или `has-`
4. Утилиты через `u-` — одно свойство = один класс
5. JS-хуки через `js-` — никогда не стилизуются
6. Темы через `t-` или `data-` атрибуты

## 8. Чек-лист дизайн-системы

| Критерий | Статус |
|----------|--------|
| Примитивные токены для всех цветов, отступов, шрифтов | ☐ |
| Семантические токены (--color-primary, --space-md) | ☐ |
| Компонентные токены (--btn-padding, --card-radius) | ☐ |
| Темы через data-атрибуты (light/dark, brand-a/brand-b) | ☐ |
| Мультибрендовая поддержка (разные бренды на одной кодовой базе) | ☐ |
| Конвенции命名 (c-, u-, l-, is-, has-, t-, js-) | ☐ |
| БЭМ именование (block__element--modifier) | ☐ |
| Нет хардкода цветов и отступов в компонентах | ☐ |
| Все компоненты используют токены | ☐ |
| Документация токенов и компонентов | ☐ |

## 9. Практическое задание

### Задача 1: Система токенов
Создай файл `tokens.css` с:
- Примитивами: цвета (OKLCH), отступы, размеры шрифтов, радиусы, тени
- Семантическими токенами: --color-primary, --color-bg, --color-text, --space-md, --fs-base
- Компонентными токенами: --btn-padding, --card-radius, --modal-max-width

### Задача 2: Система тем
Создай переключатель тем:
- Светлая тема (по умолчанию)
- Темная тема через `data-theme="dark"`
- JS-переключатель с сохранением в localStorage
- Проверь, что все компоненты автоматически перекрашиваются

### Задача 3: Мультибренд
Создай два бренда на одной кодовой базе:
- Бренд A: синяя гамма, шрифт Inter
- Бренд B: зелёная гамма, шрифт Roboto
- Переключение через `data-brand="brand-a"` / `data-brand="brand-b"`
- Одинаковая структура компонентов, разные цвета и шрифты

### Задача 4: Компонентная библиотека

## 11. Ключевые выводы

1. **Дизайн-токены** — единственный источник истины для цветов, отступов, шрифтов, радиусов
2. **Три уровня токенов** — примитивы → семантические → компонентные
3. **Темы через CSS-переменные** — одна переменная, весь интерфейс перекрашивается (light/dark, бренды)
4. **Мультибренд** — одна кодовая база, разные бренды через data-атрибуты и переопределение токенов
5. **Конвенции命名** — c-, u-, l-, is-, has-, t-, js- префиксы для понятности кода
6. **БЭМ** — block__element--modifier для структуры компонентов
7. **Никакого хардкода** — все значения через токены
8. **Документация** — таблица токенов, примеры компонентов, правила использования
