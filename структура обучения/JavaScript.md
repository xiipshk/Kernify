# Курс JavaScript

## 1. Новичок

1.  **Введение:** JavaScript, browser console, подключение скрипта,
    первая программа.
2.  **Переменные/типы:** `let`, `const`, `var`, numbers, strings,
    Boolean, `null`, `undefined`, conversions.
3.  **Операторы/условия:** arithmetic, comparisons, `===`, logic, `if`,
    `switch`.
4.  **Циклы:** `while`, `for`, `for...of`, `break`, `continue`.
5.  **Функции:** declarations, parameters, return, expressions, arrow
    functions, scope.
6.  **Массивы:** создание, индексы, изменение, iteration, основные
    методы.
7.  **Объекты:** properties, methods, nested objects, arrays of objects.
8.  **DOM:** поиск/изменение элементов, events, forms, user input.
9.  **Асинхронность basics:** timers, Promises, `async/await`.
10. **Проект:** интерактивная web page и debugging.

## 2. Средний уровень

1.  **Семантика:** types, coercion, equality, references, object
    copying.
2.  **Scope/closures:** lexical scope, hoisting, closures, execution
    context, `this`.
3.  **Функциональный стиль:** higher-order functions, callbacks, pure
    functions, `map/filter/reduce`.
4.  **Прототипы/classes:** prototype chain, `class`, inheritance,
    getters/setters.
5.  **Modules/tooling:** ES modules, npm, project structure, bundlers.
6.  **Async:** event loop, task/microtask queues, Promises, errors,
    concurrent requests.
7.  **Browser APIs:** DOM/events, Fetch, storage, URL/history, forms.
8.  **Node.js:** runtime, modules, filesystem, HTTP server, environment
    variables.
9.  **Code quality:** JSDoc, TypeScript intro, ESLint, tests, debugging.
10. **Security/performance:** XSS, validation, profiling, memory, web
    optimization.
11. **Проект:** modular app with API, tests and build.

## 3. Углублённый уровень

1.  **ECMAScript/runtime:** specification, types, abstract operations,
    execution contexts, environment records.
2.  **Objects/prototypes:** property descriptors, prototype inheritance,
    `Reflect`, `Proxy`, private fields.
3.  **Functions:** lexical environments, `this`, `call/apply/bind`,
    generators, iterators.
4.  **Async internals:** event loop, Promise resolution, cancellation,
    AbortController, workers, async iterators.
5.  **Modules/metaprogramming:** cycles, dynamic import, resolution,
    reflection, library design.
6.  **Browser platform:** rendering pipeline, layout/paint/compositing,
    Web Components, Service Workers, security model.
7.  **Node internals:** event-driven design, streams, buffers, worker
    threads, processes, IPC.
8.  **Performance:** profiling, memory leaks, rendering, JIT concepts,
    data structures.
9.  **Security:** XSS, CSRF, same-origin policy, CSP, dependency
    security.
10. **Large app engineering:** TypeScript, tree shaking, integration
    tests, CI/CD, monitoring.
11. **Проект:** advanced application/library with architecture, security
    review and performance tests.

**Методика:** различать браузерную и Node.js среды; проверять
совместимость API и опираться на актуальные спецификации.
