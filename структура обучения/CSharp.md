# Курс C

Указывать целевую версию C# и .NET: некоторые функции зависят от версии.

## 1. Новичок

1.  **Введение:** C#, .NET, setup, project, run, first program.
2.  **Переменные/типы:** numeric types, string, bool, `var`, `const`,
    conversions.
3.  **Операторы/условия:** arithmetic, comparisons, logic, `if/else`,
    `switch`.
4.  **Циклы:** `while`, `do`, `for`, `foreach`, `break`, `continue`.
5.  **Методы:** declaration, parameters, return, overloads, scope.
6.  **Массивы/строки:** arrays, indexing, iteration, interpolation,
    string methods.
7.  **Коллекции:** `List<T>`, `Dictionary<TKey,TValue>`, `HashSet<T>`.
8.  **Классы/объекты:** fields, properties, constructors, methods,
    encapsulation, inheritance basics.
9.  **Исключения/файлы:** try/catch/finally, exceptions, file I/O,
    paths.
10. **LINQ basics:** filtering, projection, sorting, querying
    collections.
11. **Проект:** console app, classes, error handling, basic tests.

## 2. Средний уровень

1.  **Type system:** value/reference types, nullable, boxing/unboxing,
    struct/record/class, immutability.
2.  **ООП/design:** interfaces, abstract classes, polymorphism,
    composition, generics.
3.  **Delegates/events:** delegates, lambdas, events, `Func`, `Action`,
    `Predicate`, subscription.
4.  **LINQ:** query/method syntax, deferred execution,
    `IEnumerable`/`IQueryable`, grouping/join.
5.  **Collections/algorithms:** interfaces, data structures,
    comparison/sorting, iterators, `yield`.
6.  **Async:** `Task`, `async/await`, `CancellationToken`, errors,
    parallel operations.
7.  **.NET internals:** CLR, IL, JIT, managed memory, GC, assemblies.
8.  **Testing/quality:** unit/mocking/integration tests, analyzers,
    debugging.
9.  **Data:** JSON, files/streams, SQL basics, database access, ORM
    introduction.
10. **App development:** configuration, logging, dependency injection,
    APIs, ASP.NET Core basics.
11. **Проект:** layered app with DB/API, tests, logging and error
    handling.

## 3. Углублённый уровень

1.  **Advanced type system:** generic constraints, variance, nullable
    reference types, pattern matching, records.
2.  **Language/runtime internals:** IL, attributes, reflection,
    expression trees, source generators.
3.  **Advanced C#:** extension members where supported, operator
    overloading, indexers, `ref/in/out`, spans, unsafe.
4.  **Memory:** GC, generations, finalizers, `IDisposable`,
    `Span<T>`/`Memory<T>`, allocation reduction.
5.  **Async/concurrency:** async internals, scheduling, `ValueTask`,
    Channels, Parallel/PLINQ, synchronization.
6.  **Performance:** BenchmarkDotNet, profiling, JIT/tiered compilation,
    memory optimization.
7.  **Architecture:** DI, middleware, Clean Architecture and
    alternatives, CQRS trade-offs, API design.
8.  **Advanced .NET:** ASP.NET Core, EF Core, networking, background
    services, observability.
9.  **Testing/reliability:** unit/integration/contract, property-based,
    performance tests, resilience.
10. **Platforms/ecosystem:** .NET versions, publishing, containers,
    cross-platform, dependency compatibility.
11. **Проект:** complex app/library with architecture, tests, profiling,
    docs, maintenance.

**Методика:** фиксировать версии C#/.NET; запускать примеры и тесты;
отмечать version-specific APIs.
