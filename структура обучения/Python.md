# Курс Python

Три траектории. Каждый модуль можно разделить на уроки; итоговый тест
темы включает и материал пропущенных уроков.

## 1. Новичок

1.  **Введение:** назначение Python, установка, запуск, `print`,
    комментарии, ошибки.
2.  **Переменные и типы:** присваивание, числа, строки, Boolean,
    преобразования, `input`.
3.  **Операторы:** арифметика, сравнения, логика, приоритет.
4.  **Условия:** `if/elif/else`, вложенные условия, условные выражения.
5.  **Циклы:** `while`, `for`, `range`, `break`, `continue`, вложенные
    циклы.
6.  **Коллекции:** списки, кортежи, множества, словари, перебор и
    изменение.
7.  **Строки:** индексы, срезы, методы, форматирование, поиск.
8.  **Функции:** объявление, параметры, возврат, область видимости.
9.  **Файлы и ошибки:** чтение/запись, пути, `try/except/finally`.
10. **ООП:** классы, объекты, `__init__`, атрибуты, методы,
    наследование, композиция.
11. **Модули и проект:** импорт, пакеты, `pip`, консольное приложение.

## 2. Средний уровень

1.  **Модель объектов:** ссылки, изменяемость, истинность, `is` и `==`.
2.  **Коллекции и алгоритмы:** вложенные структуры, comprehensions,
    сортировка, стек/очередь, хеширование.
3.  **Функции глубже:** `*args`, `**kwargs`, lambda, замыкания,
    декораторы, рекурсия.
4.  **Итераторы/генераторы:** протокол итерации, `iter`, `next`,
    `yield`, generator expressions.
5.  **ООП глубже:** полиморфизм, композиция, миксины, свойства,
    дескрипторы, magic methods.
6.  **Организация проекта:** пакеты, импорты, виртуальные окружения,
    зависимости.
7.  **Тестирование:** исключения, собственные ошибки, unit-тесты,
    mocking, edge cases.
8.  **Типизация:** аннотации, `typing`, generics, protocols, статическая
    проверка.
9.  **Данные и сеть:** JSON/CSV, HTTP/API, SQL и базы данных.
10. **Асинхронность/производительность:** context managers,
    `async/await`, `asyncio`, threads/processes, profiling.
11. **Проект:** приложение с модулями, тестами, типизацией и
    документацией.

## 3. Углублённый уровень

1.  **Модель данных:** протоколы объектов, жизненный цикл, GC,
    `__new__`, сравнение и хеширование.
2.  **Объектный механизм:** descriptors, metaclasses, MRO, multiple
    inheritance, ABC.
3.  **Функциональные internals:** closures, parameterized decorators,
    introspection, signatures, annotations.
4.  **Продвинутая типизация:** `TypeVar`, `ParamSpec`, `TypeVarTuple`,
    `Protocol`, `TypedDict`, `Literal`, variance.
5.  **Concurrency:** event loop, cancellation, asyncio errors,
    threads/processes, synchronization, GIL.
6.  **Память и performance:** CPU/memory profiling, caching, allocation,
    C extensions.
7.  **Профессиональные инструменты:** packaging/publishing, linters,
    formatters, type checkers, CI.
8.  **Security/reliability:** input validation, secrets, safe
    deserialization, dependency vulnerabilities, logging.
9.  **Экосистема:** web, automation, scientific computing, databases,
    выбор инструментов.
10. **Изучение языка:** PEP, CPython source, C API, version
    compatibility.
11. **Продвинутый проект:** библиотека или приложение с архитектурой,
    тестами и документацией.

**Методика:** зафиксировать версию Python; проверять код запуском и
тестами; добавлять источники и дату проверки.
