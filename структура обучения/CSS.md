# Курс CSS

CSS --- язык стилей, а не язык программирования общего назначения. Курсы
посвящены оформлению, макетам, адаптивности, доступности и архитектуре
стилей.

## 1. Новичок

1.  **Введение:** роль CSS/HTML, подключение stylesheets, rules,
    comments.
2.  **Selectors/cascade:** element/class/ID, combinators,
    pseudo-classes, specificity, inheritance.
3.  **Цвета/текст:** color formats, fonts, typography, line-height.
4.  **Box model:** width/height, padding, border, margin, box-sizing,
    overflow.
5.  **Layout basics:** display, block/inline, position, z-index,
    document flow.
6.  **Flexbox:** axes, alignment, wrapping, gaps, flex sizing.
7.  **Grid:** rows/columns, track sizing, placement, simple grids.
8.  **Фоны/эффекты:** backgrounds, borders, radius, shadows, opacity.
9.  **Responsive basics:** units, media queries, phone/desktop layouts.
10. **Проект:** styled page, cards, navigation, mobile adaptation.

## 2. Средний уровень

1.  **Cascade/architecture:** specificity, cascade layers,
    `:is/:where/:not/:has`, custom properties.
2.  **Advanced Flex/Grid:** complex layouts, `minmax`,
    `auto-fit/auto-fill`, nested grids, grid areas.
3.  **Responsive design:** mobile-first, container queries, fluid
    typography, `clamp()`.
4.  **Positioning/layers:** sticky/fixed, stacking contexts, overflow,
    overlays.
5.  **Visual effects:** pseudo-elements, gradients, masks, filters,
    blend modes.
6.  **Transitions/animations:** transitions, transforms, keyframes,
    reduced motion.
7.  **Modern CSS:** aspect-ratio, object-fit, focus-visible, logical
    properties, color functions.
8.  **Accessibility:** focus, contrast, text scaling, keyboard
    interaction states.
9.  **Debugging/compatibility:** DevTools, computed styles, progressive
    enhancement.
10. **CSS architecture:** BEM/alternatives, component styles, design
    tokens, conflict reduction.
11. **Проект:** responsive component system with animation and
    accessibility checks.

## 3. Углублённый уровень

1.  **Cascade model:** origins/priorities, layers, specificity,
    inheritance, shorthands, `@scope`.
2.  **Advanced layout:** grid track sizing, subgrid, flex sizing,
    intrinsic sizing, containing blocks.
3.  **Container systems:** container queries/units, fluid layouts,
    component breakpoints.
4.  **Selectors/logical properties:** complex `:has()`, writing modes,
    `@supports`, progressive enhancement.
5.  **Animation/effects:** compositing, 3D transforms, masks, filters,
    performance, reduced motion.
6.  **Emerging CSS:** nesting, `@property`, new functions/color spaces,
    scroll-driven animations where supported.
7.  **Rendering performance:** style/layout/paint/compositing, layout
    thrashing, animation profiling.
8.  **Design systems:** tokens, themes, custom properties, component
    conventions, multi-brand systems.
9.  **Accessibility/i18n:** contrast, focus, reduced motion, RTL,
    logical properties, text zoom.
10. **Tooling:** PostCSS, preprocessors, CSS Modules, CSS-in-JS
    trade-offs, linting, visual regression.
11. **Проект:** scalable design system, responsive components,
    accessibility/performance audits.

**Методика:** учитывать поддержку браузеров; оценивать адаптивность,
доступность и поддерживаемость, а не только внешний вид.
