## ПРИМЕЧАНИЯ ПО ИСПОЛЬЗОВАНИЮ

1. **Комбинируй форматы**: читай главу в книге/туториале → сразу решай соответствующие упражнения на Exercism/Practice Python
2. **Exercism уникально** — бесплатное менторство на каждом упражнении (code review от живых людей)
3. **Corey Schafer** — лучшие видео для визуального понимания сложных тем (декораторы, генераторы, ООП, async)
4. **Real Python** — лучший источник для "промежуточного" уровня: глубже туториалов, но доступнее официальных доков
5. **Fluent Python** — "библия" для перехода на Senior/Advanced уровень (читать по главам, параллельно с кодом)
6. **Официальные доки** — всегда в закладках для точного референса (typing, asyncio, datamodel, library reference)
