# 1.1. Введение в Python

Что такое Python, зачем нужен интерпретатор, как установить язык и запустить первую программу.

Python удобен для первого знакомства с программированием: его код читается почти как обычная инструкция, а ошибки сопровождаются понятным объяснением. На Python пишут веб-сервисы, обрабатывают таблицы, обучают модели машинного обучения и автоматизируют рутинные задачи.

В этом уроке мы пройдём путь от установки языка до первой работающей программы. Заодно разберёмся, что такое интерпретатор, зачем нужна командная строка и как читать сообщения об ошибках. Последний навык особенно важен: новичок тратит больше всего времени именно на разбор непонятных красных сообщений.

## Чему вы научитесь

- объяснять, чем Python отличается от компилируемых языков и где он применяется;
- устанавливать Python 3 и проверять его версию в терминале;
- запускать код двумя способами: в интерактивной оболочке и из файла `.py`;
- выводить текст и значения функцией `print()`, включая настройку разделителя и перевода строки;
- писать комментарии, которые объясняют причину решения, а не пересказывают код;
- читать `traceback` и понимать пять ошибок, с которыми новичок встречается чаще всего.

## Что такое Python

Python — это **высокоуровневый интерпретируемый язык программирования общего назначения**. В определении важен каждый эпитет, поэтому разберём их по отдельности.

- **Язык программирования** — формальный набор правил, с помощью которого человек записывает команды для компьютера. Компьютер не понимает русский или английский текст, поэтому команды нужно оформлять по строгим правилам синтаксиса.
- **Высокоуровневый** — операции записываются близко к человеческим понятиям: сложить числа, взять элемент списка, открыть файл. Python сам управляет памятью, поэтому начинающему не нужно вручную резервировать и освобождать её, как в C или C++.
- **Интерпретируемый** — исходный код выполняется специальной программой-интерпретатором построчно, без отдельного этапа сборки в машинный код. Это ускоряет запуск и упрощает отладку, хотя итоговая скорость работы обычно ниже, чем у компилируемых языков.
- **Общего назначения** — язык не привязан к одной задаче. На нём можно написать и короткий скрипт для переименования файлов, и сервер, обслуживающий миллионы запросов.

Python создал Гвидо ван Россум в конце 1980-х годов, а первая публичная версия вышла в 1991 году. Сегодня язык развивает большое сообщество, а его библиотеки покрывают веб-разработку, научные расчёты, автоматизацию и машинное обучение.

> **Почему сразу Python 3**
> Вторая и третья версии Python несовместимы по части синтаксиса и стандартной библиотеки. Python 2 больше не поддерживается, поэтому весь код в курсе рассчитан на Python 3.

## Как Python выполняет программу

**Программа** — это последовательность инструкций, которые нужно выполнить по порядку. В компилируемых языках, например в C++ или Rust, исходный текст сначала целиком переводится компилятором в машинный код, а уже потом запускается. В Python отдельного шага сборки нет: **интерпретатор** читает очередную инструкцию, выполняет её и переходит к следующей.

У такого подхода есть компромисс. С одной стороны, программу можно запустить сразу после изменения — не нужно ждать компиляцию. С другой — интерпретатору приходится разбирать код во время работы, поэтому Python обычно медленнее языков, которые компилируются заранее. Для обучения и большинства прикладных задач этой скорости достаточно.

```python
print("Привет, мир!")
```

Если сохранить эту строку в файл и запустить, на экране появится текст:

```text
Привет, мир!
```

Разберём строку по частям, потому что в ней уже есть несколько важных понятий.

1. `print` — имя **функции**. Функция — это готовая команда, которая выполняет действие. В данном случае она выводит данные на экран.
2. Круглые скобки `()` означают **вызов функции**. Без скобок мы просто упомянули бы функцию, но не попросили её выполниться.
3. `"Привет, мир!"` — **аргумент**, то есть значение, которое передаётся функции. Здесь аргумент один.
4. Текст в кавычках называется **строкой**. Строка — последовательность символов: букв, цифр, пробелов и знаков препинания.

> **Термин: строка**
> Строка — значение, заключённое в одинарные или двойные кавычки: `"привет"`, `'Python'`, `"42"`. Кавычки являются частью записи, но в выводимый текст они не попадают.

Python умеет не только выводить готовый текст, но и вычислять выражения. **Выражение** — запись, которую можно вычислить и получить значение.

```python
print(2 + 2)
```

```text
4
```

Здесь `2` и `2` — целые числа, а `+` — оператор сложения. Python вычисляет сумму и передаёт результат `4` в `print`. Обратите внимание: кавычек нет, поэтому это не текст, а число. Если написать `"2" + "2"`, Python соединит две строки и выведет `22` — смысл операции изменится.

## Где Python применяется

Python выбирают не только за простой синтаксис, но и за готовые библиотеки. **Библиотека** — набор функций и классов, который решает отдельный круг задач и подключается к программе. Вот несколько направлений, где Python особенно заметен.

| Направление | Инструменты | Что делают |
|---|---|---|
| Веб-разработка | Django, FastAPI, Flask | Создают серверную часть сайтов и API. Django — веб-фреймворк, то есть набор готовых компонентов для маршрутов, базы данных и админки. |
| Анализ данных | pandas, NumPy | pandas работает с таблицами, похожими на Excel. NumPy добавляет быстрые массивы и математические операции над ними. |
| Машинное обучение | scikit-learn, PyTorch, TensorFlow | Позволяют строить модели, которые находят закономерности в данных: от предсказания цены до распознавания изображений. |
| Автоматизация | стандартная библиотека, requests | Избавляют от ручной работы: переименовать сотни файлов, собрать данные с сайта, отправить отчёт по расписанию. |
| Тестирование | pytest, Playwright | Проверяют, что программа работает правильно. pytest запускает тесты, Playwright управляет браузером и проверяет интерфейс. |

Выбор Python для старта не означает, что другие языки не нужны. Он даёт быстрый вход в программирование, а затем вы сможете изучить инструменты под конкретную задачу: например, C++ для игровых движков или Rust для системного кода.

## Установка Python

Чтобы выполнять код, нужен **интерпретатор** — программа, которая читает файл с кодом Python и выполняет его инструкции. Проще всего установить официальную сборку с сайта python.org или воспользоваться пакетным менеджером системы.

### Windows

1. Откройте страницу `python.org/downloads` и скачайте установщик для Windows.
2. Запустите установщик. На первом экране обязательно отметьте галочку **Add python.exe to PATH**.
3. Нажмите **Install Now** и дождитесь завершения.
4. Откройте PowerShell или командную строку и проверьте установку командой `py --version`.

`PATH` — это список папок, в которых система ищет программы по имени. Если Python не добавлен в `PATH`, команда `python` не будет найдена, хотя сам интерпретатор установлен. Команда `py` — отдельный лаунчер Windows, который сам находит нужную версию Python.

```bash
py --version
# Пример вывода: Python 3.12.3
```

### macOS

В macOS удобнее установить Python через **Homebrew** — менеджер пакетов, который скачивает программы и их зависимости из проверенных репозиториев. Если Homebrew ещё не установлен, инструкция есть на `brew.sh`.

```bash
brew install python
python3 --version
```

Не удаляйте системный Python, который уже есть в macOS: он нужен операционной системе. Для учебных проектов используйте отдельную установку и команду `python3`.

### Linux

В Ubuntu и Debian Python устанавливается из репозитория пакетов. **Пакет** — набор файлов и настроек, который устанавливается одной командой. `sudo` временно даёт права администратора, а `apt` управляет пакетами.

```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv
python3 --version
```

Пакет `python3-venv` понадобится позже для виртуальных окружений — отдельных папок с библиотеками конкретного проекта. `pip` — установщик сторонних библиотек из каталога PyPI.

### Проверка установки

Откройте терминал и выполните команду. **Терминал** — программа, в которую вводят текстовые команды и получают текстовый ответ.

```bash
python3 --version
# Пример вывода: Python 3.12.3
```

> **Если команда не найдена**
> На разных системах интерпретатор может называться `python` или `python3`. В курсе используется `python3`, потому что на macOS и Linux команда `python` иногда указывает на старую версию или отсутствует.

## Две среды: REPL и файл

Запускать код можно двумя способами. Первый удобен для экспериментов, второй — для настоящих программ, которые нужно сохранить и повторно запускать.

### Интерактивная оболочка REPL

**REPL** расшифровывается как Read-Eval-Print Loop — «прочитать, вычислить, вывести, повторить». Это цикл, в котором Python принимает одну строку, сразу выполняет её и показывает результат. Удобно проверять небольшие фрагменты, не создавая файл.

```bash
$ python3
Python 3.12.3 (main, ...)
>>> print("Привет!")
Привет!
>>> 2 + 2
4
>>> exit()
```

Символ `$` здесь обозначает приглашение командной строки, а `>>>` — приглашение Python. Их не нужно вводить вручную: они появляются сами. Команда `exit()` завершает оболочку; также можно нажать `Ctrl+D` в macOS и Linux или `Ctrl+Z`, затем `Enter` в Windows.

### Файл со скриптом

**Скрипт** — файл с кодом, который запускается целиком. Создайте в любом редакторе файл `hello.py`. Расширение `.py` подсказывает системе и редактору, что внутри код Python.

```python
print("Привет, мир!")
print("Эта программа запускается из файла.")
```

Теперь откройте терминал в папке с файлом и выполните команду `python3 hello.py`. Здесь `python3` — программа-интерпретатор, а `hello.py` — аргумент, то есть имя файла, который нужно выполнить.

```bash
python3 hello.py
```

```text
Привет, мир!
Эта программа запускается из файла.
```

> **Как называть файлы**
> Используйте строчные латинские буквы, цифры и подчёркивания: `hello.py`, `about_me.py`, `lesson_01.py`. Пробелы и дефисы в именах файлов усложняют команды в терминале.

## Функция print()

`print()` — встроенная функция Python. **Встроенная** значит, что она доступна сразу, без подключения библиотек. Её задача — вывести значения в стандартный поток вывода, то есть на экран терминала.

```python
print("Год:", 2026)
print("Python", "учится", "быстро")
```

```text
Год: 2026
Python учится быстро
```

Если передать несколько значений через запятую, `print` выведет их в одну строку и по умолчанию разделит пробелом. Каждое значение — отдельный аргумент функции.

### Разделитель и конец строки

По умолчанию `print` ставит пробел между аргументами и добавляет перевод строки в конце. Эти настройки можно изменить именованными аргументами: `sep` задаёт разделитель, а `end` — то, что будет добавлено после последнего значения.

```python
print("A", "B", "C", sep="-")
print("Без перевода строки", end=" ")
print("и продолжение")
```

```text
A-B-C
Без перевода строки и продолжение
```

Во втором примере `end=" "` заменил перевод строки на пробел, поэтому следующий `print` продолжил ту же строку. Такой приём пригодится, когда нужно собрать вывод в одну строку.

### f-строки

Часто нужно вставить значение прямо в текст. Для этого в Python есть **f-строки**: перед кавычками ставится буква `f`, а внутри текста в фигурных скобках указывается выражение. Python вычисляет его и подставляет результат.

```python
print(f"2 + 2 = {2 + 2}")
print(f"Сейчас {2026} год")
```

```text
2 + 2 = 4
Сейчас 2026 год
```

Фигурные скобки в f-строке — не часть текста, а место подстановки. Если нужно вывести сами скобки, их удваивают: `{{` и `}}`. Подробнее f-строки разберём, когда появятся переменные.

## Комментарии

**Комментарий** — пояснение в коде, которое интерпретатор игнорирует. Он нужен людям: вам через месяц, коллеге при чтении кода или преподавателю при проверке. Комментарий начинается с символа `#` и продолжается до конца строки.

```python
# Это комментарий. Python его не выполняет.
print("Привет!")  # Комментарий может стоять после кода
```

Три двойные кавычки создают многострочную строку. Если такая строка стоит первой в файле, функции или классе, она становится **docstring** — документацией, которую можно прочитать через `help()`. Это не совсем комментарий, хотя визуально похоже.

```python
"""
Этот текст — docstring модуля.
Он описывает, зачем нужен файл.
"""
print("Программа запущена")
```

Главное правило: комментарий объясняет **почему**, а не **что**. Пересказ очевидной строки только загромождает код.

```python
# Плохо: сообщение без восклицательного знака.
# Хорошо: сообщение намеренно нейтральное, чтобы его было
# проще сравнивать в автоматических тестах.
print("Готово")
```

Первый комментарий повторяет то, что и так видно. Второй объясняет причину, которую нельзя восстановить из самого кода. Именно такие комментарии экономят время при сопровождении.

## Ошибки и traceback

Ошибка в программе — нормальная часть работы. Важно не пугаться, а понимать, что именно сообщает Python. При запуске файла с ошибкой интерпретатор выводит **traceback** — отчёт, в котором показана цепочка вызовов и место сбоя.

```python
print("Привет"
```

```text
  File "hello.py", line 1
    print("Привет"
         ^
SyntaxError: '(' was never closed
```

Читать такой отчёт нужно с конца. Последняя строка `SyntaxError: '(' was never closed` называет тип ошибки и объясняет причину: открывающая скобка не была закрыта. Строка выше показывает файл и номер строки, а символ `^` указывает место, где Python заметил проблему.

`SyntaxError` означает, что код нарушает правила языка, поэтому программа даже не начала выполняться. Остальные ошибки возникают уже во время работы и называются **исключениями**. Python останавливает программу и показывает, какая инструкция привела к сбою.

| Ошибка | Пример | Что означает |
|---|---|---|
| `SyntaxError` | `print("Привет"` | Нарушен синтаксис: забыта скобка, кавычка или двоеточие. Программа не запускается. |
| `NameError` | `print(name)` | Имя `name` не определено. Возможно, переменная не создана или в имени опечатка. |
| `TypeError` | `"возраст: " + 25` | Операция не подходит для этих типов. Строку нельзя сложить с числом без преобразования. |
| `ValueError` | `int("двадцать")` | Тип подходящий, но значение неверное: `int()` умеет превращать в число строку из цифр, а не слово. |
| `ZeroDivisionError` | `10 / 0` | Деление на ноль запрещено математически и в Python. |

Порядок разбора traceback удобно запомнить так:

1. Прочитайте последнюю строку: там указан тип ошибки и короткое объяснение.
2. Найдите строку выше с файлом и номером: она показывает, где произошёл сбой.
3. Посмотрите на фрагмент кода и символ `^`: он подсказывает конкретное место.
4. Исправьте одну причину и запустите программу снова. Не меняйте сразу несколько мест — иначе непонятно, что помогло.

> **Не угадывайте**
> Если сообщение непонятно, скопируйте последнюю строку ошибки в поиск вместе с названием языка. Но сначала прочитайте её сами: в большинстве случаев там прямо написано, чего не хватает.

## Практика

Без собственных запусков материал останется теорией. Выполните задания по порядку — каждое занимает несколько минут.

1. Установите Python и проверьте версию командой `python3 --version` (или `py --version` в Windows).
2. Откройте REPL и выполните по очереди: `print("Проверка")`, `2 + 2`, `print("A", "B", sep=" | ")`. Затем выйдите через `exit()`.
3. Создайте файл `about_me.py` и выведите три строки: имя, возраст и любимый язык программирования. Используйте три отдельных вызова `print()`.
4. Запустите файл. Затем намеренно уберите закрывающую скобку в одной строке, запустите снова и прочитайте traceback. Верните скобку и убедитесь, что программа снова работает.
5. Добавьте в `about_me.py` комментарий, который объясняет, почему строки идут именно в таком порядке. Комментарий должен объяснять причину, а не пересказывать `print`.

Пример ожидаемого результата для третьего задания:

```text
Имя: Анна
Возраст: 25
Любимый язык: Python
```

> **Подсказка**
> Если не получается запустить файл, проверьте, что терминал открыт в той же папке, где лежит `about_me.py`. Команда `pwd` в macOS и Linux показывает текущую папку.

5. Что нужно прочитать в traceback в первую очередь?

### Ответы

1. Компилируемый язык сначала переводится в машинный код целиком, а интерпретируемый выполняется построчно специальной программой-интерпретатором.
2. `print()` выводит значения на экран. Аргумент — значение, которое передаётся функции в скобках.
3. `sep` задаёт разделитель между несколькими аргументами, а `end` — текст, который добавляется после последнего аргумента. По умолчанию `sep` равен пробелу, а `end` — переводу строки.
4. Строку можно сложить только со строкой. `"5" + 5` смешивает строку и число, а `"5" + "5"` соединяет две строки в `"55"`.
5. Последнюю строку: в ней указан тип ошибки и краткое объяснение.

## Итоги

- Python — высокоуровневый интерпретируемый язык общего назначения; код выполняется интерпретатором без отдельной сборки.
- Для работы нужен Python 3. После установки проверьте версию командой `python3 --version` или `py --version`.
- Код можно выполнять в REPL для быстрых экспериментов или из файла `.py` для полноценных программ.
- `print()` выводит значения; `sep` и `end` управляют форматированием, а f-строки позволяют вставлять выражения в текст.
- Комментарии начинаются с `#` и объясняют причину решения, а не пересказывают очевидные действия.
- Traceback читают с конца: последняя строка называет ошибку, строки выше показывают место.
