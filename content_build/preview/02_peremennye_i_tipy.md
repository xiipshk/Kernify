# 1.2. Переменные и типы данных

Присваивание, имена переменных, числа, строки, логический тип, преобразование типов и ввод данных.

В первом уроке программа выводила заранее известные значения. Но настоящая программа должна запоминать данные: имя пользователя, цену товара, результат вычисления. Для этого используются переменные.

В этом уроке разберём, как Python хранит значения, какие типы данных встречаются чаще всего и почему строка `"25"` ведёт себя не так, как число `25`. Эти различия — источник большей части ошибок у начинающих.

## Чему вы научитесь

- создавать переменные, переприсваивать значения и объяснять, что происходит в памяти;
- выбирать допустимые и понятные имена, не конфликтующие с ключевыми словами;
- различать целые числа, числа с плавающей точкой, строки, логические значения и `None`;
- проверять тип значения через `type()` и `isinstance()`;
- преобразовывать строки в числа и обратно, понимая, когда преобразование обязательно;
- читать ввод пользователя через `input()` и не путать введённый текст с числом.

## Переменная и присваивание

**Переменная** — это имя, которое ссылается на объект в памяти. **Объект** — конкретное значение: число `25`, строка `"Анна"`, логическое `True`. **Присваивание** — операция, которая связывает имя с объектом. В Python она записывается одним знаком `=`.

```python
name = "Анна"
age = 25

print(name)
print(age)
```

```text
Анна
25
```

Разберём первую строку: `name` — имя переменной, `=` — присваивание, `"Анна"` — строковый объект. После выполнения имя `name` ссылается на строку `"Анна"`. Когда `print(name)` получает это имя, Python подставляет объект, на который оно указывает, и выводит текст.

> **Присваивание не сравнивает**
> Один знак `=` означает «положить значение в переменную», а два знака `==` — «сравнить два значения». Запись `x = 5` меняет переменную, запись `x == 5` только задаёт вопрос и возвращает `True` или `False`.

Переменную можно переприсвоить. Python не хранит историю значений: после нового присваивания имя начинает ссылаться на другой объект.

```python
score = 10
print(score)

score = 25
print(score)
```

```text
10
25
```

Python — язык с **динамической типизацией**. Это значит, что тип определяется у значения во время выполнения, а не объявляется заранее для имени. Одна и та же переменная может сначала ссылаться на число, а потом на строку.

```python
value = 10
print(type(value))

value = "десять"
print(type(value))
```

```text
<class 'int'>
<class 'str'>
```

Гибкость помогает быстро писать код, но требует внимательности: если переменная неожиданно получила строку вместо числа, арифметика с ней перестанет работать. Поэтому тип значения лучше проверять и контролировать.

### Несколько значений за раз

Python позволяет присвоить одно значение нескольким именам или разложить последовательность по переменным. Второй приём называется **распаковкой**.

```python
x = y = z = 0
a, b, c = 1, 2, 3

print(x, y, z)
print(a, b, c)
```

```text
0 0 0
1 2 3
```

При распаковке количество имён слева должно совпадать с количеством значений справа. Запись `a, b = 1, 2, 3` вызовет `ValueError`, потому что двум именам пытаются передать три значения.

## Правила именования

Имя переменной — не произвольный текст. Python принимает только такие имена, которые состоят из букв, цифр и символа подчёркивания `_` и не начинаются с цифры. Регистр важен: `name`, `Name` и `NAME` — три разные переменные.

| Имя | Допустимо? | Почему |
|---|---|---|
| `user_name` | Да | Буквы и подчёркивание, начинается с буквы. |
| `_tmp` | Да | Подчёркивание разрешено в начале, хотя имя не очень понятное. |
| `2fast` | Нет | Имя не может начинаться с цифры. |
| `user-name` | Нет | Дефис Python воспримет как минус. |
| `class` | Нет | Это ключевое слово языка. |
| `User Name` | Нет | Пробел внутри имени недопустим. |

Кроме формальных правил есть договорённости о стиле. Они записаны в документе **PEP 8** — официальном руководстве по оформлению кода Python. Для переменных и функций принят **snake_case**: слова в нижнем регистре, разделённые подчёркиваниями. Для констант используют **UPPER_SNAKE_CASE** — заглавные буквы и подчёркивания.

```python
user_name = "Анна"
total_price = 1990
MAX_ATTEMPTS = 3

print(user_name, total_price, MAX_ATTEMPTS)
```

**Константа** — значение, которое по договорённости не меняют во время работы программы. Python не запрещает переприсвоить такую переменную, поэтому заглавные буквы — это сигнал другим разработчикам, а не защита языка. Имена вроде `uc` или `tmp2` экономят несколько символов, но затрудняют чтение; `user_count` понятнее.

## Типы данных

**Тип данных** определяет, какие значения может хранить объект и какие операции с ним допустимы. Число можно сложить с числом, строку — со строкой, но смешивать их напрямую нельзя. Вот основные типы, с которыми мы будем работать.

| Тип | Пример | Для чего нужен |
|---|---|---|
| `int` | `42`, `-10`, `0` | Целые числа без дробной части. |
| `float` | `3.14`, `-0.5`, `1.5e-4` | Числа с дробной частью. |
| `str` | `"Python"`, `'42'` | Текст и последовательности символов. |
| `bool` | `True`, `False` | Логические значения: да или нет. |
| `NoneType` | `None` | Отсутствие значения. |

Проверить тип конкретного значения можно функцией `type()`. Она возвращает объект-тип, который при выводе выглядит как `<class 'int'>`.

```python
print(type(42))
print(type(3.14))
print(type("Python"))
print(type(True))
print(type(None))
```

```text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'NoneType'>
```

### int — целые числа

`int` хранит целые числа: положительные, отрицательные и ноль. В Python целые числа не ограничены фиксированным размером, поэтому можно работать с очень большими значениями. Для читаемости длинные числа разрешено разделять подчёркиваниями.

```python
count = 42
temperature = -10
population = 1_000_000

print(count, temperature, population)
print(type(count))
```

```text
42 -10 1000000
<class 'int'>
```

С целыми числами работают обычные арифметические операторы. Важно запомнить разницу между `/`, `//` и `%`: деление `/` всегда возвращает `float`, даже если числа делятся нацело.

```python
print(10 + 3)
print(10 - 3)
print(10 * 3)
print(10 / 3)
print(10 // 3)
print(10 % 3)
print(2 ** 10)
```

```text
13
7
30
3.3333333333333335
3
1
1024
```

`//` — целочисленное деление: оно отбрасывает дробную часть. `%` — остаток от деления. `**` — возведение в степень. Например, `10 % 3` равно `1`, потому что 10 делится на 3 с остатком 1.

### float — числа с плавающей точкой

`float` хранит числа с дробной частью. Внутри Python представляет их в двоичном формате с плавающей точкой, поэтому некоторые десятичные дроби хранятся приближённо. Это не особенность Python, а общее свойство формата.

```python
price = 19.99
ratio = 1.5e-4

print(price)
print(ratio)
print(0.1 + 0.2)
```

```text
19.99
0.00015
0.30000000000000004
```

Запись `1.5e-4` означает `1.5 × 10⁻⁴`, то есть `0.00015`. Результат `0.1 + 0.2` выглядит странно, но объясняется округлением при хранении дробей. Если нужна точная десятичная арифметика, например для денег, используют модуль `decimal`.

```python
from decimal import Decimal

print(Decimal("0.1") + Decimal("0.2"))
print(round(0.1 + 0.2, 2))
```

```text
0.3
0.3
```

`Decimal` принимает строку и хранит десятичные цифры точно. `round(значение, количество_знаков)` округляет результат до нужного числа знаков после запятой. Для обычных вычислений обычно достаточно `float`, а `Decimal` нужен там, где ошибка округления недопустима.

### str — строки

`str` хранит текст. Строкой считается последовательность символов в кавычках: одинарных, двойных или тройных. Python использует **Unicode** — стандарт, который включает буквы разных языков, цифры, знаки препинания и эмодзи. Строки **неизменяемы**: существующую строку нельзя поменять по символу, можно только создать новую.

```python
greeting = "Привет"
name = 'Анна'
multiline = """Первая строка
Вторая строка"""

print(greeting, name)
print(multiline)
```

```text
Привет Анна
Первая строка
Вторая строка
```

Внутри строки некоторые символы имеют специальное значение. Обратная косая черта `\` начинает **escape-последовательность**: `\n` — перевод строки, `\t` — табуляция, `\\` — сама обратная косая черта. Если экранирование не нужно, перед кавычками ставят `r`, и строка становится **raw-строкой**.

```python
print("Первая строка\nВторая строка")
print("C:\\Users\\name")

path = r"C:\Users\name"
print(path)
```

```text
Первая строка
Вторая строка
C:\Users\name
C:\Users\name
```

Строки можно соединять оператором `+` и повторять оператором `*`. Функция `len()` возвращает количество символов.

```python
print(len("привет"))
print("а" + "б")
print("ха" * 3)
```

```text
6
аб
хахаха
```

Неизменяемость проявляется так: `word = word + "ик"` не меняет старую строку, а создаёт новую и связывает с ней имя `word`. Старая строка остаётся в памяти, пока на неё есть ссылки.

### bool — логический тип

`bool` принимает только два значения: `True` (истина) и `False` (ложь). Логические значения обычно получаются из сравнений. **Оператор сравнения** задаёт вопрос и возвращает `bool`.

```python
is_student = True
has_error = False

print(is_student, has_error)
print(10 > 5)
print(10 == 10)
print(10 != 5)
print("а" < "б")
```

```text
True False
True
True
True
True
```

Операторы `>`, `<`, `>=`, `<=`, `==`, `!=` работают так же, как в математике, но `==` и `!=` сравнивают значения на равенство и неравенство. Строки сравниваются посимвольно по кодам Unicode, поэтому `"а" < "б"` истинно.

Логические операторы объединяют условия: `and` требует, чтобы оба условия были истинны, `or` — чтобы было истинно хотя бы одно, `not` меняет значение на противоположное.

```python
print(True and False)
print(True or False)
print(not True)

x = 0
print(x != 0 and 10 / x > 1)
```

```text
False
True
False
False
```

В последней строке деления на ноль не произошло. Оператор `and` вычисляет второй операнд только тогда, когда первый истинен. Это называется **коротким замыканием** и часто используется для защиты от ошибок.

Почти любое значение можно привести к `bool`. Ложными считаются `False`, `0`, `0.0`, пустая строка `""`, `None` и пустые коллекции, которые появятся позже. Все остальные значения, включая строку `"False"`, истинны.

```python
print(bool(0), bool(1))
print(bool(""), bool("текст"))
print(bool(None))
print(bool("False"))
```

```text
False True
False True
False
True
```

> **Строка "False" — это не False**
> Логическое значение `False` — специальный объект. Строка `"False"` состоит из пяти символов и считается непустой, поэтому `bool("False")` возвращает `True`.

### None — отсутствие значения

`None` — специальное значение, которое означает «значения нет». Оно не равно ни нулю, ни пустой строке, ни `False`. `None` удобно использовать, когда результат ещё не известен или функция намеренно ничего не возвращает.

```python
winner = None
print(winner)
print(winner is None)
print(winner == None)
```

```text
None
True
True
```

Для проверки на `None` принято использовать `is None`, а не `== None`. Оператор `is` проверяет, является ли это тем же самым объектом. Для `None` такой способ точнее выражает намерение и не зависит от переопределения равенства.

## Преобразование типов

**Преобразование типа** — получение значения другого типа из уже существующего. Оно бывает явным, когда программист сам вызывает `int()`, `float()`, `str()` или `bool()`, и неявным, когда Python делает его при операции.

```python
print(int("42"))
print(int(3.99))
print(float("3.14"))
print(str(123))
print(bool(0), bool(""))
```

```text
42
3
3.14
123
False False
```

`int(3.99)` возвращает `3`, потому что преобразование отбрасывает дробную часть, а не округляет. `int("42")` разбирает строку из цифр. `float("3.14")` понимает точку как десятичный разделитель. `str(123)` создаёт строку `"123"`.

Неявное преобразование происходит, например, при сложении `int` и `float`: результат становится `float`. Со строкой и числом автоматического преобразования нет — нужно явно привести одно из значений.

```python
print(5 + 3.2)
print("текст" + str(5))
```

```text
8.2
текст5
```

| Выражение | Результат | Пояснение |
|---|---|---|
| `int("42")` | `42` | Строка из цифр превращается в целое число. |
| `int("3.9")` | `ValueError` | Строка с точкой не является записью целого числа. |
| `float("3.9")` | `3.9` | Строка с точкой превращается в число с плавающей точкой. |
| `str(3.9)` | `"3.9"` | Число превращается в текст. |
| `bool("0")` | `True` | Непустая строка истинна, даже если внутри ноль. |

Если пользователь вводит десятичную дробь с запятой, `float("3,14")` вызовет `ValueError`. Строку можно заранее подготовить: заменить запятую на точку.

```python
text = "3,14"
value = float(text.replace(",", "."))
print(value)
```

```text
3.14
```

## Ввод пользователя: input()

Функция `input()` выводит приглашение, ждёт, пока пользователь введёт строку и нажмёт Enter, и возвращает введённый текст. Ключевая особенность: `input()` **всегда возвращает строку**, даже если пользователь напечатал число.

```python
name = input("Ваше имя: ")
print("Привет, " + name + "!")
```

```text
Ваше имя: Анна
Привет, Анна!
```

Строка `"Ваше имя: "` — приглашение, которое видит пользователь. Оно не является частью результата. Если нужно получить число, введённую строку преобразуют явно. Во вложенном вызове `int(input(...))` сначала выполняется `input`, затем `int` разбирает полученный текст.

```python
age = int(input("Возраст: "))
print(f"Через год вам будет {age + 1}")

height = float(input("Рост в метрах: "))
print(f"Рост: {height} м")
```

```text
Возраст: 25
Через год вам будет 26
Рост в метрах: 1.75
Рост: 1.75 м
```

> **Почему "25" + 1 не работает**
> `input()` вернул строку `"25"`. Строку нельзя сложить с числом `1`: получится `TypeError`. Сначала преобразуйте ввод через `int()` или `float()`.

Если пользователь введёт не число, преобразование вызовет `ValueError`. В уроке об ошибках мы разбирали `try` и `except`; с их помощью можно попросить ввести значение повторно, не завершая программу.

## Проверка типа: type() и isinstance()

`type(value)` возвращает точный тип значения. `isinstance(value, тип)` отвечает на вопрос, принадлежит ли значение типу, и считается более гибким способом проверки.

```python
x = 42

print(type(x))
print(type(x) is int)
print(isinstance(x, int))
print(isinstance(x, (int, float)))
```

```text
<class 'int'>
True
True
True
```

Запись `(int, float)` — кортеж типов, то есть несколько значений в скобках. `isinstance` вернёт `True`, если значение подходит хотя бы к одному из них. Второй аргумент `isinstance` учитывает наследование, поэтому он удобнее, когда появятся собственные классы.

> **Практическое правило**
> Когда нужно узнать точный тип для отладки, используйте `type()`. Когда нужно проверить, можно ли работать со значением как с числом, используйте `isinstance(value, int)` или `isinstance(value, (int, float))`.

## Типичные ошибки

| Ошибка | Что происходит | Как правильно |
|---|---|---|
| `x = 5` вместо `x == 5` | Присваивание вместо сравнения. В условиях это меняет смысл проверки. | Для сравнения используйте `==`. |
| `"5" + 3` | `TypeError`: строку нельзя сложить с числом. | `int("5") + 3` или `"5" + str(3)`. |
| `age = input("Возраст: ")`, затем `age + 1` | `TypeError`: `input` вернул строку. | `age = int(input("Возраст: "))`. |
| `float("3,14")` | `ValueError`: запятая не является десятичным разделителем Python. | `float("3.14")` или заменить запятую на точку. |
| Обращение к переменной до присваивания | `NameError`: имени ещё нет в текущей области видимости. | Создайте переменную до первого использования. |
| `str = "текст"` | Имя перекрывает встроенную функцию `str`, и вызов `str(123)` перестанет работать. | Используйте `text` или `message`. |

Отдельно запомните: имена чувствительны к регистру. Если создать `user_name`, а потом обратиться к `user_Name`, Python не найдёт вторую переменную и вызовет `NameError`.

## Проверьте себя

1. Чем `=` отличается от `==`?
2. Почему `int(3.99)` возвращает `3`, а не `4`?
3. Что возвращает `input()` и почему для возраста нужно `int()`?
4. Почему `0.1 + 0.2` не равно ровно `0.3`?
5. Чем `None` отличается от `False`?

### Ответы

1. `=` присваивает значение переменной, а `==` сравнивает два значения и возвращает `bool`.
2. `int()` отбрасывает дробную часть, а не округляет. Для округления используется `round()`.
3. `input()` всегда возвращает строку. `int()` нужен, чтобы получить число и выполнять с ним арифметику.
4. Дробные числа хранятся в двоичном формате с ограниченной точностью, поэтому `0.1` и `0.2` представляются приближённо. Для точной десятичной арифметики есть `Decimal`.
5. `None` означает отсутствие значения. `False` — конкретное логическое значение, означающее «ложь». Они не равны друг другу.

## Итоги

- Переменная — имя, ссылающееся на объект. Присваивание записывается одним `=`, сравнение — двумя `==`.
- Имена состоят из букв, цифр и `_`, не начинаются с цифры и чувствительны к регистру. Для переменных принят `snake_case`.
- Основные типы: `int` для целых чисел, `float` для дробных, `str` для текста, `bool` для истины и лжи, `None` для отсутствия значения.
- `type()` показывает точный тип, `isinstance()` проверяет принадлежность типу и удобнее для практических проверок.
- `input()` всегда возвращает строку; для чисел используйте `int()` или `float()`.
- `0.1 + 0.2` может дать `0.30000000000000004` из-за двоичного представления дробей; для денег и точных расчётов применяют `Decimal`.
