  ---
  name: mycmd
  description: Описание
  ---

  Наборы инструкций для типовых задач (deploy, review, dataviz и т.д.).

  - CLAUDE_CODE_* env vars

  - CLAUDE.md — инструкции для модели

  # bot.py
  import os
  from aiogram import Bot, Dispatcher, types, F
  from aiogram.filters import Command
  from aiogram.client.default import DefaultBotProperties
  from aiogram.enums import ParseMode
  import asyncio

  TOKEN = os.getenv("BOT_TOKEN")
  bot = Bot(token=TOKEN, default=DefaultBotProperties(parse_mode=ParseMode.HTML))
  dp = Dispatcher()

  @dp.message(Command("start"))
  async def start(msg: types.Message):
      await msg.answer("Привет! Я бот. Напиши /help")

  @dp.message(Command("help"))
  async def help_cmd(msg: types.Message):
      await msg.answer("Команды:\n/start — начало\n/echo <текст> — повторю")

  @dp.message(F.text & ~F.text.startswith("/"))
  async def echo(msg: types.Message):
      await msg.answer(f"Ты написал: <code>{msg.text}</code>")

  async def main():
      await dp.start_polling(bot)

  if __name__ == "__main__":
      asyncio.run(main())

  # Запуск
  export BOT_TOKEN="123456:ABC-DEF..."
  pip install aiogram
  python bot.py

● Как поднять свой VPN — основные варианты

  1. WireGuard — самый простой и быстрый
  (рекомендую для начала)

  На VPS (Ubuntu/Debian) — 5 минут:

  # На сервере
  wget -O wireguard-install.sh
  https://git.io/wireguard-install
  chmod +x wireguard-install.sh
  sudo ./wireguard-install.sh
  Скрипт сам:
  - Установит WireGuard
  - Сгенерирует ключи
  - Создаст конфиг для клиента (.conf или
    QR-код)
  - Настроит firewall и forwarding

  На клиенте (телефон/ПК):

  - Установи приложение WireGuard
  - Импортируй .conf или отсканируй QR →
    подключился

  ---

  2. AmneziaWG — WireGuard с обфускацией (для
  обхода блокировок)

  # На сервере
  wget -O amnezia-install.sh
  https://git.io/amnezia-install
  chmod +x amnezia-install.sh
  sudo ./amnezia-install.sh
  Работает так же просто, но маскирует трафик
  под обычный HTTPS — полезно в РФ/Китае/Иране.

  ---

  3. Outline (Shadowsocks) — от Jigsaw (Google)

  # На сервере
  sudo bash -c "$(wget -qO-
  https://raw.githubusercontent.com/Jigsaw-Code/
  outline-server/master/src/server_manager/insta
  ll_scripts/install_server.sh)"
  Потом управляешь через приложение Outline
  Manager (Windows/Mac/Linux) — добавляешь
  ключи, смотришь трафик.

  ---

  4. Xray / VLESS + Reality / TUIC —
  максимальная маскировка

  Сложнее в настройке, но лучше проходит DPI.
  Есть готовые скрипты:
  - Xray-reality (под TLS, выглядит как
    нормальный сайт)
  - Hysteria2 (на QUIC, очень быстрый)

  Пример (Xray + Reality):
  bash -c "$(wget -qO- https://github.com/XTLS/X
  ray-install/raw/main/install.sh)"
  # Потом настраиваешь через конфиг или панель
  3x-ui

  ---

  5. Панели управления (если не любишь консоль)

  ┌─────────┬──────────────────┬───────────┐
  │ Панель  │    Протоколы     │ Сложность │
  ├─────────┼──────────────────┼───────────┤
  │         │ Xray (VLESS,     │           │
  │ 3x-ui   │ VMess, Trojan,   │ Низкая    │

     1.1.1.1, 8.8.8.8 (или свой DoH)
  3. MTU — для WireGuard ставь MTU = 1280
     (избегаешь фрагментации)
  4. Keepalive — PersistentKeepalive = 25 (чтобы
     не рвало за NAT)
  5. Автозапуск — systemctl enable wg-quick@wg0
     (или docker --restart always)

  команду в терминале",
       "input_schema": {"type": "object",
  "properties": {"cmd": {"type": "string"}},
  "required": ["cmd"]}},

  "Прочитать файл",
       "input_schema": {"type": "object",
  "properties": {"path": {"type": "string"}},
  "required": ["path"]}},

  "Записать файл",
       "input_schema": {"type": "object",
  "properties": {"path": {"type": "string"},
  "content": {"type": "string"}}, "required":
  ["path", "content"]}},
      {"name": "list_files", "description":
  "Список файлов",

  "properties": {"path": {"type": "string"}},
  "required": ["path"]}},

      if name == "bash":
          r = subprocess.run(args["cmd"],
  shell=True, capture_output=True, text=True,
  timeout=60, cwd=os.getcwd())
          return r.stdout + r.stderr
      if name == "read_file":
          with open(args["path"], "r",
  encoding="utf-8") as f: return f.read()
      if name == "write_file":
          with open(args["path"], "w",
  encoding="utf-8") as f:
  f.write(args["content"]); return "OK"
      if name == "list_files":
          return
  "\n".join(os.listdir(args["path"]))
      return "Unknown tool"

  @dp.message()

      messages = [{"role": "user", "content":
  msg.text}]
      while True:

              model="claude-sonnet-4-20250514",
              max_tokens=8000,

          if resp.stop_reason == "tool_use":
