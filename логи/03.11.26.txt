## 2. БАЗА ДАННЫХ

### Статус
**База данных НЕ СУЩЕСТВУЕТ** — файл `bot.db` будет создан при первом запуске через `init_db()`.

### Конфигурация (config.py)
```python
DATABASE_URL: str = "sqlite+aiosqlite:///./bot.db"
```
- Драйвер: `aiosqlite` (async SQLite)
- Расположение: рабочая директория при запуске

### Схема БД (models.py — 11 таблиц)

| Таблица | Назначение | Ключевые поля |
|---------|------------|---------------|
| `users` | Пользователи Telegram | id (BigInteger, PK), username, first_name, preferred_language, current_level, is_admin |
| `courses` | Курсы по языкам | id, language (Enum), name, description, version |
| `topics` | Темы/уроки курса | id, course_id (FK), level, order, title, description, content, code_examples, prerequisites, is_base_topic |
| `test_questions` | Вопросы входного теста | id, topic_id (FK), question_text, question_type, expected_answer, difficulty |
| `test_results` | Ответы пользователей | id, user_id (FK), question_id (FK), topic_id (FK), score (0-2), user_answer, ai_feedback, status |
| `user_progress` | Прогресс по темам | id, user_id (FK), topic_id (FK), status (Enum), score, completed_at, review_count, error_patterns |
| `practice_tasks` | Практические задания | id, topic_id (FK), level, task_type, title, description, starter_code, solution, test_cases (JSON), hints, difficulty, xp_reward |
| `practice_sessions` | Попытки решения | id, user_id (FK), task_id (FK), topic_id (FK), submitted_code, language, status, test_results (JSON), ai_feedback, hints_used, attempts, time_spent, xp_earned |
| `error_repetitions` | Ошибки для повторения | id, user_id (FK), topic_id (FK), task_id (FK), error_type, error_description, user_code, correct_code, count, next_review, is_resolved |
| `ai_chats` | История ИИ-чатов | id, user_id (FK), topic_id (FK), message_role, content, metadata (JSON), tokens_used |
| `search_queries` | Поисковые запросы | id, user_id (FK), query, language, ai_response, sources (JSON) |

### Enums (переиспользуемые)
- `Language`: PYTHON, CPP, CSHARP, JAVASCRIPT, RUST, CSS, C
- `Level`: BEGINNER, INTERMEDIATE, ADVANCED
- `TopicStatus`: MASTERED, PARTIAL, NOT_MASTERED, UNCLEAR, UNTESTED

### Связи
- User → UserProgress (1:N) → Topic
- User → TestResult (1:N) → TestQuestion → Topic
- User → PracticeSession (1:N) → PracticeTask → Topic
- User → ErrorRepetition (1:N)
- User → AIChat (1:N)
- Course → Topic (1:N)
- Topic → TestQuestion (1:N), PracticeTask (1:N), UserProgress (1:N)

## 4. TELEGRAM-КОМПОНЕНТЫ (ДЛЯ УДАЛЕНИЯ)

### Полностью удалить
1. `main.py` — точка входа бота, polling, Application builder
2. `handlers/` — все 11 файлов обработчиков (Commands, CallbackQuery, ConversationHandler)
3. `keyboards/` — InlineKeyboardMarkup генерация
4. Telegram-специфичные паттерны в коде: `Update`, `ContextTypes`, `CallbackQueryHandler`, `CommandHandler`, `ConversationHandler`, `PicklePersistence`

### Содержат полезную логику (ПЕРЕНЕСТИ В DJANGO)
| Компонент | Что перенести | Куда |
|-----------|---------------|------|
| `models.py` | Вся схема БД (11 таблиц, Enums, связи) | Django models.py (адаптировать под Django ORM) |
| `services/` (пусто) | Бизнес-логика: тесты, практика, ИИ, прогресс | Django services / managers |
| `config.py` | Настройки (BOT_TOKEN, AI_KEYS, DB_URL) | Django settings.py + .env |
| `database.py` | Сессии, init_db | Django migrations + manage.py |

### Адаптация моделей под Django ORM
- `BigInteger` → `BigIntegerField` (Telegram user_id)
- `Enum` → `CharField` с `choices`
- `JSON` → `JSONField`
- `DateTime` с `func.now()` → `auto_now_add` / `auto_now`
- `UniqueConstraint` → `Meta.constraints`
- `relationship` → `ForeignKey` / `ManyToManyField`

## 6. РИСКИ И ПРОБЛЕМЫ

| Риск | Оценка | Митигация |
|------|--------|-----------|
| Потеря структуры БД при переходе на Django ORM | Высокий | Пошаговая миграция моделей, тестирование на пустой БД |
| Telegram user_id (BigInteger) не совпадает с Django User PK | Средний | Использовать `BigIntegerField` для `telegram_id`, связывать с `AbstractUser` |
| Async SQLAlchemy vs Sync Django ORM | Средний | Полный переход на Django ORM (sync), async только для views если нужно |
| Нужны миграции для существующей схемы | Низкий (БД пуста) | Создать initial migration из Django моделей |
| AI интеграция требует архитектурного слоя | Низкий | Создать абстрактный `AIProvider` интерфейс заранее |
