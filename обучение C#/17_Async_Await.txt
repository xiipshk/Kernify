## 1. Основы Task и async/await

### Task vs Thread
```csharp
// Thread — поток ОС, дорогой (~1MB стека), блокирует при ожидании
// Task — обещание результата, дешёвый, не блокирует поток при await

// Создание Task
Task.Run(() => DoWork());           // в ThreadPool
Task.Factory.StartNew(() => ...);   // больше контроля
Task.CompletedTask;                 // уже завершённый
Task.FromResult(42);                // с результатом
Task.FromException(new Exception()); // с ошибкой
Task.Delay(1000);                   // таймер (не блокирует поток!)
```

### async/await — синтаксический сахар
```csharp
// Компилятор превращает в state machine (IAsyncStateMachine)
public async Task<string> DownloadAsync(string url)
{
    using var http = new HttpClient();
    var content = await http.GetStringAsync(url); // yield control здесь
    return content.ToUpper(); // продолжение в captured context
}

// Эквивалентно (упрощённо):
public Task<string> DownloadAsync(string url)
{
    var tcs = new TaskCompletionSource<string>();
    var http = new HttpClient();
    http.GetStringAsync(url).ContinueWith(t =>
    {
        if (t.IsFaulted) tcs.SetException(t.Exception!);
        else tcs.SetResult(t.Result.ToUpper());
    });
    return tcs.Task;
}
```

### ValueTask — для горячих путей (high-frequency)
```csharp
// ValueTask — struct, избегает аллокации Task если результат уже есть
public ValueTask<int> GetCachedOrCompute(int key)
{
    if (_cache.TryGetValue(key, out var value))
        return new ValueTask<int>(value); // синхронно, без аллокации

    return new ValueTask<int>(ComputeAsync(key)); // асинхронно
}

// ValueTask<T> можно await'ить как обычный Task
// ВАЖНО: ValueTask можно await'ить ТОЛЬКО ОДИН РАЗ!
```

## 2. CancellationToken — кооперативная отмена

### Базовое использование
```csharp
public async Task ProcessAsync(CancellationToken ct = default)
{
    for (int i = 0; i < 100; i++)
    {
        ct.ThrowIfCancellationRequested(); // бросает OperationCanceledException
        await DoStepAsync(i, ct);
    }
}

// Вызов с таймаутом
using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(30));
await ProcessAsync(cts.Token);

// Отмена вручную
cts.Cancel();
```

### CancellationToken в стандартных API
```csharp
// Большинство BCL методов принимают ct
await httpClient.GetAsync(url, ct);
await stream.ReadAsync(buffer, ct);
await Task.Delay(1000, ct);
await semaphore.WaitAsync(ct);

// LINQ с отменой (PLINQ)
var result = items.AsParallel()
    .WithCancellation(ct)
    .Where(x => ExpensiveCheck(x))
    .ToList();
```

### Linked CancellationTokenSource
```csharp
// Комбинирование нескольких токенов
public async Task ParentAsync(CancellationToken parentCt)
{
    using var linkedCts = CancellationTokenSource.CreateLinkedTokenSource(parentCt);

    var child1 = ChildAsync(linkedCts.Token);
    var child2 = ChildAsync(linkedCts.Token);

    await Task.WhenAll(child1, child2);
}
```

## 3. Обработка ошибок

### try/catch с await
```csharp
public async Task<User?> GetUserAsync(int id)
{
    try
    {
        return await _db.Users.FindAsync(id);
    }
    catch (SqlException ex) when (ex.Number == -2) // timeout
    {
        _logger.LogWarning(ex, "DB timeout");
        throw new TimeoutException("Database unavailable", ex);
    }
    catch (Exception ex)
    {
        _logger.LogError(ex, "Unexpected error");
        throw; // сохраняет stack trace
    }
}
```

### Task.Exception — AggregateException
```csharp
var task = Task.Run(() => { throw new InvalidOperationException("oops"); });

try { await task; }
catch (Exception ex)
{
    // ex — это InvalidOperationException (не AggregateException!)
    // await "разворачивает" AggregateException
}

// Без await — нужно распаковывать
var task2 = Task.Run(() => { throw new Exception("x"); });
task2.Wait(); // AggregateException с InnerException
```

### Необработанные исключения в Task
```csharp
// ОПАСНО: fire-and-forget без обработки
Task.Run(() => { throw new Exception("lost!"); }); // Exception потеряется!

// ПРАВИЛЬНО: всегда обрабатывайте
_ = Task.Run(async () =>
{
    try { await DoWork(); }
    catch (Exception ex) { _logger.LogError(ex, "Background task failed"); }
});

// Или используйте TaskScheduler.UnobservedTaskException (глобальный хук)
TaskScheduler.UnobservedTaskException += (s, e) =>
{
    _logger.LogError(e.Exception, "Unobserved exception");
    e.SetObserved(); // предотвращает crash процесса
};
```

## 4. Параллельные операции

### Task.WhenAll / WhenAny
```csharp
// Параллельный запуск — все одновременно
var tasks = urls.Select(url => DownloadAsync(url)).ToArray();
var results = await Task.WhenAll(tasks); // ждёт все

// Fail-fast: первый успешный или первая ошибка
var first = await Task.WhenAny(tasks);
var result = await first; // propagate exception if any

// Timeout pattern
var completed = await Task.WhenAny(task, Task.Delay(5000));
if (completed == task) return await task;
throw new TimeoutException();
```

### Parallel / Parallel.ForEach
```csharp
// CPU-bound параллелизм (использует ThreadPool)
Parallel.For(0, 100, i => Compute(i));

Parallel.ForEach(items, item => Process(item));

// С опциями
Parallel.ForEach(items, new ParallelOptions
{
    MaxDegreeOfParallelism = 4,
    CancellationToken = ct
}, item => Process(item));

// Parallel LINQ (PLINQ) — для запросов
var result = items.AsParallel()
    .WithDegreeOfParallelism(4)
    .Select(Transform)
    .ToList();
```

### SemaphoreSlim — ограничение параллелизма
```csharp
// Ограничить до 5 одновременных запросов
var semaphore = new SemaphoreSlim(5);

var tasks = urls.Select(async url =>
{
    await semaphore.WaitAsync(ct);
    try { return await DownloadAsync(url); }
    finally { semaphore.Release(); }
});

var results = await Task.WhenAll(tasks);
```

### Channels — Producer/Consumer (.NET Core 3.0+)
```csharp
using System.Threading.Channels;

var channel = Channel.CreateBounded<int>(new BoundedChannelOptions(100)
{
    FullMode = BoundedChannelFullMode.Wait // блокирует producer при заполнении
});

// Producer
async Task Produce(ChannelWriter<int> writer, CancellationToken ct)
{
    for (int i = 0; i < 1000; i++)
    {
        await writer.WriteAsync(i, ct);
    }
    writer.Complete();
}

// Consumer
async Task Consume(ChannelReader<int> reader, CancellationToken ct)
{
    await foreach (var item in reader.ReadAllAsync(ct))
    {
        await ProcessAsync(item);
    }
}
```

## 5. Асинхронные паттерны и антипаттерны

### ConfigureAwait(false) — не захватывать context
```csharp
// В библиотеках — ВСЕГДА используйте ConfigureAwait(false)
public async Task<Data> GetDataAsync()
{
    var json = await _http.GetStringAsync(url).ConfigureAwait(false);
    return JsonSerializer.Deserialize<Data>(json);
}

// В UI (WPF/WinForms/MAUI) — НЕ используйте, нужен UI context
// В ASP.NET Core — context нет, можно не писать
```

### Async void — ТОЛЬКО для event handlers
```csharp
// ПЛОХО: исключения не ловятся, не await'ится
public async void BadButton_Click(object sender, EventArgs e) { ... }

// ХОРОШО: event handler
public async void GoodButton_Click(object sender, EventArgs e)
{
    try { await DoWork(); }
    catch (Exception ex) { MessageBox.Show(ex.Message); }
}

// В остальных случаях — async Task
public async Task GoodMethod() { ... }
```

### Async в конструкторе / свойствах — НЕТ
```csharp
// ПЛОХО
public class Bad
{
    public Bad() { _data = await LoadAsync(); } // Ошибка компиляции
    public async Task<string> Prop { get => await LoadAsync(); } // Ошибка
}

// ХОРОШО: фабричный метод или Lazy initialization
public class Good
{
    private readonly Lazy<Task<Data>> _lazyData;
    public Good() => _lazyData = new(async () => await LoadAsync());
    public Task<Data> GetDataAsync() => _lazyData.Value;
}
```

### Deadlock: .Result / .Wait() в async контексте
```csharp
// ДЕДЛОК в UI/ASP.NET (legacy sync context):
public string Bad() => DownloadAsync(url).Result; // БЛОКИРУЕТ поток!
// await continuation ждёт захваченный контекст, который занят .Result

// ПРАВИЛЬНО:
public async Task<string> Good() => await DownloadAsync(url);

// Если ОЧЕНЬ нужно синхронно (редко):
public string Sync() => Task.Run(() => DownloadAsync(url)).GetAwaiter().GetResult();
```

## 6. Продвинутые темы

### IAsyncEnumerable — асинхронные стримы (.NET Core 3.0+)
```csharp
public async IAsyncEnumerable<int> GenerateAsync([EnumeratorCancellation] CancellationToken ct = default)
{
    for (int i = 0; i < 100; i++)
    {
        ct.ThrowIfCancellationRequested();
        await Task.Delay(100, ct);
        yield return i;
    }
}

// Потребление
await foreach (var item in GenerateAsync(ct))
{
    Console.WriteLine(item);
}
```

### Async Disposable
```csharp
public class AsyncResource : IAsyncDisposable
{
    private readonly HttpClient _http = new();

    public async ValueTask DisposeAsync()
    {
        await _http.DisposeAsync(); // асинхронный Dispose
    }
}

// Использование
await using var resource = new AsyncResource();
```

### TaskCompletionSource — мост к event-based API
```csharp
public Task<string> WaitForMessageAsync(CancellationToken ct)
{
    var tcs = new TaskCompletionSource<string>(TaskCreationOptions.RunContinuationsAsynchronously);

    void Handler(string msg)
    {
        _eventSource.MessageReceived -= Handler;
        tcs.TrySetResult(msg);
    }

    _eventSource.MessageReceived += Handler;

    ct.Register(() => tcs.TrySetCanceled(ct));

    return tcs.Task;
}
```

## 8. Типичные ошибки

| Ошибка | Правильно |
|--------|-----------|
| `async void` не в event handler | `async Task` |
| `.Result` / `.Wait()` в async коде | `await` |
| Игнорирование `CancellationToken` | Прокидывайте во все async вызовы |
| `Task.Run` для IO-bound операций | Прямой `await` IO метода |
| Захват UI context в библиотеках | `.ConfigureAwait(false)` |
| Многократный `await` одного `ValueTask` | `await` только один раз |
| Отсутствие `try/catch` в fire-and-forget | Оборачивайте в try/catch + логирование |
| `Task.Delay` без токена отмены | `Task.Delay(ms, ct)` |
