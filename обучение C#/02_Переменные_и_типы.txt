**Целевая версия:** C# 12 / .NET 8

## 1. Объявление переменных

```csharp
// Явное указание типа
int age = 25;
string name = "Анна";
double price = 19.99;
bool isStudent = true;

// Неявное типизирование (var) — тип выводится компилятором
var city = "Москва";      // string
var count = 100;          // int
var ratio = 3.14;         // double
var flag = false;         // bool

// var ОБЯЗАТЕЛЬНО требует инициализацию
// var x; // Ошибка компиляции!
```

## 2. Числовые типы (Value Types)

### Целые числа

| Тип | Размер | Диапазон | Суффикс |
|-----|--------|----------|---------|
| `sbyte` | 8 бит | -128 … 127 | - |
| `byte` | 8 бит | 0 … 255 | - |
| `short` | 16 бит | -32 768 … 32 767 | - |
| `ushort` | 16 бит | 0 … 65 535 | - |
| `int` | 32 бит | -2 147 483 648 … 2 147 483 647 | - |
| `uint` | 32 бит | 0 … 4 294 967 295 | `U` / `u` |
| `long` | 64 бит | ±9.22×10¹⁸ | `L` / `l` |
| `ulong` | 64 бит | 0 … 1.84×10¹⁹ | `UL` / `ul` |
| `nint` / `nuint` | Зависит от платформы | Нативный int/uint | C# 9+ |

```csharp
int a = 42;
long b = 1_000_000_000_000L;  // подчёркивания для читаемости (C# 7+)
uint c = 42U;
```

### Вещественные числа

| Тип | Размер | Точность | Суффикс |
|-----|--------|----------|---------|
| `float` | 32 бит | ~7 знаков | `F` / `f` |
| `double` | 64 бит | ~15-17 знаков | `D` / `d` (по умолчанию) |
| `decimal` | 128 бит | 28-29 знаков | `M` / `m` |

```csharp
float f = 3.14F;
double d = 3.1415926535;
decimal money = 19.99M;  // для финансов — точное представление
```

**Важно:** `decimal` не является примитивным типом в CLR, но ключевым словом C#. Используйте для денежных расчётов.

## 3. Символьные и строковые типы

```csharp
char letter = 'A';
char digit = '7';
char symbol = '@';
char unicode = '\u041F';  // 'П' (кириллица)
char newline = '\n';
char tab = '\t';

string text = "Привет, мир!";
string path = @"C:\Users\Name";  // verbatim string (без экранирования)
string multi = @"Строка 1
Строка 2";  // многострочный verbatim
```

**Интерполяция строк (C# 6+):**
```csharp
string name = "Алекс";
int age = 20;
string msg = $"Имя: {name}, Возраст: {age}";  // Имя: Алекс, Возраст: 20
string calc = $"{2 + 2} = 4";  // 4 = 4
string formatted = $"Цена: {19.99:C}";  // Цена: 19,99 ₽ (зависит от культуры)
```

## 5. Константы и readonly

```csharp
// const — константа времени КОМПИЛЯЦИИ (неявно static)
const double PI = 3.14159265359;
const string AppName = "MyApp";

// readonly — константа времени ВЫПОЛНЕНИЯ (только для полей класса)
class Config
{
    public readonly string ConnectionString;

    public Config(string cs)
    {
        ConnectionString = cs;  // можно назначить в конструкторе
    }
}
```

## 6. Преобразования типов

### Неявное (безопасное, без потери данных)
```csharp
int i = 42;
long l = i;           // int → long
float f = 3.14F;
double d = f;         // float → double
int x = 10;
decimal dec = x;      // int → decimal
```

### Явное (приведение, возможна потеря данных)
```csharp
double d = 3.14;
int i = (int)d;       // 3 — отбрасывается дробная часть

long big = 1_000_000_000_000L;
int small = (int)big; // переполнение! (результат некорректен без checked)
```

### Конвертация через `Convert` и `Parse`
```csharp
string s = "42";
int n1 = int.Parse(s);           // исключение при ошибке
int n2 = Convert.ToInt32(s);     // возвращает 0 при null
bool ok = int.TryParse(s, out int n3);  // безопасный способ (true/false)

// ToString()
int num = 42;
string str = num.ToString();     // "42"
string hex = num.ToString("X");  // "2A" (шестнадцатеричный)
```

### Проверка переполнения (`checked` / `unchecked`)
```csharp
int max = int.MaxValue;
// int overflow = max + 1;  // тихо переполняется в unchecked (по умолчанию)

checked
{
    int overflow = max + 1;  // OverflowException!
}
```

## 7. Nullable типы (значимые типы, которые могут быть null)

```csharp
int? nullableInt = null;      // синтаксический сахар для Nullable<int>
int? value = 42;

bool hasValue = value.HasValue;
int actual = value.Value;     // исключение, если null!
int safe = value ?? 0;        // null-coalescing: если null → 0

// Null-conditional operator (C# 6+)
string? name = null;
int? length = name?.Length;   // null, если name == null
```

## 8. Область видимости и время жизни

```csharp
void Demo()
{
    int a = 1;  // локальная переменная — живет до конца блока

    if (true)
    {
        int b = 2;  // видна только внутри этого блока
        a = b;      // OK
    }
    // b здесь недоступна — ошибка компиляции

    for (int i = 0; i < 3; i++) { }  // i видна только в цикле
}
```

## 9. Рекомендации по стилю (Microsoft C# Coding Conventions)

- Локальные переменные: `camelCase` — `userName`, `itemCount`
- Константы: `PascalCase` — `MaxSize`, `DefaultTimeout`
- Публичные поля/свойства: `PascalCase`
- `var` — когда тип очевиден справа (`var list = new List<string>()`)
- Явный тип — когда тип неочевиден или для читаемости
