**Целевая версия:** C# 12 / .NET 8

---

## 1. Что такое C# и .NET

**C#** (читается «си-шарп») — современный объектно-ориентированный язык программирования от Microsoft. Используется для:
- Десктопных приложений (WPF, WinForms, MAUI)
- Веб-приложений (ASP.NET Core)
- Мобильных приложений (.NET MAUI, Xamarin)
- Игр (Unity, Godot с C#)
- Облачных сервисов и микросервисов
- Консольных утилит и сервисов

**.NET** — это платформа выполнения (runtime) и библиотека классов. Код C# компилируется в **IL** (Intermediate Language), который выполняется **CLR** (Common Language Runtime) с JIT-компиляцией в машинный код.

**.NET 8** — текущая LTS-версия (Long Term Support), вышедшая в ноябре 2023. Поддерживается до ноября 2026.

## 3. Создание первого проекта

Консольное приложение — самый простой тип проекта для обучения.

```bash
dotnet new console -n MyFirstApp
cd MyFirstApp
```

Структура проекта:
```
MyFirstApp/
├── MyFirstApp.csproj    # Файл проекта (MSBuild)
├── Program.cs           # Точка входа
└── obj/                 # Временные файлы сборки
```

---

## 4. Структура Program.cs (C# 12 / .NET 8)

В .NET 6+ используется **top-level statements** — не нужно писать `class Program` и `static void Main()`.

```csharp
// Program.cs
using System;

Console.WriteLine("Hello, World!");
```

**Разбор:**
- `using System;` — подключает пространство имён `System` (где лежит `Console`)
- `Console.WriteLine(...)` — выводит строку в консоль с переводом строки

---

## 5. Запуск программы

```bash
dotnet run
```

**Вывод:**
```
Hello, World!
```

---

## 6. Сборка и публикация

```bash
# Сборка в Debug (по умолчанию)
dotnet build

# Сборка в Release (оптимизированная)
dotnet build -c Release

# Публикация как самодостаточный исполняемый файл
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

## 7. Полезные команды CLI

| Команда | Описание |
|---------|----------|
| `dotnet new console` | Создать консольное приложение |
| `dotnet new classlib` | Создать библиотеку классов |
| `dotnet new sln` | Создать файл решения (.sln) |
| `dotnet add package <pkg>` | Добавить NuGet-пакет |
| `dotnet restore` | Восстановить зависимости |
| `dotnet run` | Собрать и запустить |
| `dotnet test` | Запустить тесты |
| `dotnet --info` | Информация об установленном SDK |

## 9. Домашнее задание

1. Установите .NET 8 SDK
2. Создайте проект: `dotnet new console -n Lesson1_Hello`
3. Измените `Program.cs` так, чтобы выводилось ваше имя и текущая дата:
   ```csharp
   Console.WriteLine($"Привет, {Environment.UserName}!");
   Console.WriteLine($"Сегодня: {DateTime.Now:dd.MM.yyyy}");
   ```
4. Запустите: `dotnet run`
5. Поэкспериментируйте с `dotnet build -c Release`
