**Целевая версия:** C# 12 / .NET 8

## 1. Арифметические операторы

```csharp
int a = 10, b = 3;

int sum = a + b;       // 13
int diff = a - b;      // 7
int prod = a * b;      // 30
int quot = a / b;      // 3 (целочисленное деление!)
int rem = a % b;       // 1 (остаток от деления)

// Унарные
int inc = ++a;         // 11 (префиксный инкремент)
int dec = --b;         // 2 (префиксный декремент)
int postInc = a++;     // 11, потом a = 12
int postDec = b--;     // 2, потом b = 1
```

**Важно:** Деление `int / int` даёт `int`. Для дробного результата приведите к `double`:
```csharp
double result = (double)a / b;  // 3.333...
```

## 2. Операторы присваивания

```csharp
int x = 10;
x += 5;   // x = x + 5 → 15
x -= 3;   // 12
x *= 2;   // 24
x /= 4;   // 6
x %= 5;   // 1
```

## 3. Операторы сравнения (возвращают `bool`)

```csharp
int a = 5, b = 10;

bool eq = (a == b);   // false
bool ne = (a != b);   // true
bool gt = (a > b);    // false
bool lt = (a < b);    // true
bool ge = (a >= b);   // false
bool le = (a <= b);   // true
```

## 4. Логические операторы

```csharp
bool p = true, q = false;

bool and = p & q;     // false (логическое И, вычисляет ОБЕ стороны)
bool or  = p | q;     // true  (логическое ИЛИ, вычисляет ОБЕ стороны)
bool xor = p ^ q;     // true  (исключающее ИЛИ)
bool not = !p;        // false (отрицание)

// Короткое замыкание (short-circuit) — РЕКОМЕНДУЕТСЯ
bool andSC = p && q;  // false, q НЕ вычисляется
bool orSC  = p || q;  // true,  q НЕ вычисляется
```

**Пример короткого замыкания:**
```csharp
string? s = null;
if (s != null && s.Length > 5) { }  // s.Length не вызовется при s == null
```

## 5. Побитовые операторы (для целых чисел)

```csharp
int a = 6;   // 0110
int b = 3;   // 0011

int bitAnd = a & b;  // 0010 → 2
int bitOr  = a | b;  // 0111 → 7
int bitXor = a ^ b;  // 0101 → 5
int not    = ~a;     // ...11111001 → -7 (дополнительный код)
int shl    = a << 1; // 1100 → 12
int shr    = a >> 1; // 0011 → 3
```

## 6. Условная конструкция if / else

```csharp
int score = 85;

if (score >= 90)
{
    Console.WriteLine("Отлично!");
}
else if (score >= 70)
{
    Console.WriteLine("Хорошо");
}
else if (score >= 50)
{
    Console.WriteLine("Удовлетворительно");
}
else
{
    Console.WriteLine("Неудовлетворительно");
}

// Блоки {} обязательны, если больше одной инструкции
// Для одной инструкции можно без скобок (но лучше всегда ставить):
if (score > 100) Console.WriteLine("Ошибка!");
```

## 7. Тернарный оператор (?:)

```csharp
int age = 20;
string status = age >= 18 ? "взрослый" : "несовершеннолетний";

// Вложенные (не рекомендуется часто)
string grade = score >= 90 ? "A" : score >= 80 ? "B" : "C";
```

## 8. Switch (классический и pattern matching)

### Классический switch (C# 1.0+)
```csharp
int day = 3;
string dayName;

switch (day)
{
    case 1: dayName = "Понедельник"; break;
    case 2: dayName = "Вторник"; break;
    case 3: dayName = "Среда"; break;
    case 4: dayName = "Четверг"; break;
    case 5: dayName = "Пятница"; break;
    case 6: dayName = "Суббота"; break;
    case 7: dayName = "Воскресенье"; break;
    default: dayName = "Неверный день"; break;
}
```

### Switch expression (C# 8+) — возвращает значение
```csharp
string dayName = day switch
{
    1 => "Понедельник",
    2 => "Вторник",
    3 => "Среда",
    4 => "Четверг",
    5 => "Пятница",
    6 => "Суббота",
    7 => "Воскресенье",
    _ => "Неверный день"  // default
};
```

### Pattern matching (C# 7+)
```csharp
object obj = "hello";

string desc = obj switch
{
    int i when i > 0 => $"Положительное число: {i}",
    int i => $"Число: {i}",
    string s when s.Length > 5 => $"Длинная строка: {s}",
    string s => $"Строка: {s}",
    null => "Null",
    _ => "Другое"
};
```

### Switch с типами (type pattern)
```csharp
void Process(object o)
{
    switch (o)
    {
        case int i:
            Console.WriteLine($"int: {i}");
            break;
        case string s:
            Console.WriteLine($"string: {s}");
            break;
        case double d when d > 0:
            Console.WriteLine($"positive double: {d}");
            break;
        default:
            Console.WriteLine("unknown");
            break;
    }
}
```

## 9. Оператор is / as

```csharp
object obj = "текст";

// is — проверка типа (с pattern matching C# 7+)
if (obj is string s)  // объявление переменной s
{
    Console.WriteLine(s.Length);
}

// as — приведение с возвратом null при неудаче
string? str = obj as string;
if (str != null) { }

// is not (C# 9+)
if (obj is not null) { }
if (obj is not string) { }
```
