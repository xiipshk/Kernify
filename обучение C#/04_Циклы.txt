# Урок 4: Циклы

**Целевая версия:** C# 12 / .NET 8

---

## 1. Цикл while

```csharp
int i = 0;
while (i < 5)
{
    Console.WriteLine(i);  // 0 1 2 3 4
    i++;
}

// Бесконечный цикл
while (true)
{
    // break для выхода
}
```

---

## 2. Цикл do-while (хотя бы одно выполнение)

```csharp
int n;
do
{
    Console.Write("Введите число > 0: ");
    n = int.Parse(Console.ReadLine()!);
} while (n <= 0);

Console.WriteLine($"Вы ввели: {n}");
```

---

## 3. Цикл for

```csharp
// Классическая форма
for (int i = 0; i < 5; i++)
{
    Console.WriteLine(i);  // 0 1 2 3 4
}

// Множественные переменные
for (int i = 0, j = 10; i < j; i++, j--)
{
    Console.WriteLine($"{i} + {j} = {i + j}");
}

// Без инициализации/инкремента (как while)
int k = 0;
for (; k < 3;)
{
    Console.WriteLine(k++);
}
```

---

## 4. Цикл foreach (перебор коллекций)

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };

foreach (int n in numbers)
{
    Console.WriteLine(n);
}

// С строками (перебор char)
foreach (char c in "Hello")
{
    Console.Write(c + " ");  // H e l l o
}

// var в foreach
foreach (var item in numbers) { }
```

**Важно:** В `foreach` переменная итерации **только для чтения** — нельзя изменить элемент коллекции.

## 5. Управление циклом: break и continue

```csharp
// break — полный выход из цикла
for (int i = 0; i < 10; i++)
{
    if (i == 5) break;
    Console.Write(i + " ");  // 0 1 2 3 4
}

Console.WriteLine();

// continue — переход к следующей итерации
for (int i = 0; i < 5; i++)
{
    if (i == 2) continue;
    Console.Write(i + " ");  // 0 1 3 4
}
```

## 6. Вложенные циклы и метки (labels)

```csharp
outer: for (int i = 0; i < 3; i++)
{
    for (int j = 0; j < 3; j++)
    {
        if (i == 1 && j == 1)
        {
            break outer;  // выходит из ВНЕШНЕГО цикла
        }
        Console.WriteLine($"i={i}, j={j}");
    }
}
```

## 7. Pattern matching в циклах (C# 9+)

```csharp
object[] items = { 1, "two", 3.0, "four", 5 };

foreach (var item in items)
{
    if (item is int n)
    {
        Console.WriteLine($"int: {n * 2}");
    }
    else if (item is string s && s.Length > 3)
    {
        Console.WriteLine($"long string: {s}");
    }
}
```

## 8. Цикл по индексам (when you need index)

```csharp
string[] names = { "Анна", "Борис", "Сергей" };

// Классический for с индексом
for (int i = 0; i < names.Length; i++)
{
    Console.WriteLine($"{i + 1}. {names[i]}");
}

// Range и Index (C# 8+)
foreach (var name in names[1..])  // со 2-го элемента до конца
{
    Console.WriteLine(name);
}
```

## 9. Бесконечные циклы с выходом

```csharp
// Вариант 1: while(true) + break
while (true)
{
    var input = Console.ReadLine();
    if (input == "exit") break;
    Console.WriteLine($"Echo: {input}");
}

// Вариант 2: for(;;)
for (;;)
{
    // ...
}
```

## 10. Практические паттерны

### Сумма чисел
```csharp
int sum = 0;
for (int i = 1; i <= 100; i++)
    sum += i;  // 5050
```

### Факториал
```csharp
int n = 5;
long fact = 1;
for (int i = 2; i <= n; i++)
    fact *= i;  // 120
```

### Поиск в массиве
```csharp
int[] arr = { 5, 2, 9, 1, 7 };
int target = 9;
int index = -1;

for (int i = 0; i < arr.Length; i++)
{
    if (arr[i] == target)
    {
        index = i;
        break;
    }
}
```

### Чтение до пустой строки
```csharp
List<string> lines = new();
string? line;
while ((line = Console.ReadLine()) != "")
{
    lines.Add(line);
}
```

## 11. Производительность: for vs foreach

- **Массивы/List<T>**: `for` немного быстрее (нет аллокации итератора)
- **IEnumerable<T> (LINQ, yield)**: только `foreach`
- Для 99% случаев разница незначительна — пишите читаемо

## 13. Краткая шпаргалка

```
while (cond) { }           // предусловие
do { } while (cond);       // постусловие
for (init; cond; step) { } // счётчик
foreach (var x in coll) { }// перебор
break;                     // выход из цикла
continue;                  // следующая итерация
label: break label;        // выход из внешнего цикла
```
