## 1. Higher-Ranked Trait Bounds (HRTB)

### Проблема: время жизни в trait bounds
```rust
// Обычный bound: конкретное время жизни
fn call_with_ref<'a, F>(f: F) where F: Fn(&'a i32) {}

// HRTB: для ЛЮБОГО времени жизни
fn call_with_any_ref<F>(f: F) where F: for<'a> Fn(&'a i32) {}

fn main() {
    let x = 5;
    call_with_any_ref(|r| println!("{}", r)); // Замыкание работает с любым &'a i32
}
```

### Синтаксис `for<'a>`
```rust
// Эквивалентно:
trait Fn<Args> {
    type Output;
    fn call(&self, args: Args) -> Self::Output;
}

// HRTB версия:
fn takes_hrtb<F>(f: F) where F: for<'a> Fn(&'a i32) -> &'a i32 {}

// Множественные lifetimes
fn multi_hrtb<F>(f: F) where F: for<'a, 'b> Fn(&'a i32, &'b i32) {}

// В trait bounds
trait Processor {
    fn process<'a>(&self, data: &'a [u8]) -> &'a [u8];
}

// Требует, чтобы метод работал для любого 'a
fn use_processor<P: for<'a> Processor>(p: P) {}
```

### Практический пример: коллбэки с лендингом
```rust
struct Data<'a>(&'a str);

fn with_data<F>(f: F) where F: for<'a> FnOnce(Data<'a>) {
    let s = String::from("hello");
    f(Data(&s));
}
```

## 2. Generic Associated Types (GAT)

### Базовый синтаксис
```rust
trait Iterator {
    type Item;
    fn next(&mut self) -> Option<Self::Item>;
}

// С GAT — ассоциированный тип с параметрами
trait LendingIterator {
    type Item<'a> where Self: 'a;
    fn next<'a>(&'a mut self) -> Option<Self::Item<'a>>;
}

// Пример: итератор, возвращающий ссылки на внутренние данные
struct WindowIter<'a, T> {
    slice: &'a [T],
    pos: usize,
}

impl<'a, T> LendingIterator for WindowIter<'a, T> {
    type Item<'b> = &'b [T] where 'a: 'b;

    fn next<'b>(&'b mut self) -> Option<Self::Item<'b>> {
        if self.pos + 2 > self.slice.len() { return None; }
        let window = &self.slice[self.pos..self.pos+2];
        self.pos += 1;
        Some(window)
    }
}
```

### GAT в стандартной библиотеке (Rust 1.65+)
```rust
// std::ops::FnOnce с GAT (упрощённо)
trait FnOnce<Args> {
    type Output;
    fn call_once(self, args: Args) -> Self::Output;
}

// Async_fn_traits (nightly)
trait AsyncFnOnce<Args> {
    type Output<'a>: Future<Output = Self::Output> where Self: 'a;
    fn call_once(self, args: Args) -> Self::Output<'_>;
}
```

### GAT для стриминговых API
```rust
trait Stream {
    type Item<'a> where Self: 'a;
    fn poll_next<'a>(self: Pin<&'a mut Self>, cx: &mut Context) -> Poll<Option<Self::Item<'a>>>;
}
```

## 3. Const Generics

### Базовое использование
```rust
fn print_array<const N: usize>(arr: [i32; N]) {
    println!("Length: {}", N);
    for x in arr { println!("{}", x); }
}

fn main() {
    print_array([1, 2, 3]);        // N = 3
    print_array([1, 2, 3, 4, 5]);  // N = 5
}
```

### Const generics в struct
```rust
struct FixedArray<T, const N: usize> {
    data: [T; N],
}

impl<T, const N: usize> FixedArray<T, N> {
    fn new(default: T) -> Self where T: Copy {
        FixedArray { data: [default; N] }
    }

    fn len(&self) -> usize { N }

    fn get(&self, index: usize) -> Option<&T> {
        self.data.get(index)
    }
}

fn main() {
    let arr: FixedArray<i32, 5> = FixedArray::new(0);
    println!("Len: {}", arr.len()); // 5 (compile-time!)
}
```

### Const выражения
```rust
fn take_const<const N: usize>() {}

fn main() {
    const SIZE: usize = 10;
    take_const::<SIZE>();
    take_const::<{ 2 + 3 }>();        // выражения
    take_const::<{ SIZE * 2 }>();     // с константами
    // take_const::<{ std::mem::size_of::<i32>() }>(); // const fn в const generics (nightly)
}
```

### Const generic bounds (Rust 1.79+)
```rust
trait ConstBound<const N: usize> {}

fn foo<const N: usize>() where N: ConstBound<N> {}
```

## 4. `impl Trait` в разных позициях

### Return position (уже знаем)
```rust
fn make_iter() -> impl Iterator<Item = i32> {
    (0..10).map(|x| x * 2)
}
```

### Argument position (sugar for generic)
```rust
// Эквивалентно:
fn process(iter: impl Iterator<Item = i32>) {}

// Развёрнуто:
fn process<I: Iterator<Item = i32>>(iter: I) {}
```

### Type aliases с `impl Trait` (Rust 1.74+)
```rust
type MyIter = impl Iterator<Item = i32>;

fn get_iter() -> MyIter {
    (0..5).map(|x| x * 2)
}

// В структурах (nightly: type_ascription)
struct Container {
    iter: impl Iterator<Item = i32>, // Только в nightly!
}
```

### `impl Trait` в ассоциированных типах
```rust
trait Factory {
    type Product: Debug;
    fn create(&self) -> Self::Product;
}

struct MyFactory;
impl Factory for MyFactory {
    type Product = impl Debug; // Нельзя! impl Trait не в type aliases в traits
}
```

## 5. Specialization (min_specialization)

### Базовый пример (nightly)
```rust
#![feature(min_specialization)]

trait ToStringExt {
    fn to_string_ext(&self) -> String;
}

// Default implementation
impl<T: Display> ToStringExt for T {
    default fn to_string_ext(&self) -> String {
        format!("Display: {}", self)
    }
}

// Specialization для String
impl ToStringExt for String {
    fn to_string_ext(&self) -> String {
        format!("String: {}", self)
    }
}

// Specialization для &str
impl ToStringExt for &str {
    fn to_string_ext(&self) -> String {
        format!("Str: {}", self)
    }
}

fn main() {
    println!("{}", 42.to_string_ext());      // "Display: 42"
    println!("{}", String::from("hi").to_string_ext()); // "String: hi"
    println!("{}", "hello".to_string_ext());  // "Str: hello"
}
```

### Ограничения specialization
```rust
// 1. Тrait должен быть marked как `default` в базовой имплементации
// 2. Специализация только для более конкретных типов
// 3. Нельзя специализировать по lifetimes (soundness)
// 4. `min_specialization` — ограниченная форма
```

## 6. Orphan Rules и Newtype Pattern

### Orphan Rule (правило сироты)
```rust
// МОЖНО: trait или type определён в текущем крейте
impl MyTrait for MyType {}        // OK
impl ForeignTrait for MyType {}   // OK
impl MyTrait for ForeignType {}   // OK

// НЕЛЬЗЯ: оба foreign
// impl ForeignTrait for ForeignType {} // ERROR!
```

### Newtype Pattern
```rust
// Обёртка для реализации foreign trait для foreign type
struct MyVec(Vec<i32>);

impl Deref for MyVec {
    type Target = Vec<i32>;
    fn deref(&self) -> &Self::Target { &self.0 }
}

impl DerefMut for MyVec {
    fn deref_mut(&mut self) -> &mut Self::Target { &mut self.0 }
}

// Теперь можно реализовать foreign traits
use std::fmt::Display;
impl Display for MyVec {
    fn fmt(&self, f: &mut std::fmt::Formatter) -> std::fmt::Result {
        write!(f, "MyVec({:?})", self.0)
    }
}
```

### Extension Traits
```rust
// Расширение foreign types своими методами
trait VecExt {
    fn median(&self) -> Option<f64>;
}

impl<T: Copy + Ord> VecExt for Vec<T> {
    fn median(&self) -> Option<f64> {
        if self.is_empty() { return None; }
        let mut sorted = self.clone();
        sorted.sort();
        let mid = sorted.len() / 2;
        if sorted.len() % 2 == 0 {
            Some((sorted[mid-1] as f64 + sorted[mid] as f64) / 2.0)
        } else {
            Some(sorted[mid] as f64)
        }
    }
}

fn main() {
    let v = vec![3, 1, 4, 1, 5];
    println!("Median: {:?}", v.median());
}
```

## 7. Marker Traits

### Стандартные маркеры
```rust
// Send — можно передать владение в другой поток
// Sync — можно делить &T между потоками (&T: Send)
// Unpin — можно перемещать в памяти (не self-referential)
// Freeze — immutable (no UnsafeCell inside)
// Copy — bitwise copy
// Clone — explicit clone
// Sized — известный размер (DST не Sized)
```

### Авто-реализация
```rust
// Большинство типов: Send + Sync
// НЕ Send/Sync: Rc, RefCell, *const T, *mut T
// НЕ Sync: Cell, RefCell, MutexGuard (в некоторых случаях)

// Ручная реализация (unsafe)
struct MyPtr<T>(*mut T);
unsafe impl<T: Send> Send for MyPtr<T> {}
unsafe impl<T: Sync> Sync for MyPtr<T> {}
```

### Пользовательские маркеры
```rust
// Sealed trait pattern
mod private {
    pub trait Sealed {}
}

pub trait MyTrait: private::Sealed {
    fn method(&self);
}

impl private::Sealed for MyType {}
impl MyTrait for MyType { ... }

// Теперь MyTrait можно имплементировать ТОЛЬКО в этом крейте
```

## 8. Sealed Traits (запечатанные трейты)

### Через модуль
```rust
// lib.rs
mod sealed {
    pub trait Sealed {}
}

pub trait PublicTrait: sealed::Sealed {
    fn public_method(&self);
}

// В том же крейте — можно имплементировать
impl sealed::Sealed for MyStruct {}
impl PublicTrait for MyStruct { ... }

// В другом крейте — НЕЛЬЗЯ имплементировать sealed::Sealed
// Поэтому PublicTrait тоже нельзя имплементировать
```

### Через `enum` (стабильно)
```rust
pub enum Sealed {}

pub trait MyTrait {
    type Sealed: Sealed;
    fn method(&self);
}

// Внешний код не может создать Sealed
```

## 9. Trait Objects и `dyn`

### Object Safety
```rust
// Trait object safe (можно сделать dyn Trait):
trait ObjectSafe {
    fn method(&self) -> i32;
    fn method_with_default(&self) -> i32 { 42 }
}

// НЕ object safe:
trait NotObjectSafe {
    fn generic_method<T>(&self, t: T);     // generic method
    fn returns_self(&self) -> Self;        // returns Self
    fn static_method() -> i32;             // no &self
    const CONST: i32;                      // associated const
}
```

### `dyn Trait` с bounds
```rust
// dyn Trait + Send + Sync + 'static
fn takes_send_sync(x: &dyn Debug + Send + Sync) {}

// dyn с lifetime
fn takes_ref<'a>(x: &'a (dyn Debug + 'a)) {}

// Thin pointer (только для Single trait без auto traits)
fn thin_ptr(x: &dyn Debug) {}  // fat pointer (data + vtable)
```

### VTable layout
```rust
// VTable содержит:
// - drop_in_place (деструктор)
// - size
// - align
// - методы trait'а
```

## 11. Практические упражнения

### Упражнение 1: GAT для кэша с лендингом
```rust
trait Cache {
    type Entry<'a> where Self: 'a;
    fn get<'a>(&'a self, key: &str) -> Option<Self::Entry<'a>>;
    fn insert(&mut self, key: String, value: String);
}

struct StringCache {
    data: HashMap<String, String>,
}

impl Cache for StringCache {
    type Entry<'a> = &'a str;

    fn get<'a>(&'a self, key: &str) -> Option<Self::Entry<'a>> {
        self.data.get(key).map(|s| s.as_str())
    }

    fn insert(&mut self, key: String, value: String) {
        self.data.insert(key, value);
    }
}
```

### Упражнение 2: Const generic матрица
```rust
use std::ops::{Add, Mul};

struct Matrix<T, const R: usize, const C: usize> {
    data: [[T; C]; R],
}

impl<T: Copy + Default + Add<Output = T> + Mul<Output = T>, const R: usize, const C: usize, const N: usize>
    Mul<Matrix<T, C, N>> for Matrix<T, R, C>
{
    type Output = Matrix<T, R, N>;

    fn mul(self, rhs: Matrix<T, C, N>) -> Self::Output {
        let mut result = Matrix { data: [[T::default(); N]; R] };
        for i in 0..R {
            for j in 0..N {
                let mut sum = T::default();
                for k in 0..C {
                    sum = sum + self.data[i][k] * rhs.data[k][j];
                }
                result.data[i][j] = sum;
            }
        }
        result
    }
}
```

### Упражнение 3: HRTB для коллбэков с borrowing
```rust
struct Processor {
    data: Vec<i32>,
}

impl Processor {
    fn with_data<F>(&self, f: F) where F: for<'a> FnOnce(&'a [i32]) {
        f(&self.data);
    }
}

fn main() {
    let p = Processor { data: vec![1,2,3] };
    p.with_data(|slice| {
        println!("Sum: {}", slice.iter().sum::<i32>());
    });
}
```

### Упражнение 4: Sealed trait для внутреннего API
```rust
// internal/mod.rs
mod sealed {
    pub trait Sealed {}
}

pub trait InternalApi: sealed::Sealed {
    fn internal_method(&self);
}

// internal/impl.rs
impl sealed::Sealed for MyStruct {}
impl InternalApi for MyStruct { ... }

// public_api.rs
pub use internal::InternalApi; // Реэкспорт, но impl только внутри крейта
```

## 12. Типичные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `the trait cannot be made into an object` | Не object safe | Уберите generic методы, Self в return, static методы |
| `const generics not supported` | Старый Rust | Обновите до 1.51+ |
| `type parameter must be used` | Неиспользуемый const generic | Используйте в типе или добавьте `_` |
| `specialization not allowed` | Не nightly или неправильный порядок | Используйте `min_specialization` feature |
| `orphan rule violated` | Foreign trait для foreign type | Newtype pattern |

## 13. Шпаргалка: Advanced Traits

| Фича | Синтаксис | Стабильность |
|------|-----------|--------------|
| HRTB | `for<'a> Fn(&'a T)` | Stable |
| GAT | `type Item<'a> where Self: 'a` | 1.65+ |
| Const Generics | `const N: usize` | 1.51+ |
| `impl Trait` in return | `-> impl Trait` | Stable |
| `impl Trait` in args | `fn(f: impl Trait)` | Stable |
| `impl Trait` in type alias | `type X = impl Trait` | 1.74+ |
| Specialization | `default impl` | Nightly |
| Sealed Traits | `trait T: private::Sealed` | Stable (pattern) |
| Auto traits | `auto trait` | Nightly |
