## 1. Что такое Rust?

**Rust** — это системный язык программирования, разработанный с фокусом на:
- **Безопасность памяти** без сборщика мусора (garbage collector)
- **Параллелизм** без гонок данных (data races)
- **Производительность**, сопоставимую с C/C++
- **Выразительность** и современный синтаксис

### Ключевые особенности:
| Особенность | Описание |
|------------|----------|
| Ownership (владение) | Каждое значение имеет одного владельца; при выходе из области видимости память освобождается автоматически |
| Borrowing (заимствование) | Ссылки на данные с проверками на этапе компиляции |
| Lifetimes (времени жизни) | Статический анализ ссылок для предотвращения висячих указателей |
| Zero-cost abstractions | Абстракции, не добавляющие накладных расходов во время выполнения |

## 2. Установка Rust

### Windows
```bash
# Скачайте и запустите rustup-init.exe с https://rustup.rs/
# Или через winget:
winget install Rustlang.Rustup
```

### Linux / macOS
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
```

### Проверка установки
```bash
rustc --version    # Компилятор
cargo --version    # Менеджер пакетов и сборки
rustup --version   # Инструмент управления версиями
```

### Обновление Rust
```bash
rustup update
```

## 3. Cargo — система сборки и менеджер пакетов

**Cargo** входит в состав Rust и выполняет несколько ролей:
- Сборка кода (`cargo build`)
- Запуск программы (`cargo run`)
- Тестирование (`cargo test`)
- Генерация документации (`cargo doc`)
- Публикация пакетов (`cargo publish`)

### Создание нового проекта
```bash
cargo new hello_world
cd hello_world
```

Структура проекта:
```
hello_world/
├── Cargo.toml      # Манифест проекта (метаданные, зависимости)
└── src/
    └── main.rs     # Точка входа программы
```

### Cargo.toml — манифест проекта
```toml
[package]
name = "hello_world"
version = "0.1.0"
edition = "2021"

[dependencies]
# Здесь добавляются внешние зависимости
```

## 4. Первая программа: Hello, World!

### Создание и запуск
```bash
cargo new hello_world
cd hello_world
cargo run
```

### Код main.rs
```rust
fn main() {
    println!("Hello, World!");
}
```

### Разбор кода:
| Элемент | Описание |
|---------|----------|
| `fn main()` | Точка входа в программу |
| `println!` | Макрос для печати в stdout (обратите внимание на `!`) |
| `"Hello, World!"` | Строковый литерал (тип `&str`) |
| `;` | Завершает выражение (statement) |

### Компиляция без запуска
```bash
cargo build          # Debug-сборка (в target/debug/)
cargo build --release # Release-сборка (в target/release/, оптимизированная)
```

## 5. Диагностика компилятора

Rust nổiся информативными сообщениями об ошибках. Давайте посмотрим на примеры.

### Ошибка: неиспользуемая переменная
```rust
fn main() {
    let x = 5;
    // warning: unused variable: `x`
}
```
```
warning: unused variable: `x`
 --> src/main.rs:2:9
  |
2 |     let x = 5;
  |         ^
  |
  = note: `#[warn(unused_variables)]` on by default
help: if this is intentional, prefix it with an underscore: `_x`
```

### Ошибка: изменение неизменяемой переменной
```rust
fn main() {
    let x = 5;
    x = 6; // error!
}
```
```
error[E0384]: cannot assign twice to immutable variable `x`
 --> src/main.rs:3:5
  |
2 |     let x = 5;
  |         -
  |         |
  |         first assignment to `x`
  |         help: make this binding mutable: `mut x`
3 |     x = 6;
  |     ^^^^^ cannot assign twice to immutable variable
```

### Ошибка: несоответствие типов
```rust
fn main() {
    let x: i32 = "hello"; // error!
}
```
```
error[E0308]: mismatched types
 --> src/main.rs:2:15
  |
2 |     let x: i32 = "hello";
  |               ^^^^^^^ expected `i32`, found `&str`
```

### Полезные флаги компилятора
```bash
# Показать все предупреждения
cargo build -- --warn=unused

# Остановиться на первой ошибке
cargo build -- -Z panic-on-error

# Вывод в JSON для инструментов
cargo build --message-format=json
```

## 6. Полезные команды Cargo

| Команда | Описание |
|---------|----------|
| `cargo new <name>` | Создать новый проект |
| `cargo init` | Инициализировать проект в текущей папке |
| `cargo build` | Собрать проект (debug) |
| `cargo build --release` | Собрать оптимизированную версию |
| `cargo run` | Собрать и запустить |
| `cargo check` | Быстрая проверка типов без сборки бинарника |
| `cargo test` | Запустить тесты |
| `cargo doc` | Сгенерировать документацию |
| `cargo clean` | Удалить артефакты сборки (target/) |
| `cargo update` | Обновить зависимости до последних версий |

## 8. Типичные ошибки новичков

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `cannot assign twice to immutable variable` | Переменная объявлена без `mut` | Добавьте `mut`: `let mut x = 5;` |
| `mismatched types` | Типы не совпадают | Проверьте аннотацию типа или значение |
| `expected function, found macro` | Забыт `!` после имени макроса | Используйте `println!` вместо `println` |
| `binary assignment to borrow` | Попытка изменить через неминутую ссылку | Используйте `&mut` или сделайте переменную `mut` |
| `use of moved value` | Значение перемещено (move semantics) | Используйте заимствование (`&`) или клонирование (`.clone()`) |
