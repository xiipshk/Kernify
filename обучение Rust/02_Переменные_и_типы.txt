## 1. Объявление переменных: `let` и `mut`

### Неизменяемые переменные (по умолчанию)
```rust
fn main() {
    let x = 5;
    println!("x = {}", x);
    // x = 6; // Ошибка компиляции!
}
```

### Изменяемые переменные
```rust
fn main() {
    let mut x = 5;
    println!("x = {}", x);
    x = 6; // OK
    println!("x = {}", x);
}
```

**Ключевой момент:** В Rust переменные **неизменяемы по умолчанию**. Это предотвращает случайные изменения и упрощает рассуждение о коде.

## 2. Shadowing (переопределение переменных)

Shadowing позволяет создать новую переменную с тем же именем:
```rust
fn main() {
    let x = 5;
    let x = x + 1;      // Новая переменная x, скрывает предыдущую
    let x = x * 2;      // Ещё одна новая переменная x
    println!("x = {}", x); // 12
}
```

### Разница между `mut` и shadowing:
| Аспект | `mut` | Shadowing (`let x = ...`) |
|--------|-------|---------------------------|
| Тип данных | Не может измениться | Может измениться |
| Память | Та же ячейка | Новая аллокация |
| Использование | Изменение значения | Трансформация + смена типа |

```rust
// Shadowing позволяет сменить тип:
let spaces = "   ";     // &str
let spaces = spaces.len(); // usize — новый тип!
```

## 3. Скалярные типы

### Целые числа (Integers)
| Длина | Знаковые | Беззнаковые | Диапазон (пример для 8 бит) |
|-------|----------|-------------|----------------------------|
| 8-bit | `i8` | `u8` | -128..127 / 0..255 |
| 16-bit | `i16` | `u16` | -32,768..32,767 / 0..65,535 |
| 32-bit | `i32` | `u32` | ±2 млрд / 0..4 млрд |
| 64-bit | `i64` | `u64` | ±9 квинтиллионов / 0..18 квинтиллионов |
| 128-bit | `i128` | `u128` | Очень большие |
| arch | `isize` | `usize` | Зависит от архитектуры (32/64 бит) |

**Литералы:**
```rust
let decimal = 98_222;      // 98,222 (подчёркивания для читаемости)
let hex = 0xff;            // 255
let octal = 0o77;          // 63
let binary = 0b1111_0000;  // 240
let byte = b'A';           // u8 (только ASCII)
```

**По умолчанию:** `i32` — самый быстрый на современных CPU.

### Числа с плавающей точкой
```rust
let x = 2.0;        // f64 (по умолчанию)
let y: f32 = 3.0;   // f32 (single precision)
```

| Тип | Размер | Точность |
|-----|--------|----------|
| `f32` | 32 бита | ~7 знаков |
| `f64` | 64 бита | ~15 знаков (по умолчанию) |

**Операции:** `+`, `-`, `*`, `/`, `%` (остаток от деления)

### Булев тип (`bool`)
```rust
let t = true;
let f: bool = false; // явная аннотация
```
Используется в `if`, `while`, логических операторах: `&&`, `||`, `!`

### Символьный тип (`char`)
```rust
let c = 'z';
let heart = '❤';
let chinese = '中';
let emoji = '😀';
```
- **Всегда 4 байта** (Unicode Scalar Value)
- Одинарные кавычки `'` (не двойные `"`)

## 4. Составные типы

### Кортежи (Tuples)
Фиксированный размер,heterogeneous (разные типы):
```rust
fn main() {
    let tup: (i32, f64, u8) = (500, 6.4, 1);

    // Деструктуризация
    let (x, y, z) = tup;
    println!("x={}, y={}, z={}", x, y, z);

    // Доступ по индексу (начиная с 0)
    println!("tup.0 = {}", tup.0);
    println!("tup.1 = {}", tup.1);
    println!("tup.2 = {}", tup.2);
}
```

**Пустой кортеж `()`** — это тип `unit` (аналог `void`), возвращается функциями без явного `return`.

### Массивы (Arrays)
Фиксированный размер, homogeneous (один тип):
```rust
fn main() {
    let arr = [1, 2, 3, 4, 5];           // Тип: [i32; 5]
    let arr: [i32; 5] = [1, 2, 3, 4, 5]; // Явная аннотация
    let zeros = [0; 5];                  // [0, 0, 0, 0, 0]

    println!("first = {}", arr[0]);
    println!("len = {}", arr.len());
}
```

**Важно:** Индексация с проверкой границ во время выполнения (panic при выходе за границы):
```rust
let arr = [1, 2, 3];
// println!("{}", arr[5]); // PANIC: index out of bounds
```

**Slice (срез) — динамический взгляд на массив:**
```rust
let arr = [1, 2, 3, 4, 5];
let slice = &arr[1..3]; // &[2, 3] — тип &[i32]
```

## 5. Константы (`const`)

```rust
const MAX_POINTS: u32 = 100_000;
const PI: f64 = 3.14159265359;
const GREETING: &str = "Hello, Rust!";
```

### Правила констант:
| Правило | Описание |
|---------|----------|
| Обязательная аннотация типа | `const NAME: TYPE = VALUE;` |
| Только константные выражения | Нельзя вызывать функции (кроме `const fn`) |
| Имена в SCREAMING_SNAKE_CASE | `MAX_SIZE`, `DEFAULT_TIMEOUT` |
| Время жизни `'static` | Живут всё время выполнения программы |
| Нельзя использовать `mut` | Константы всегда неизменяемы |

### `const` vs `let`:
```rust
const GLOBAL: i32 = 42;    // Глобальная, compile-time
let local = 42;            // Локальная, runtime
```

## 6. Приведение типов (Casting)

```rust
fn main() {
    let x: i32 = 42;
    let y: f64 = x as f64;    // Явное приведение

    let a = 10u8;
    let b = a as u16;         // Расширение (безопасно)

    let big = 1000i32;
    let small = big as u8;    // Усечение! 1000 % 256 = 232
    println!("small = {}", small); // 232
}
```

**Правило:** `as` используется для примитивных типов. Для сложных — `From`/`Into` трейты.

## 8. Типичные ошибки новичков

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `cannot assign twice to immutable variable` | Забыли `mut` | Добавьте `mut` или используйте shadowing |
| `mismatched types` | Присваивание значения не того типа | Проверьте тип, используйте `as` или измените аннотацию |
| `index out of bounds` | Обращение к несуществующему индексу массива | Проверяйте длину: `if idx < arr.len()` |
| `overflow` при `as` | Усечение большого числа в маленький тип | Проверяйте диапазон или используйте `try_from()` |
| `expected tuple with N elements` | Неправильное число элементов при деструктуризации | Убедитесь, что количество переменных совпадает |
| `use of moved value` | Попытка использовать кортеж после частичной деструктуризации | Используйте `..` для игнорирования или клонируйте |

## 9. Таблица: Сравнение типов

| Категория | Типы | Размер | Mutability | Stack/Heap |
|-----------|------|--------|------------|------------|
| Integers | `i8`..`i128`, `u8`..`u128`, `isize`, `usize` | 1-16 байт | `mut` | Stack |
| Floats | `f32`, `f64` | 4/8 байт | `mut` | Stack |
| Bool | `bool` | 1 байт | `mut` | Stack |
| Char | `char` | 4 байта | `mut` | Stack |
| Tuple | `(T1, T2, ...)` | Сумма размеров | `mut` | Stack |
| Array | `[T; N]` | N * size_of(T) | `mut` | Stack |
| Const | `const` | Зависит от типа | Нет | Static/Read-only |
