# Урок 3: Управление потоком выполнения

## Цели урока
После изучения этого урока вы сможете:
- Использовать условные конструкции `if`, `else if`, `else`
- Применять `if` как выражение (expression)

- Управлять циклами через `break` и `continue`
- Использовать метки циклов (loop labels)
- Понимать pattern matching в `match` (базовое введение)

## 1. Условные конструкции: `if` и `else`

### Базовый синтаксис
```rust
fn main() {
    let number = 7;

    if number < 5 {
        println!("Меньше 5");
    } else if number < 10 {
        println!("От 5 до 9");
    } else {
        println!("10 или больше");
    }
}
```

### `if` как выражение (expression)
В Rust `if` возвращает значение — его можно присваивать переменным:
```rust
fn main() {
    let condition = true;
    let number = if condition { 5 } else { 6 };
    println!("number = {}", number); // 5

    // Типы веток должны совпадать!
    // let error = if condition { 5 } else { "six" }; // Ошибка компиляции
}
```

### Условие должно быть `bool`
```rust
fn main() {
    let x = 5;
    // if x { ... } // Ошибка: ожидается bool, найдено i32
    if x != 0 {     // Правильно: явное сравнение
        println!("Не ноль");
    }
}
```

## 2. Циклы

### `loop` — бесконечный цикл
```rust
fn main() {
    let mut count = 0;
    loop {
        count += 1;
        if count == 3 {
            break; // Выход из цикла
        }
    }
    println!("count = {}", count); // 3
}
```

#### Возврат значения из `loop`
```rust
fn main() {
    let mut counter = 0;
    let result = loop {
        counter += 1;
        if counter == 10 {
            break counter * 2; // Возврат значения
        }
    };
    println!("result = {}", result); // 20
}
```

### `while` — цикл с условием
```rust
fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("ПУСК!");
}
```

### `for` — итерация по коллекциям
```rust
fn main() {
    // Итерация по диапазону
    for i in 1..=3 { // 1, 2, 3 (включительно)
        println!("{}", i);
    }

    // Итерация по массиву
    let arr = [10, 20, 30];
    for element in arr {
        println!("{}", element);
    }

    // Итерация по ссылке (чтобы не потребить массив)
    for element in &arr {
        println!("{}", element);
    }
}
```

## 3. Управление циклами: `break` и `continue`

### `break` — выход из цикла
```rust
fn main() {
    let mut count = 0;
    loop {
        count += 1;
        if count == 5 {
            break;
        }
    }
}
```

### `continue` — переход к следующей итерации
```rust
fn main() {
    for i in 1..=10 {
        if i % 2 == 0 {
            continue; // Пропускаем чётные
        }
        println!("Нечётное: {}", i);
    }
}
```

---

## 4. Метки циклов (Loop Labels)

Позволяют выйти из внешнего цикла из внутреннего:
```rust
fn main() {
    'outer: loop {
        println!("Внешний цикл");
        loop {
            println!("Внутренний цикл");
            break 'outer; // Выход из внешнего цикла
        }
    }
    println!("Вышли из обоих циклов");
}
```

С `continue`:
```rust
fn main() {
    'outer: for x in 0..5 {
        for y in 0..5 {
            if x == 2 && y == 2 {
                continue 'outer; // Переход к следующей итерации внешнего цикла
            }
            println!("x={}, y={}", x, y);
        }
    }
}
```

## 5. Pattern Matching: `match` (введение)

`match` — мощная конструкция для сопоставления с образцом:
```rust
fn main() {
    let number = 3;
    match number {
        1 => println!("Один"),
        2 => println!("Два"),
        3 => println!("Три"),
        _ => println!("Другое"), // _ — catch-all (как default)
    }
}
```

`match` как выражение:
```rust
fn main() {
    let x = 5;
    let result = match x {
        0 => "ноль",
        1..=5 => "от 1 до 5", // Диапазон
        6..=10 => "от 6 до 10",
        _ => "остальное",
    };
    println!("{}", result);
}
```

Связывание переменных в паттернах:
```rust
fn main() {
    let x = Some(5);
    match x {
        Some(n) if n < 10 => println!("Мало: {}", n), // Guard (страж)
        Some(n) => println!("Много: {}", n),
        None => println!("Ничего"),
    }
}
```

## 6. Практические упражнения

### Упражнение 1: FizzBuzz
```rust
fn main() {
    for n in 1..=100 {
        let output = match (n % 3, n % 5) {
            (0, 0) => "FizzBuzz".to_string(),
            (0, _) => "Fizz".to_string(),
            (_, 0) => "Buzz".to_string(),
            _ => n.to_string(),
        };
        println!("{}", output);
    }
}
```

### Упражнение 2: Поиск в массиве
```rust
fn main() {
    let arr = [4, 8, 15, 16, 23, 42];
    let target = 16;
    let mut found = false;

    for (i, &val) in arr.iter().enumerate() {
        if val == target {
            println!("Найдено на индексе {}", i);
            found = true;
            break;
        }
    }
    if !found {
        println!("Не найдено");
    }
}
```

### Упражнение 3: Вложенные циклы с метками
```rust
fn main() {
    'matrix: for i in 0..5 {
        for j in 0..5 {
            if i * j == 12 {
                println!("i={}, j={}", i, j);
                break 'matrix;
            }
        }
    }
}
```

### Упражнение 4: `if` как выражение
```rust
fn main() {
    let temp = -5;
    let state = if temp < 0 { "ice" } else if temp < 100 { "water" } else { "steam" };
    println!("State: {}", state);
}
```

## 7. Типичные ошибки новичков

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `if` without `else` in expression | `if` как выражение требует `else` | Добавьте `else` или используйте блок `{}` |
| `mismatched types` в `if` | Ветки возвращают разные типы | Приведите к общему типу или исправьте логику |
| `break` outside loop | `break` используется не в цикле | Разместите внутри `loop`/`while`/`for` |
| `continue` outside loop | Аналогично | Разместите внутри цикла |
| Infinite loop | Нет условия выхода | Добавьте `break` или условие в `while` |
| Shadowing loop variable | Переменная цикла скрывает внешнюю | Используйте разные имена или метки |

---

## 8. Сравнение циклов

| Цикл | Когда использовать | Возврат значения |
|------|-------------------|------------------|
| `loop` | Бесконечный, выход через `break` | Да (`break value`) |
| `while` | Условие проверяется каждый раз | Нет (используйте переменную снаружи) |
| `for` | Итерация по коллекции/диапазону | Нет |
