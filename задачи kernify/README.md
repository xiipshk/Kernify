## Темы

### 01_basics: Основы: переменные, ввод/вывод, типы данных
1. **A+B** (easy) - Сложить два числа
2. **Разность** (easy) - Вычислить a - b
3. **Произведение** (easy) - Умножить два числа
4. **Деление** (easy) - Целочисленное деление и остаток
5. **Квадрат числа** (easy) - Возвести в квадрат
6. **Площадь прямоугольника** (easy) - a * b
7. **Периметр прямоугольника** (easy) - 2*(a+b)
8. **Диаметр окружности** (easy) - 2*R
9. **Длина окружности** (easy) - 2*pi*R
10. **Площадь круга** (easy) - pi*R^2
11. **Среднее арифметическое** (easy) - (a+b+c)/3
12. **Обмен значениями** (easy) - Swap a и b
13. **Последняя цифра** (easy) - n % 10
14. **Сумма цифр двузначного** (easy) - (n//10)+(n%10)
15. **Перевод секунд** (medium) - Часы, минуты, секунды

### 02_conditionals: Условные операторы (if, else, elif)
1. **Положительное/отрицательное** (easy) - Знак числа
2. **Четное/нечетное** (easy) - n % 2 == 0
3. **Максимум из двух** (easy) - max(a, b)
4. **Минимум из трех** (easy) - min(a, b, c)
5. **Квадратное уравнение** (medium) - Дискриминант, корни
6. **Принадлежность интервалу** (easy) - a < x < b
7. **Високосный год** (medium) - Григорианский календарь
8. **Треугольник** (medium) - Существует ли по 3 сторонам
9. **Тип треугольника** (medium) - Равносторонний, равнобедренный
10. **Знак произведения** (easy) - Без умножения
11. **Координатные четверти** (easy) - Определить четверть точки
12. **Дни недели** (easy) - Номер -> название
13. **Стоимость покупки** (medium) - Скидки при сумме > N
14. **Калькулятор** (medium) - + - * / с проверкой на 0
15. **Квадрат/прямоугольник** (easy) - Определить фигуру по сторонам

6. **Сумма цифр числа** (easy) - While n > 0

8. **Количество делителей** (medium) - Подсчет делителей
9. **Сумма делителей** (medium) - Сумма всех делителей

11. **НОК** (medium) - a*b/НОД

14. **Угадай число** (medium) - Бинарный поиск
