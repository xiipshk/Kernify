## 1. Что такое Python и зачем он нужен

**Python** — это высокоуровневый интерпретируемый язык программирования общего назначения.

### Основные области применения:
- **Веб-разработка** (Django, FastAPI, Flask)
- **Data Science / ML** (Pandas, NumPy, scikit-learn, PyTorch, TensorFlow)
- **Автоматизация и скрипты** (работа с файлами, API, системное администрирование)
- **Тестирование** (pytest, playwright)
- **Обучение программированию** (простой синтаксис, читаемый код)
- **Научные вычисления** (SciPy, SymPy)
- **Работа с данными** (ETL, парсинг, анализ логов)

### Почему Python популярен:
- Читаемый синтаксис, близкий к английскому
- Огромная экосистема библиотек (PyPI — 500k+ пакетов)
- Кроссплатформенность (Windows, Linux, macOS)
- Активное сообщество и документация
- Поддержка всех парадигм: процедурной, ООП, функциональной

## 2. Установка Python

### Windows:
1. Скачайте установщик с **python.org/downloads**
2. **Важно**: поставьте галочку **"Add Python to PATH"**
3. Нажмите "Install Now"

### macOS:
```bash
# Через Homebrew (рекомендуется)
brew install python

# Или скачайте .pkg с python.org
```

### Linux (Ubuntu/Debian):
```bash
sudo apt update && sudo apt install python3 python3-pip python3-venv
```

### Проверка установки:
```bash
python --version
# или
python3 --version
# Должно показать: Python 3.x.x
```

## 3. Запуск Python

### Режим REPL (интерактивная оболочка):
```bash
python
>>> print("Привет, мир!")
Привет, мир!
>>> 2 + 2
4
>>> exit()
```

### Запуск файла-скрипта:
1. Создайте файл `hello.py`:
```python
print("Привет, мир!")
name = input("Как тебя зовут? ")
print(f"Привет, {name}!")
```

2. Запустите:
```bash
python hello.py
```

### IDE и редакторы (рекомендуемые):
- **VS Code** + расширение Python (бесплатно, популярно)
- **PyCharm Community** (бесплатно, мощная IDE)
- **Thonny** (простая IDE для новичков)
- **IDLE** (входит в состав Python)

## 4. Функция print()

```python
# Базовый вывод
print("Привет, мир!")

# Вывод нескольких значений (разделитель — пробел)
print("Год:", 2026, "Месяц:", "Октябрь")

# Изменение разделителя и конца строки
print("А", "Б", "В", sep="-", end="!\n")
# Вывод: А-Б-В!

# f-строки (форматирование) — Python 3.6+
name = "Анна"
age = 25
print(f"Имя: {name}, Возраст: {age}")
# Вывод: Имя: Анна, Возраст: 25

# Старый способ форматирования (для понимания чужого кода)
print("Имя: %s, Возраст: %d" % (name, age))
print("Имя: {}, Возраст: {}".format(name, age))
```

## 5. Комментарии

```python
# Это однострочный комментарий
# Он игнорируется интерпретатором

"""
Это многострочный комментарий (docstring).
Используется для документирования функций, классов, модулей.
"""

# Хорошая практика: комментарии объясняют "ЗАЧЕМ", а не "ЧТО"
# Плохо: x = x + 1  # увеличиваем x на 1
# Хорошо: x = x + 1  # переходим к следующему элементу списка
```

## 6. Основные типы ошибок

### SyntaxError — ошибка синтаксиса (код не запускается)
```python
print("Привет"  # забыта закрывающая скобка
# SyntaxError: '(' was never closed
```

### NameError — обращение к несуществующей переменной
```python
print(undefined_variable)
# NameError: name 'undefined_variable' is not defined
```

### TypeError — неправильный тип для операции
```python
"строка" + 5
# TypeError: can only concatenate str (not "int") to str
```

### ValueError — правильный тип, но неподходящее значение
```python
int("не_число")
# ValueError: invalid literal for int() with base 10
```

### IndexError / KeyError — выход за границы коллекции
```python
lst = [1, 2, 3]
print(lst[5])  # IndexError

d = {"a": 1}
print(d["b"])  # KeyError
```

### ZeroDivisionError — деление на ноль
```python
10 / 0
# ZeroDivisionError: division by zero
```

## 7. Обработка ошибки (предварительно)
