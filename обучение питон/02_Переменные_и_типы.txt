## 1. Переменные и присваивание

### Что такое переменная
Переменная — это **имя**, ссылающееся на **объект** в памяти.

```python
# Присваивание: имя = объект
name = "Анна"
age = 25
height = 1.75
is_student = True

# Несколько присваиваний в одной строке
x = y = z = 0
a, b, c = 1, 2, 3  # распаковка

# Переменная может ссылаться на другой объект
name = "Борис"  # теперь name указывает на другую строку
```

### Правила именования
- Только буквы, цифры, подчёркивание (`_`)
- Не может начинаться с цифры
- Чувствительность к регистру: `name` ≠ `Name`
- Нельзя использовать ключевые слова (`if`, `for`, `class`, `def`, ...)

**Стиль (PEP 8):**
- `snake_case` для переменных и функций: `user_name`, `total_price`
- `UPPER_SNAKE_CASE` для констант: `MAX_SIZE`, `PI`
- Описательные имена: `user_count` лучше чем `uc`

## 2. Числовые типы

### int — целые числа (неограниченной точности)
```python
x = 42
y = -10
z = 1_000_000  # подчёркивания для читаемости (Python 3.6+)

# Арифметика
print(10 + 3)   # 13
print(10 - 3)   # 7
print(10 * 3)   # 30
print(10 / 3)   # 3.333... (всегда float!)
print(10 // 3)  # 3 (целочисленное деление)
print(10 % 3)   # 1 (остаток)
print(2 ** 10)  # 1024 (степень)
```

### float — числа с плавающей точкой (IEEE 754, 64 бита)
```python
pi = 3.14159
scientific = 1.5e-4  # 0.00015 (научная нотация)

# Особенность: точность
print(0.1 + 0.2)  # 0.30000000000000004
# Решение: decimal модуль или round()
from decimal import Decimal
print(Decimal('0.1') + Decimal('0.2'))  # 0.3
```

### complex — комплексные числа
```python
z = 3 + 4j
print(z.real)   # 3.0
print(z.imag)   # 4.0
print(abs(z))   # 5.0 (модуль)
```

## 3. Строки (str) — неизменяемые последовательности Unicode

```python
# Создание
s1 = 'Одинарные кавычки'
s2 = "Двойные кавычки"
s3 = """Тройные кавычки
поддерживают
многострочность"""
s4 = '''Тоже многострочные'''

# Экранирование
path = "C:\\Users\\name"  # обратный слэш
path = r"C:\Users\name"   # raw-строка (игнорирует экранирование)

# Длина
len("привет")  # 6

# Конкатенация и повторение
"а" + "б"      # "аб"
"ха" * 3       # "хахаха"
```

## 4. Boolean (bool) — логический тип

```python
# Только два значения: True, False
is_valid = True
has_error = False

# Булевы значения других типов (правдивость / falsy)
bool(0)         # False
bool(1)         # True
bool("")        # False
bool("текст")   # True
bool([])        # False
bool([1, 2])    # True
bool(None)      # False

# Операторы сравнения (возвращают bool)
10 > 5          # True
10 == 10        # True
10 != 5         # True
"а" < "б"       # True (лексографическое сравнение)

# Логические операторы
True and False  # False
True or False   # True
not True        # False

# Короткое замыкание (short-circuit)
result = x and y / x  # если x=0, деление не выполнится
```

## 5. Преобразование типов (приведение / casting)

```python
# Явное преобразование
int("42")           # 42
int(3.99)           # 3 (отбрасывает дробную часть)
float("3.14")       # 3.14
str(123)            # "123"
bool(0)             # False
bool("")            # False

# Неявное преобразование (при операциях)
5 + 3.2             # 8.2 (int -> float)
"текст" + str(5)    # "текст5" (нужно явное str())

# Ошибки преобразования
int("привет")       # ValueError!
float("3,14")       # ValueError! (нужна точка)
```

## 6. Ввод пользователя — input()

```python
# input() ВСЕГДА возвращает строку!
name = input("Ваше имя: ")  # пользователь вводит "Анна"
print(type(name))           # <class 'str'>

# Нужно преобразовывать:
age = int(input("Возраст: "))
height = float(input("Рост: "))

# Несколько значений в одной строке
a, b = input("Два числа через пробел: ").split()
a, b = int(a), int(b)

# Безопасный ввод с проверкой
def get_int(prompt):
    while True:
        try:
            return int(input(prompt))
        except ValueError:
            print("Ошибка: введите целое число!")

age = get_int("Возраст: ")
```

## 7. None — отсутствие значения

```python
result = None
print(result is None)  # True

# None возвращается функциями без return
def greet():
    print("Привет!")

x = greet()  # печатает "Привет!", x = None
```

## 8. Проверка типа — type() и isinstance()

```python
x = 42
type(x)           # <class 'int'>
type(x) == int    # True (но лучше не так)

isinstance(x, int)          # True (рекомендуемый способ)
isinstance(x, (int, float)) # True — проверка на несколько типов
```

## Типичные ошибки новичков

| Ошибка | Правильно |
|--------|-----------|
| `input("Возраст: ")` → сравнение с числом | `int(input("Возраст: "))` |
| `if x = 5:` (присваивание) | `if x == 5:` (сравнение) |
| `"5" + 3` | `"5" + str(3)` или `int("5") + 3` |
| `name = input()` без подсказки | `name = input("Имя: ")` |
