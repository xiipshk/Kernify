## 1. Цикл while

Выполняется, пока условие истинно.

```python
# Базовый while
count = 0
while count < 5:
    print(count)
    count += 1  # важно: изменение условия выхода!
# 0 1 2 3 4

# Бесконечный цикл + break
while True:
    cmd = input("> ")
    if cmd == "exit":
        break
    print(f"Вы ввели: {cmd}")

# while с else (выполняется, если НЕ было break)
n = 5
while n > 0:
    print(n)
    n -= 1
else:
    print("Цикл завершился нормально")
# 5 4 3 2 1
# Цикл завершился нормально
```

## 2. Функция range()

Генерирует последовательность чисел (лениво — не создаёт список сразу).

```python
range(stop)              # 0, 1, ..., stop-1
range(start, stop)       # start, ..., stop-1
range(start, stop, step) # с шагом

list(range(5))           # [0, 1, 2, 3, 4]
list(range(2, 8))        # [2, 3, 4, 5, 6, 7]
list(range(0, 10, 2))    # [0, 2, 4, 6, 8]
list(range(5, 0, -1))    # [5, 4, 3, 2, 1] (обратный)
```

## 3. Цикл for

Итерируется по любой последовательности (list, tuple, str, range, dict, set, файл...).

```python
# По range
for i in range(5):
    print(i)
# 0 1 2 3 4

# По списку
fruits = ["яблоко", "банан", "вишня"]
for fruit in fruits:
    print(fruit)

# По строке
for char in "Python":
    print(char, end="-")
# P-y-t-h-o-n-

# enumerate — индекс + значение
for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")
# 0: яблоко
# 1: банан
# 2: вишня

# enumerate с началом от 1
for i, fruit in enumerate(fruits, start=1):
    print(f"{i}. {fruit}")

# zip — параллельная итерация
names = ["Анна", "Борис", "Виктор"]
ages = [25, 30, 35]
for name, age in zip(names, ages):
    print(f"{name} — {age} лет")

# По словарю
grades = {"математика": 5, "физика": 4, "химия": 5}
for subject in grades:          # ключи
    print(subject)
for grade in grades.values():   # значения
    print(grade)
for subject, grade in grades.items():  # пары
    print(f"{subject}: {grade}")
```

## 4. break, continue, else в циклах

```python
# break — выход из цикла
for i in range(10):
    if i == 5:
        break
    print(i)
# 0 1 2 3 4

# continue — пропуск итерации
for i in range(5):
    if i == 2:
        continue
    print(i)
# 0 1 3 4

# else в for — выполняется, если НЕ было break
for i in range(3):
    print(i)
else:
    print("Цикл завершён")
# 0 1 2
# Цикл завершён

# Поиск с break + else
numbers = [1, 3, 5, 7, 9]
target = 6
for n in numbers:
    if n == target:
        print("Найдено!")
        break
else:
    print("Не найдено")
# Не найдено
```

## 5. Вложенные циклы

```python
# Таблица умножения
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i*j:3}", end="")
    print()  # новая строка после внутреннего цикла
#   1  2  3
#   2  4  6
#   3  6  9

# Перебор пар (комбинации)
team = ["А", "Б", "В"]
for i in range(len(team)):
    for j in range(i + 1, len(team)):
        print(f"{team[i]} vs {team[j]}")
# А vs Б
# А vs В
# Б vs В

# break/continue во вложенных — влияют только на свой цикл
# Для выхода из внешнего — флаг или исключение
found = False
for i in range(3):
    for j in range(3):
        if i == 1 and j == 2:
            found = True
            break
    if found:
        break
```

## 6. Итерация по изменяемым коллекциям — опасно!

```python
# ОШИБКА: изменение списка во время итерации
lst = [1, 2, 3, 4, 5]
for x in lst:
    if x % 2 == 0:
        lst.remove(x)  # пропускает элементы!
print(lst)  # [1, 3, 5] — но 4 могло остаться!

# ПРАВИЛЬНО: итерируемся по копии или создаём новый
lst = [1, 2, 3, 4, 5]
# Вариант 1: по копии
for x in lst[:]:
    if x % 2 == 0:
        lst.remove(x)
# Вариант 2: list comprehension (лучше)
lst = [x for x in lst if x % 2 != 0]
# Вариант 3: обратный порядок
for i in range(len(lst) - 1, -1, -1):
    if lst[i] % 2 == 0:
        del lst[i]
```

## 7. Паттерны циклов

### Аккумулятор (сумма, произведение, счётчик)
```python
total = 0
for n in range(1, 101):
    total += n
print(total)  # 5050
```

### Поиск максимума/минимума
```python
numbers = [3, 1, 4, 1, 5, 9, 2]
maximum = numbers[0]
for n in numbers:
    if n > maximum:
        maximum = n
print(maximum)  # 9
```

### Флаг (найдено/не найдено)
```python
found = False
for item in items:
    if condition(item):
        found = True
        break
if found:
    ...
```

## 8. Комплексный пример: угадай число

```python
import random

secret = random.randint(1, 100)
attempts = 0
max_attempts = 7

print("Угадай число от 1 до 100!")

while attempts < max_attempts:
    guess = int(input(f"Попытка {attempts + 1}: "))
    attempts += 1

    if guess == secret:
        print(f"Поздравляю! Угадал за {attempts} попыток!")
        break
    elif guess < secret:
        print("Больше!")
    else:
        print("Меньше!")
else:
    print(f"Попытки закончились. Число было: {secret}")
```

## Практические задания

1. **Сумма чётных**: сумма чётных чисел от 1 до 100 (через range с шагом)
2. **Факториал**: n! через цикл (while и for)
3. **Простые числа**: выведите все простые до 100 (вложенный цикл)
4. **Пирамида**: введите высоту, нарисуйте пирамиду из `*`
5. **Таблица степеней**: базы 2-5, показатели 1-5
6. **Collatz sequence**: введите n, пока n ≠ 1: если чётное — /2, иначе *3+1

## Типичные ошибки

| Ошибка | Правильно |
|--------|-----------|
| `for i in len(lst):` | `for i in range(len(lst)):` |
| Забыли изменить счётчик в while | `while i < 10: ... i += 1` |
| `break` выходит только из одного цикла | используйте флаг или функцию с `return` |
| Изменение списка в цикле по нему | итерируйтесь по `lst[:]` или создавайте новый |
