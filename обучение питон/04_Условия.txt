## 1. Базовый if

```python
age = 20

if age >= 18:
    print("Совершеннолетний")
print("Проверка завершена")  # выполняется всегда
```

**Важно:** отступы (4 пробела) определяют блок кода!

---

## 2. if / else

```python
age = 16

if age >= 18:
    print("Можно голосовать")
else:
    print("Ещё рано")
```

---

## 3. if / elif / else

```python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"Оценка: {grade}")  # B
```

**Порядок важен:** проверяются сверху вниз, срабатывает первый подходящий.

## 4. Вложенные условия

```python
age = 20
has_license = True

if age >= 18:
    if has_license:
        print("Может водить")
    else:
        print("Нужно получить права")
else:
    print("Ещё рано для прав")
```

**Лучше — объединять через and:**
```python
if age >= 18 and has_license:
    print("Может водить")
elif age >= 18:
    print("Нужно получить права")
else:
    print("Ещё рано")
```

## 5. Truthy / Falsy значения

В условии Python приводит значение к bool:

```python
# Falsy (ложные):
False, None, 0, 0.0, "", [], (), {}, set(), range(0)

# Truthy (истинные) — всё остальное:
True, 1, -1, 3.14, "текст", [1], (1,), {"a": 1}

# Примеры
user_input = input("Введите имя: ")
if user_input:           # True, если не пустая строка
    print(f"Привет, {user_input}!")
else:
    print("Имя не введено")

# Проверка на None
value = None
if value is not None:    # правильно
    ...

if value:                # тоже работает, но 0, "", [] тоже дадут False
    ...
```

## 6. Условное выражение (тернарный оператор)

```python
# синтаксис: значение_если_true if условие else значение_если_false
age = 20
status = "взрослый" if age >= 18 else "ребёнок"

# Внутри выражений
numbers = [1, 2, 3, 4, 5]
even = [x for x in numbers if x % 2 == 0]
# или с тернарным:
labels = ["чёт" if x % 2 == 0 else "нечёт" for x in numbers]

# Вложенные (читать справа налево)
score = 85
grade = "A" if score >= 90 else "B" if score >= 80 else "C"
```

## 7. Match / Case (Python 3.10+) — структурное сопоставление

```python
command = "start"

match command:
    case "start":
        print("Запуск...")
    case "stop":
        print("Остановка")
    case "restart":
        print("Перезапуск")
    case _:          # default (wildcard)
        print("Неизвестная команда")

# С переменными и условиями (guards)
match point := (x, y):
    case (0, 0):
        print("Начало координат")
    case (x, 0) if x > 0:
        print(f"Ось X: {x}")
    case (0, y):
        print(f"Ось Y: {y}")
    case (x, y):
        print(f"Точка ({x}, {y})")

# С типами
match data:
    case int() | float() as num:
        print(f"Число: {num}")
    case str() as s:
        print(f"Строка: {s}")
    case list() as lst:
        print(f"Список из {len(lst)} элементов")
    case _:
        print("Другое")
```

## 8. Частые паттерны

### Проверка в диапазоне:
```python
# Хорошо (Python-style)
if 0 <= x <= 100:
    print("В диапазоне")

# Не нужно:
if x >= 0 and x <= 100:
    ...
```

### Множественные условия:
```python
# Вместо цепочки or
if day == "sat" or day == "sun":
    ...

# Лучше — in
if day in ("sat", "sun"):
    ...
```

### Ранний возврат (guard clauses):
```python
def process(user):
    if not user:
        return "Нет пользователя"
    if not user.is_active:
        return "Неактивен"
    if not user.has_permission:
        return "Нет прав"

    # основная логика
    return do_work(user)
```

## Практические задания

1. **Классификатор чисел**: введите число, выведите: положительное/отрицательное/ноль, чётное/нечётное
2. **Калькулятор**: два числа + операция (+,-,*,/), обработайте деление на ноль
3. **Сезон по месяцу**: 1-12 → зима/весна/лето/осень (используйте match или in)
4. **FizzBuzz**: 1-100, кратные 3 → "Fizz", 5 → "Buzz", 3 и 5 → "FizzBuzz"
5. **Валидация пароля**: длина ≥ 8, есть цифра, есть заглавная, есть спецсимвол

## Типичные ошибки

| Ошибка | Правильно |
|--------|-----------|
| `if x = 5:` | `if x == 5:` |
| `if 0 < x < 10:` без переменной | работает! Python поддерживает цепочки |
| `if name == "Анна" or "Мария":` | `if name in ("Анна", "Мария"):` |
| Забытый `:` после условия | `if x > 0:` |
| Неправильные отступы | 4 пробела (не таб!) |
