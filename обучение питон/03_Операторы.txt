## 1. Арифметические операторы

| Оператор | Название | Пример | Результат |
|----------|----------|--------|-----------|
| `+` | Сложение | `5 + 3` | `8` |
| `-` | Вычитание | `5 - 3` | `2` |
| `*` | Умножение | `5 * 3` | `15` |
| `/` | Деление (всегда float) | `5 / 2` | `2.5` |
| `//` | Целочисленное деление | `5 // 2` | `2` |
| `%` | Остаток от деления | `5 % 2` | `1` |
| `**` | Возведение в степень | `2 ** 3` | `8` |

```python
# Примеры
x = 17
y = 5

print(x + y)   # 22
print(x - y)   # 12
print(x * y)   # 85
print(x / y)   # 3.4
print(x // y)  # 3
print(x % y)   # 2
print(x ** y)  # 1419857

# Унарные плюс/минус
print(+5)   # 5
print(-5)   # -5
```

### Применение `%` и `//`:
```python
# Определение чётности
n = 42
if n % 2 == 0:
    print("Чётное")
else:
    print("Нечётное")

# Извлечение цифр числа
num = 12345
print(num % 10)       # 5 (последняя цифра)
print(num // 10)      # 1234 (число без последней цифры)

# Циклический сдвиг (часы)
hour = 23
hour = (hour + 1) % 24  # 0
```

## 2. Операторы присваивания

```python
x = 10

x += 5   # x = x + 5  → 15
x -= 3   # x = x - 3  → 12
x *= 2   # x = x * 2  → 24
x /= 4   # x = x / 4  → 6.0 (становится float!)
x //= 2  # x = x // 2 → 3.0
x %= 2   # x = x % 2  → 1.0
x **= 3  # x = x ** 3 → 1.0

# Walrus operator (Python 3.8+) — присваивание в выражении
if (n := len("hello")) > 3:
    print(f"Длина {n} > 3")  # Длина 5 > 3
```

## 3. Операторы сравнения (возвращают bool)

| Оператор | Название | Пример |
|----------|----------|--------|
| `==` | Равно | `5 == 5` → `True` |
| `!=` | Не равно | `5 != 3` → `True` |
| `<` | Меньше | `3 < 5` → `True` |
| `>` | Больше | `5 > 3` → `True` |
| `<=` | Меньше или равно | `5 <= 5` → `True` |
| `>=` | Больше или равно | `5 >= 5` → `True` |

### Цепочки сравнений (уникально для Python!)
```python
x = 5
print(1 < x < 10)     # True  (эквивалентно: 1 < x and x < 10)
print(10 > x >= 5)    # True
print(0 < x < 5)      # False (x не < 5)

# Работает с любыми типами, поддерживающими сравнение
print("a" < "b" < "c")  # True
```

### Сравнение объектов:
```python
# Числа разных типов
print(5 == 5.0)       # True (значение)
print(5 is 5.0)       # False (разные объекты в памяти)

# Строки
print("abc" == "abc") # True
print("abc" is "abc") # Может быть True (интернирование), но не гарантировано!

# Списки
a = [1, 2]
b = [1, 2]
print(a == b)  # True (равны по значению)
print(a is b)  # False (разные объекты)
```

## 4. Логические операторы

### `and`, `or`, `not`
```python
# and — True, если ОБА истинны
True and True    # True
True and False   # False
False and True   # False
False and False  # False

# or — True, если ХОТЯ БЫ ОДИН истинный
True or True     # True
True or False    # True
False or True    # True
False or False   # False

# not — инверсия
not True         # False
not False        # True
```

### Короткое замыкание (short-circuit evaluation)
```python
# and: если первый False — второй НЕ вычисляется
False and print("не выполнится")  # False, ничего не печатает

# or: если первый True — второй НЕ вычисляется
True or print("не выполнится")    # True, ничего не печатает

# Практический пример: безопасный доступ
user = None
name = user and user.name  # None (не падает с AttributeError)

# Значение по умолчанию
value = None
result = value or "по умолчанию"  # "по умолчанию"
```

### Порядок вычисления: `not` → `and` → `or`
```python
True or False and False   # True or (False and False) → True
not False or True         # (not False) or True → True
```

## 5. Операторы identidad (identitiy) — `is`, `is not`

```python
a = [1, 2]
b = a
c = [1, 2]

print(a is b)   # True (один и тот же объект)
print(a is c)   # False (разные объекты, но равно по значению)
print(a == c)   # True

# None всегда проверяем через is
x = None
print(x is None)      # True
print(x is not None)  # False
```

## 6. Операторы принадлежности (membership) — `in`, `not in`

```python
# Строки
"а" in "привет"     # True
"з" in "привет"     # False

# Списки, кортежи, множества
lst = [1, 2, 3]
2 in lst            # True
4 not in lst        # True

# Словари — проверка КЛЮЧЕЙ
d = {"a": 1, "b": 2}
"a" in d            # True
1 in d              # False (1 — значение, не ключ)
1 in d.values()     # True
```

## 7. Побитовые операторы (для int)

| Оператор | Название | Пример (5 = 0101, 3 = 0011) |
|----------|----------|------------------------------|
| `&` | И (AND) | `5 & 3` → `1` (0001) |
| `\|` | ИЛИ (OR) | `5 \| 3` → `7` (0111) |
| `^` | Исключающее ИЛИ (XOR) | `5 ^ 3` → `6` (0110) |
| `~` | НЕ (NOT) | `~5` → `-6` |
| `<<` | Сдвиг влево | `5 << 1` → `10` (1010) |
| `>>` | Сдвиг вправо | `5 >> 1` → `2` (0010) |

```python
# Практические примеры
flags = 0b1010  # 10
mask = 0b0011   # 3

flags & mask    # 0b0010 (проверка битов)
flags | mask    # 0b1011 (установка битов)
flags ^ mask    # 0b1001 (переключение битов)
~flags          # инверсия
flags << 2      # умножение на 4
flags >> 1      # деление на 2
```

## 8. Приоритет операторов (от высшего к низшему)

```
1. ()          — группировка
2. **          — возведение в степень (справа налево: 2**3**2 = 2**9 = 512)
3. +x, -x, ~x  — унарные
4. *, /, //, % — мультипликативные
5. +, -        — аддитивные
6. <<, >>      — сдвиги
7. &           — побитовое И
8. ^           — побитовое XOR
9. |           — побитовое ИЛИ
10. in, not in, is, is not, <, <=, >, >=, !=, == — сравнения/принадлежность
11. not        — логическое НЕ
12. and        — логическое И
13. or         — логическое ИЛИ
14. if-else    — тернарный оператор
15. lambda     — лямбда
16. =, +=, -=... — присваивание (справа налево)
```

### Примеры приоритета:
```python
2 + 3 * 4       # 2 + (3 * 4) = 14
(2 + 3) * 4     # 20
not True or False  # (not True) or False = False
not (True or False) # not True = False
5 == 3 + 2      # 5 == (3 + 2) = True
```

## 9. Тернарный оператор (условное выражение)

```python
# синтаксис: значение_если_true if условие else значение_если_false
age = 20
status = "совершеннолетний" if age >= 18 else "несовершеннолетний"
print(status)  # совершеннолетний

# Вложенные (читать справа налево)
score = 85
grade = "A" if score >= 90 else "B" if score >= 80 else "C"
# "B"
```
