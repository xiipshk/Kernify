## 2. Индексация и срезы

```python
s = "Python"

# Одиночный символ
s[0]    # 'P'
s[-1]   # 'n'
# s[10]  # IndexError!

# Срезы: s[start:stop:step]
s[0:3]      # 'Pyt' (0,1,2)
s[:3]       # 'Pyt' (от начала)
s[2:]       # 'thon' (до конца)
s[:]        # 'Python' (копия)
s[::2]      # 'Pto' (каждый второй)
s[1::2]     # 'yhn' (каждый второй, начиная с 1)
s[::-1]     # 'nohtyP' (реверс)
s[5:1:-1]   # 'noht' (обратный срез)

# Строки НЕИЗМЕНЯЕМЫ!
# s[0] = 'J'  # TypeError!
# Создаём новую:
new_s = 'J' + s[1:]  # 'Jython'
```

## 3. Основные методы строк

### Регистр
```python
s = "привет Мир"
s.upper()        # "ПРИВЕТ МИР"
s.lower()        # "привет мир"
s.capitalize()   # "Привет мир" (только первый)
s.title()        # "Привет Мир" (каждое слово)
s.swapcase()     # "ПРИВЕТ мИР"
```

### Поиск и проверка
```python
s = "hello world hello"

s.find("world")      # 6 (индекс, -1 если нет)
s.rfind("hello")     # 12 (последнее вхождение)
s.index("world")     # 6 (ValueError если нет)
s.count("hello")     # 2
s.startswith("hel")  # True
s.endswith("ld")     # True
"world" in s         # True (Pythonic)
```

### Замена и удаление
```python
s = "  hello world  "
s.strip()        # "hello world" (пробелы по краям)
s.lstrip()       # "hello world  "
s.rstrip()       # "  hello world"
s.strip(" h")    # "ello world" (указанные символы)

s = "hello world"
s.replace("world", "Python")     # "hello Python"
s.replace("l", "L", 1)           # "heLlo world" (только 1 замена)
```

### Разделение и объединение
```python
s = "apple,banana,cherry"
parts = s.split(",")          # ['apple', 'banana', 'cherry']
s.split(",", 1)               # ['apple', 'banana,cherry'] (maxsplit)
" a b  c ".split()            # ['a', 'b', 'c'] (любые пробелы)

lines = "line1\nline2\nline3".splitlines()  # ['line1', 'line2', 'line3']

# join — обратная операция
", ".join(parts)              # "apple, banana, cherry"
"\n".join(lines)              # строки через \n
```

### Другие полезные методы
```python
s = "hello"
s.center(10, "-")    # "--hello---" (по центру, заполнитель)
s.ljust(10, ".")     # "hello....."
s.rjust(10, ".")     # ".....hello"
s.zfill(5)           # "00hello" (нули слева, для чисел)

"hello".isalpha()    # True (только буквы)
"hello123".isalnum() # True (буквы и цифры)
"123".isdigit()      # True
"  ".isspace()       # True
"HELLO".isupper()    # True
"".isupper()         # False
```

## 4. Форматирование строк

### f-строки (Python 3.6+) — РЕКОМЕНДУЕМЫЙ способ
```python
name = "Анна"
age = 25
pi = 3.14159265

f"Имя: {name}, Возраст: {age}"
# "Имя: Анна, Возраст: 25"

# Выражения внутри {}
f"Через год: {age + 1}"
f"Имя в верхнем: {name.upper()}"

# Форматирование чисел
f"Pi = {pi:.2f}"           # "Pi = 3.14" (2 знака после точки)
f"Pi = {pi:10.3f}"         # "Pi =     3.142" (ширина 10)
f"Percent: {0.75:.0%}"     # "Percent: 75%"
f"Number: {1000:,}"        # "Number: 1,000" (разделитель тысяч)
f"Hex: {255:#x}"           # "Hex: 0xff"
f"Bin: {10:#b}"            # "Bin: 0b1010"

# Выравнивание
f"{'left':<10}"            # "left      "
f"{'center':^10}"          # "  center  "
f"{'right':>10}"           # "     right"

# Спецификатор в переменной
width = 10
precision = 2
f"{pi:{width}.{precision}f}"  # "     3.14"

# = для отладки (Python 3.8+)
x = 42
f"{x=}"           # "x=42"
f"{x=}, {name=}"  # "x=42, name='Анна'"
```

### .format() — старый способ (встречается в коде)
```python
"Имя: {}, Возраст: {}".format(name, age)
"Имя: {0}, Возраст: {1}".format(name, age)
"Имя: {name}, Возраст: {age}".format(name=name, age=age)
"Pi = {pi:.2f}".format(pi=pi)
```

### % — устаревший (C-style)
```python
"Имя: %s, Возраст: %d" % (name, age)
"Pi = %.2f" % pi
```

## 5. Поиск с регулярными выражениями (re)

```python
import re

text = "Телефон: +7-999-123-45-67, Email: user@example.com"

# Поиск
re.search(r"\d+", text)           # первое число
re.findall(r"\d+", text)          # все числа: ['7', '999', '123', '45', '67']
re.finditer(r"\d+", text)         # итератор Match объектов

# Группы
match = re.search(r"(\d+)-(\d+)", "123-456")
match.group(0)   # "123-456" (всё совпадение)
match.group(1)   # "123"
match.group(2)   # "456"
match.groups()   # ("123", "456")

# Замена
re.sub(r"\d", "*", "а1б2в3")      # "а*б*в*"
re.sub(r"(\d+)-(\d+)", r"\2-\1", "123-456")  # "456-123" (перестановка)

# Компиляция (если используете много раз)
pattern = re.compile(r"\d+")
pattern.findall(text)
```

### Основные метасимволы regex
| Символ | Значение |
|--------|----------|
| `.` | любой символ кроме \n |
| `\d` | цифра [0-9] |
| `\D` | не цифра |
| `\w` | буква/цифра/_ [a-zA-Z0-9_] |
| `\W` | не \w |
| `\s` | пробельный символ |
| `\S` | не пробельный |
| `^` | начало строки |
| `$` | конец строки |
| `*` | 0 или более |
| `+` | 1 или более |
| `?` | 0 или 1 |
| `{n,m}` | от n до m раз |
| `[abc]` | один из символов |
| `[^abc]` | любой, КРОМЕ этих |
| `(...)` | группа |
| `a\|b` | a ИЛИ b |

## 6. Кодировки и байты

```python
s = "привет"
b = s.encode("utf-8")     # b'\xd0\xbf\xd1\x80\xd0\xb8\xd0\xb2\xd0\xb5\xd1\x82'
b.decode("utf-8")         # "привет"

# Другие кодировки
s.encode("cp1251")        # Windows-1251
s.encode("ascii", errors="ignore")  # b'' (кириллица потеряна)
s.encode("ascii", errors="replace") # b'??????'
```


### Генерация slug для URL
```python
import re
def slugify(text):
    text = text.lower()
    text = re.sub(r"[^\w\s-]", "", text)
    text = re.sub(r"[\s_-]+", "-", text)
    return text.strip("-")

slugify("Привет, Мир!")  # "привет-мир"
```

## Типичные ошибки

| Ошибка | Правильно |
|--------|-----------|
| `s[0] = 'a'` | `s = 'a' + s[1:]` (строки неизменяемы) |
| `"a" + 5` | `"a" + str(5)` или `f"a{5}"` |
| `replace` меняет исходную | `s = s.replace(...)` (возвращает новую) |
| `split()` без аргумента vs `split(" ")` | `split()` — по любым пробелам, `split(" ")` — только по пробелу |
| `re.search` vs `re.match` | `search` — где угодно, `match` — только в начале |
