## 2. CPython Source Code — устройство интерпретатора

### Структура репозитория
```
cpython/
├── Python/           # Основной интерпретатор (ceval.c, compile.c)
├── Objects/          # Встроенные типы (listobject.c, dictobject.c, unicodeobject.c)
├── Modules/          # C-модули стандартной библиотеки (_json, _sqlite3, etc.)
├── Parser/           # Парсер (PEG parser в 3.9+)
├── Include/          # Публичные C API заголовки
├── Internal/         # Внутренние заголовки
├── Programs/         # python.exe, pythonw.exe
├── Lib/              # Стандартная библиотека (на Python)
├── Tools/            # Инструменты (freeze, gdb, benchmark)
└── Doc/              # Документация (RST)
```

### Ключевые файлы для изучения
| Файл | Что внутри |
|------|------------|
| `Python/ceval.c` | Главный цикл интерпретатора (eval loop) |
| `Python/compile.c` | Компилятор AST → bytecode |
| `Objects/typeobject.c` | Реализация классов, MRO, дескрипторов |
| `Objects/listobject.c` / `dictobject.c` | Реализация list/dict |
| `Objects/unicodeobject.c` | Строги (compact representation, PEP 393) |
| `Include/cpython/*.h` | Публичный C API |

## 3. C API — написание расширений

### Минимальное расширение (ручное)
```c
// mymodule.c
#define PY_SSIZE_T_CLEAN
#include <Python.h>

static PyObject* my_add(PyObject* self, PyObject* args) {
    long a, b;
    if (!PyArg_ParseTuple(args, "ll", &a, &b)) {
        return NULL;
    }
    return PyLong_FromLong(a + b);
}

static PyMethodDef MyMethods[] = {
    {"add", my_add, METH_VARARGS, "Add two integers."},
    {NULL, NULL, 0, NULL}
};

static struct PyModuleDef mymodule = {
    PyModuleDef_HEAD_INIT,
    "mymodule",
    "Example module",
    -1,
    MyMethods
};

PyMODINIT_FUNC PyInit_mymodule(void) {
    return PyModule_Create(&mymodule);
}
```

```python
# setup.py
from setuptools import Extension, setup

module = Extension("mymodule", sources=["mymodule.c"])
setup(name="mymodule", version="1.0", ext_modules=[module])
```

```bash
pip install -e .
python -c "import mymodule; print(mymodule.add(2, 3))"  # 5
```

### Cython — Python-подобный синтаксис для C-расширений
```cython
# fastmath.pyx
cdef public int fib_cython(int n) nogil:
    cdef int a = 0, b = 1, i
    for i in range(n):
        a, b = b, a + b
    return a

def fib(n: int) -> int:
    return fib_cython(n)
```

```python
# setup.py для Cython
from setuptools import Extension, setup
from Cython.Build import cythonize

ext = Extension("fastmath", sources=["fastmath.pyx"])
setup(ext_modules=cythonize([ext], language_level=3))
```

```bash
pip install cython
pip install -e .
python -c "import fastmath; print(fastmath.fib(10))"  # 55
```

### pybind11 — современный C++ биндинг
```cpp
// bind.cpp
#include <pybind11/pybind11.h>

int add(int a, int b) { return a + b; }

namespace py = pybind11;

PYBIND11_MODULE(mycpp, m) {
    m.def("add", &add, "Add two integers");
}
```

```python
# pyproject.toml (с pybind11 + scikit-build-core)
[build-system]
requires = ["scikit-build-core", "pybind11"]
build-backend = "scikit_build_core.build"

[project]
name = "mycpp"
version = "1.0.0"

[tool.scikit-build]
cmake.minimum-version = "3.15"
```

```cmake
# CMakeLists.txt
cmake_minimum_required(VERSION 3.15)
project(mycpp LANGUAGES CXX)

find_package(pybind11 CONFIG REQUIRED)
pybind11_add_module(mycpp bind.cpp)
```

## 4. Совместимость версий Python

### Стратегии поддержки
```python
# 1. Версионные проверки (в runtime)
import sys

if sys.version_info >= (3, 10):
    from typing import TypeAlias
else:
    from typing_extensions import TypeAlias

if sys.version_info >= (3, 11):
    # Exception Groups, except*
    try:
        ...
    except* ValueError as eg:
        ...
else:
    try:
        ...
    except ValueError as e:
        ...
```

```python
# 2. typing_extensions — backport новых typing фич
# pip install typing_extensions
from typing_extensions import (
    TypeAlias, ParamSpec, TypeVarTuple, Unpack,
    Self, Never, LiteralString, Final, override
)
```

```python
# 3. __future__ imports (должны быть первой строкой!)
from __future__ import annotations  # PEP 563 — отложенная оценка аннотаций
```

### Матрица поддержки (пример pyproject.toml)
```toml
[project]
requires-python = ">=3.10"
classifiers = [
    "Programming Language :: Python :: 3.10",
    "Programming Language :: Python :: 3.11",
    "Programming Language :: Python :: 3.12",
    "Programming Language :: Python :: 3.13",
]

[tool.tox]
env_list = ["py310", "py311", "py312", "py313"]

[tool.nox]
sessions = ["tests-3.10", "tests-3.11", "tests-3.12", "tests-3.13"]
```

### Тестирование на матрице версий
```yaml
# .github/workflows/test.yml
jobs:
  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: ["3.10", "3.11", "3.12", "3.13"]
    steps:
      - uses: actions/setup-python@v5
        with:
          python-version: ${{ matrix.python-version }}
      - run: pip install -e ".[dev]"
      - run: pytest
```

## Типичные ошибки

| Ошибка | Правильно |
|--------|-----------|
| Игнорировать DeprecationWarning | `python -W default` / `pytest -W error::DeprecationWarning` |
| Пиннить верхние границы зависимостей (`<4.0`) | Только нижние (`>=`), upper bounds ломают resolver |
| C-расширение без GIL management | `nogil` в Cython / `Py_BEGIN_ALLOW_THREADS` в C API |
| Нет тестов на минимальных версиях зависимостей | `pip install -e ".[dev] --constraint=constraints-min.txt` |
| Документация устарела относительно кода | `doctest` / `pytest --doctest-modules` / автогенерация из docstrings |
