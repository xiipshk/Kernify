## 1. Списки (list) — изменяемые, упорядоченные, допускают дубликаты

### Создание
```python
lst = [1, 2, 3]
empty = []
mixed = [1, "текст", 3.14, True, [1, 2]]
from_list = list("abc")     # ['a', 'b', 'c']
from_range = list(range(5)) # [0, 1, 2, 3, 4]
```

### Чтение
```python
lst = ["а", "б", "в", "г", "д"]
lst[0]        # "а" (первый)
lst[-1]       # "д" (последний)
lst[1:4]      # ["б", "в", "г"] (срез: от 1 включительно до 4 исключительно)
lst[:3]       # ["а", "б", "в"]
lst[2:]       # ["в", "г", "д"]
lst[::2]      # ["а", "в", "д"] (шаг 2)
lst[::-1]     # ["д", "г", "в", "б", "а"] (реверс)
```

### Изменение
```python
lst = [1, 2, 3]
lst[0] = 10          # [10, 2, 3]
lst[1:3] = [20, 30]  # [10, 20, 30]
lst.append(4)        # [10, 20, 30, 4] — в конец
lst.insert(1, 15)    # [10, 15, 20, 30, 4] — по индексу
lst.extend([5, 6])   # [10, 15, 20, 30, 4, 5, 6] — несколько
lst += [7, 8]        # то же что extend
```

### Удаление
```python
lst = [1, 2, 3, 2, 4]
lst.remove(2)        # удаляет ПЕРВОЕ вхождение → [1, 3, 2, 4]
popped = lst.pop()   # удаляет ПОСЛЕДНИЙ, возвращает его → 4, lst=[1, 3, 2]
popped = lst.pop(0)  # удаляет по индексу → 1, lst=[3, 2]
del lst[0]           # удаляет по индексу, не возвращает → lst=[2]
lst.clear()          # [] — очистка
```

### Другие методы
```python
lst = [3, 1, 4, 1, 5]
lst.index(4)         # 2 (индекс первого вхождения)
lst.count(1)         # 2 (сколько раз встречается)
lst.sort()           # [1, 1, 3, 4, 5] — на месте!
sorted_lst = sorted(lst, reverse=True)  # [5, 4, 3, 1, 1] — новый список
lst.reverse()        # на месте
len(lst)             # 5
```

### Копирование — важно!
```python
original = [1, 2, [3, 4]]

# ПЛОХО: простое присваивание — та же ссылка
bad_copy = original
bad_copy[0] = 99
print(original[0])   # 99! (исходник изменился)

# ХОРОШО: поверхностная копия
shallow = original[:]        # или list(original), original.copy()
shallow[0] = 99
print(original[0])   # 1 (ок)
# НО вложенные объекты всё равно те же!
shallow[2][0] = 99
print(original[2])   # [99, 4] — вложенный изменился!

# ГЛУБОКАЯ КОПИЯ (для вложенных структур)
import copy
deep = copy.deepcopy(original)
deep[2][0] = 99
print(original[2])   # [3, 4] — исходник в безопасности
```

## 2. Кортежи (tuple) — НЕИЗМЕНЯЕМЫЕ, упорядоченные

```python
# Создание
t = (1, 2, 3)
single = (1,)        # запятая ОБЯЗАТЕЛЬНА для одного элемента!
empty = ()
from_list = tuple([1, 2, 3])

# Чтение — как списки
t[0]      # 1
t[-1]     # 3
t[1:3]    # (2, 3)

# НЕТ методов изменения: append, remove, pop, sort — ОШИБКА!
# t[0] = 10  # TypeError!

# Методы
t.count(1)  # 1
t.index(2)  # 1

# Распаковка
x, y, z = t  # x=1, y=2, z=3
a, *b = (1, 2, 3, 4)  # a=1, b=[2, 3, 4]

# Зачем кортежи?
# - Ключи словаря (только неизменяемые)
# - Возврат нескольких значений из функции
# - Защита от случайного изменения
# - Чуть быстрее и меньше памяти
```

## 3. Множества (set) — неупорядоченные, уникальные элементы

```python
# Создание
s = {1, 2, 3}
empty = set()        # {} — это пустой СЛОВАРЬ!
from_list = set([1, 2, 2, 3])  # {1, 2, 3} — дубликаты удалены

# Добавление/удаление
s.add(4)             # {1, 2, 3, 4}
s.update([5, 6])     # {1, 2, 3, 4, 5, 6}
s.remove(2)          # KeyError, если нет!
s.discard(10)        # нет ошибки, если нет
s.pop()              # удаляет случайный элемент

# Операции множеств (математика)
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
a | b   # объединение → {1, 2, 3, 4, 5, 6}
a & b   # пересечение → {3, 4}
a - b   # разность → {1, 2}
a ^ b   # симметричная разность → {1, 2, 5, 6}

# Проверки
3 in a        # True
a.issubset(b)     # False
a.issuperset({1}) # True
a.isdisjoint({10}) # True (нет общих)

# frozenset — неизменяемое множество (можно ключом словаря)
fs = frozenset([1, 2, 3])
```

## 4. Словари (dict) — пары ключ: значение, упорядоченные (с Python 3.7+)

```python
# Создание
d = {"name": "Анна", "age": 25}
empty = {}
from_pairs = dict([("a", 1), ("b", 2)])
from_kwargs = dict(name="Анна", age=25)
from_keys = dict.fromkeys(["a", "b", "c"], 0)  # {'a':0, 'b':0, 'c':0}
```

### Чтение
```python
d = {"name": "Анна", "age": 25, "city": "Москва"}
d["name"]           # "Анна"
d.get("name")       # "Анна"
d.get("job", "нет") # "нет" (default, если ключа нет)
d["job"]            # KeyError!

# Ключи, значения, пары
list(d.keys())      # ["name", "age", "city"]
list(d.values())    # ["Анна", 25, "Москва"]
list(d.items())     # [("name", "Анна"), ("age", 25), ("city", "Москва")]

# Проверка ключа
"name" in d         # True
```

### Изменение
```python
d["age"] = 26       # обновление
d["job"] = "dev"    # добавление
d.update({"age": 27, "skills": ["Python"]})  # несколько
d.setdefault("city", "СПб")  # только если нет ключа
```

### Удаление
```python
age = d.pop("age")      # возвращает значение, удаляет ключ
d.pop("missing", None)  # default вместо KeyError
del d["city"]           # просто удаление
d.clear()               # {}
```

### Полезные паттерны
```python
# Счётчик слов
from collections import Counter
text = "а б в а г а"
Counter(text.split())  # Counter({'а': 3, 'б': 1, 'в': 1, 'г': 1})

# Группировка
from collections import defaultdict
groups = defaultdict(list)
for word in ["cat", "dog", "cow", "duck"]:
    groups[len(word)].append(word)
# defaultdict(<class 'list'>, {3: ['cat', 'dog', 'cow'], 4: ['duck']})

# Dict comprehension
squares = {x: x**2 for x in range(5)}  # {0:0, 1:1, 2:4, 3:9, 4:16}
```

## 5. Сравнение коллекций

| Операция | list | tuple | set | dict |
|----------|------|-------|-----|------|
| Упорядочен | ✓ | ✓ | ✗ | ✓ (3.7+) |
| Изменяем | ✓ | ✗ | ✓ | ✓ |
| Дубликаты | ✓ | ✓ | ✗ | ключи — нет |
| Индексация | ✓ | ✓ | ✗ | по ключу |
| in (поиск) | O(n) | O(n) | **O(1)** | **O(1)** по ключу |

**Когда что использовать:**
- **list** — последовательность, порядок важен, нужны дубликаты
- **tuple** — неизменяемая запись (координаты, возвраты функции, ключи)
- **set** — уникальность, быстрая проверка вхождения, математика множеств
- **dict** — ассоциативный массив (ключ → значение), быстрый поиск по ключу

## 6. Перебор (итерация)

```python
# list / tuple / set
for item in collection:
    print(item)

# dict
for key in d:
    print(key, d[key])
for key, value in d.items():
    print(key, value)

# с индексом
for i, item in enumerate(lst):
    print(i, item)
```

## Типичные ошибки

| Ошибка | Правильно |
|--------|-----------|
| `{} = пустое множество` | `set()` — пустое множество, `{}` — словарь |
| `lst = lst.sort()` | `lst.sort()` (None) или `lst = sorted(lst)` |
| `for k, v in d:` | `for k, v in d.items():` |
| Изменение списка в цикле `for x in lst:` | `for x in lst[:]:` или list comprehension |
| `[1,2,3] + [4,5]` для set | `{1,2,3} | {4,5}` |
