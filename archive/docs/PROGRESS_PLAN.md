## Быстрые команды

```bash
# Прогресс
cd Kernify && source venv/bin/activate && python content_build/progress.py [python|cpp|css|js|csharp|rust]

# Валидация конкретного урока
python content_build/validate_lessons.py content_build/lessons/python/2_8.py

# Проверка примеров
python content_build/check_examples.py content_build/lessons/python/2_8.py

# Применение урока
python content_build/apply_lesson.py content_build/lessons/python/2_8.py

# Пакетное применение (все готовые файлы языка)
python content_build/apply_lesson.py --language python

# Предпросмотр
python content_build/make_preview.py --all --language python

# Перестройка структуры БД (если менялся curriculum.py)
python content_build/rebuild_structure.py
```

## Ключевые требования STYLE_GUIDE.md

- 12–18 тыс. знаков текста (без кода)
- 8–16 блоков кода (включая output)
- Русский язык, без эмодзи, без воды
- Каждый термин объясняется при первом упоминании → пример
- Структура: вводная → «Чему научитесь» → основная часть (h3) → Типичные ошибки → Практика → Проверьте себя → Итоги → Что дальше → Углубиться
- `isinstance` вместо `type() ==`, `Optional` вместо `Union[X, None]`
- `patch` там, где объект ИСПОЛЬЗУЕТСЯ
- Примеры кода запускаемые, output точный
